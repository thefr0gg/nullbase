# HTTP

**Hypertext Transfer Protocol (HTTP)** is the foundation of data communication on the Web. It is a **stateless**, **request–response** protocol used by browsers, clients, and APIs to exchange representations of resources.

An HTTP transaction is always **client → server → client**: a client sends a *request*, and the server returns a *response* containing a **status code** and (usually) a representation of the resource.
