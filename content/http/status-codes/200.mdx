# 200 OK

The `200 OK` response status code indicates that **the request has succeeded**. It is the most common status code on the web.

<StatusCodeExplorer defaultCode={200} />

## Details

- **Class:** 2xx (Success)
- **Typical with:** `GET`, `PUT`, `PATCH`, `DELETE`, `POST`
- **Caching:** a `200` response is cacheable by default.

## Example

```http
HTTP/1.1 200 OK
Content-Type: application/json

{ "status": 200, "message": "OK" }
