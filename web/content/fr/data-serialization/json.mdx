JSON (JavaScript Object Notation) est un format de données léger, textuel — malgré son nom, il est aujourd'hui indépendant du langage, avec un analyseur dans pratiquement chaque langage de programmation. C'est le format de corps de requête/réponse par défaut à travers [REST](/fr/web-apis/rest), la plupart des [RPC](/fr/web-apis/rpc), et [GraphQL](/fr/web-apis/graphql), et chaque réponse simulée de ce site est en JSON pour exactement cette raison.

```json
{
  "id": 42,
  "name": "Grace Hopper",
  "active": true,
  "roles": ["admin", "editor"],
  "manager": null
}
```

## Ce que JSON ne peut pas représenter

JSON n'a pas de type `Date` — les horodatages sont conventionnellement sérialisés en chaînes ISO 8601 (`"2024-01-15T09:00:00Z"`) et reconvertis en véritables objets date par le consommateur, pas automatiquement. Il ne peut pas non plus représenter `undefined`, des fonctions, ou des références circulaires — `JSON.stringify` supprime silencieusement les valeurs `undefined` et les fonctions, et lève une exception sur une référence circulaire.

```js
JSON.stringify({ a: undefined, b: () => {}, c: 1 });
// '{"c":1}' — a and b are just gone, not null
```

## Une syntaxe stricte, volontairement

Contrairement aux littéraux d'objet JavaScript, JSON n'a pas de virgules finales, pas de commentaires, pas de clés sans guillemets, et pas de chaînes entre guillemets simples — cette rigueur est délibérée : un analyseur n'a pas à deviner l'intention, ce qui est précisément ce qui rend JSON fiablement interopérable à travers l'implémentation de chaque langage.
