YAML (« YAML Ain't Markup Language ») représente les mêmes données structurées que [JSON](/fr/data-serialization/json) — objets, tableaux, chaînes, nombres, booléens, null — avec la ponctuation remplacée par de l'indentation, optimisé pour qu'un humain le lise et l'écrive à la main plutôt que pour qu'une machine l'analyse rapidement. Il est rarement utilisé comme format réel de requête/réponse d'une API ; son véritable domaine est celui des fichiers de configuration (Docker Compose, manifestes Kubernetes, pipelines CI, la configuration de build de ce type même de site dans certaines stacks).

```yaml
id: 42
name: Grace Hopper
active: true
roles:
  - admin
  - editor
manager: null
```

Les mêmes données en JSON, à titre de comparaison :

```json
{ "id": 42, "name": "Grace Hopper", "active": true, "roles": ["admin", "editor"], "manager": null }
```

## L'indentation est significative, et intransigeante

Contrairement aux accolades de JSON, la structure de YAML provient entièrement de l'indentation — mélanger tabulations et espaces, ou être décalé d'un seul espace, constitue une erreur d'analyse (ou pire, change silencieusement la structure) sans accolade fermante pour repérer visuellement l'erreur.

```yaml
parent:
  child: value   # 2 spaces of indentation — a child of parent
sibling: value    # 0 spaces — a top-level key, not nested
```

## Les fameux pièges

Parce que YAML essaie de déduire les types à partir de valeurs sans guillemets, une poignée de chaînes spécifiques ne signifient pas ce qu'elles semblent signifier :

```yaml
country: NO        # parsed as the boolean false in YAML 1.1 (Norway's country code!)
version: 1.10       # parsed as the number 1.1, not the string "1.10" — the trailing zero is lost
enabled: yes         # parsed as boolean true
```

C'est un problème réel, pas hypothétique — on l'appelle couramment « le problème de la Norvège », et c'est pourquoi mettre explicitement une valeur entre guillemets (`country: "NO"`) est le choix sûr par défaut chaque fois qu'une chaîne pourrait être confondue avec un autre type.
