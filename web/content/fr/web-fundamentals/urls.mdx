Une **URL** (Uniform Resource Locator) identifie une ressource et la manière d'y accéder. Chaque partie a un rôle :

<UrlAnatomy
  parts={[
    { text: "https://", label: "schéma", color: "blue" },
    { text: "api.example.com", label: "hôte", color: "green" },
    { text: ":443", label: "port", color: "orange" },
    { text: "/v1/users", label: "chemin", color: "purple" },
    { text: "?active=true", label: "requête", color: "red" },
    { text: "#profile", label: "fragment", color: "default" },
  ]}
/>

- **`https`** — protocole/schéma. Indique au navigateur quel protocole utiliser pour parler à l'hôte.
- **`api.example.com`** — hôte. Le domaine (ou l'IP) que le DNS résout pour trouver le serveur.
- **`443`** — port. Généralement omis puisque 80 (HTTP) et 443 (HTTPS) sont les valeurs par défaut.
- **`/v1/users`** — chemin. Quelle ressource sur le serveur vous voulez.
- **`?active=true`** — chaîne de requête. Paramètres supplémentaires, sous forme de paires clé-valeur.
- **`#profile`** — fragment. Côté client uniquement — jamais envoyé au serveur.
