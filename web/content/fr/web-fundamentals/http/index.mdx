Le **protocole de transfert hypertexte (HTTP)** est le fondement de la communication web. Chaque requête de votre navigateur, chaque appel d'API, chaque interaction avec un serveur passe par HTTP.

Cette référence enseigne HTTP non pas à travers des faits isolés, mais à travers des **outils interactifs** — composez de vraies requêtes, explorez les codes de statut, inspectez les en-têtes, et comprenez pourquoi HTTP se comporte comme il le fait.

## Concepts fondamentaux

### Méthodes (verbes)
Chaque requête utilise une méthode. Voici les plus importantes :

- **[GET](/fr/web-fundamentals/http/methods/get)** — Récupérer une ressource.
- **[POST](/fr/web-fundamentals/http/methods/post)** — Soumettre des données, créer des ressources, déclencher des actions.
- **[PUT](/fr/web-fundamentals/http/methods/put)** — Remplacer ou créer une ressource entièrement.
- **[PATCH](/fr/web-fundamentals/http/methods/patch)** — Mises à jour partielles.
- **[DELETE](/fr/web-fundamentals/http/methods/delete)** — Supprimer une ressource.
- **[HEAD](/fr/web-fundamentals/http/methods/head)** — Comme GET, mais les en-têtes seulement (pas de corps).
- **[OPTIONS](/fr/web-fundamentals/http/methods/options)** — Décrire les options de communication pour une ressource.
- **[Référence de toutes les méthodes](/fr/web-fundamentals/http/methods)** — Propriétés sûre, idempotente, pouvant être mise en Cache.

### Codes de statut
Chaque réponse commence par un code. Maîtrisez-les tous :

- **[2xx Succès](/fr/web-fundamentals/http/status-codes/2xx)** — 200 OK, 201 Created, 204 No Content, etc.
- **[3xx Redirection](/fr/web-fundamentals/http/status-codes/3xx)** — 301 Moved, 302 Found, 304 Not Modified, etc.
- **[4xx Erreur client](/fr/web-fundamentals/http/status-codes/4xx)** — 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, etc.
- **[5xx Erreur serveur](/fr/web-fundamentals/http/status-codes/5xx)** — 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable, etc.

**[Explorateur de codes de statut en direct](/fr/web-fundamentals/http/status-codes)** — Découvrez ce que signifie chaque code et quand les serveurs l'utilisent.

### En-têtes
Des métadonnées qui contrôlent le comportement. L'essentiel :

**En-têtes de requête :**
- **[Authorization](/fr/web-fundamentals/http/headers/authorization)** — Prouver qui vous êtes (Basic, Bearer, clés API).
- **[Content-Type](/fr/web-fundamentals/http/headers/content-type)** — Format du corps de la requête (application/json, form-data, etc.).
- **[Accept](/fr/web-fundamentals/http/headers/accept)** — Quels formats de réponse vous pouvez comprendre.
- **[User-Agent](/fr/web-fundamentals/http/headers/user-agent)** — Identifier le client.

**En-têtes de réponse :**
- **[Content-Type](/fr/web-fundamentals/http/headers/content-type)** — Format du corps de la réponse.
- **[Cache-Control](/fr/web-fundamentals/http/headers/cache-control)** — Combien de temps mettre en Cache cette réponse.
- **[Set-Cookie](/fr/web-fundamentals/http/headers/set-cookie)** — Stocker des données côté client.
- **[Location](/fr/web-fundamentals/http/headers/location)** — Où rediriger (réponses 3xx).

**[Référence de tous les en-têtes](/fr/web-fundamentals/http/headers)** — Plus de 50 en-têtes avec exemples et cas d'usage.

## Versions du protocole

Comprendre l'évolution est important — les fonctionnalités ont changé, les performances se sont améliorées.

- **[HTTP/1.0](/fr/web-fundamentals/http/http1-0)** — L'original (1991). Sans état, simple.
- **[HTTP/1.1](/fr/web-fundamentals/http/http1-1)** — Le standard (1997–aujourd'hui). Keep-Alive, pipelining, mise en Cache.
- **[HTTP/2](/fr/web-fundamentals/http/http2)** — Multiplexage et server push (2015). Plus rapide avec une seule connexion.
- **[HTTP/3](/fr/web-fundamentals/http/http3)** — Basé sur QUIC, encore plus rapide (2022).
