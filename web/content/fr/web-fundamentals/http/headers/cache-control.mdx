L'en-tête `Cache-Control` transporte des directives qui contrôlent le comportement de mise en Cache — pour les navigateurs, et pour tout ce qui se trouve entre le client et le serveur d'origine, comme un [CDN](/fr/web-fundamentals/cdns). Il peut apparaître à la fois dans les requêtes et les réponses ; c'est dans les réponses qu'il compte le plus.

## Une réponse typique

```http
HTTP/1.1 200 OK
Content-Type: application/json
Cache-Control: public, max-age=3600, must-revalidate
```

Pouvant être mise en Cache par tout le monde, fraîche pendant une heure, et une fois cette heure écoulée, ne pas la resservir sans vérifier d'abord avec l'origine.
