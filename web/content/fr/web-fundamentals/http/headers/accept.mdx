L'en-tête de requête `Accept` indique au serveur quels types de médias le client est prêt à gérer dans la réponse — c'est la **négociation de contenu**. Un serveur pouvant retourner la même ressource en JSON, HTML, ou XML utilise `Accept` pour décider lequel envoyer réellement.

## Comment c'est structuré

`Accept` peut lister plusieurs types avec une valeur `q` (qualité) indiquant la préférence, `1` étant la plus haute :

```http
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8
```

Cela signifie : préférer HTML, puis XHTML, puis XML brut à 90% de préférence, puis n'importe quoi d'autre en dernier recours.

## Quand le serveur ne peut pas se conformer

Si le serveur ne peut réellement produire aucun des types que le client acceptera, il doit répondre avec `406 Not Acceptable` plutôt que d'envoyer silencieusement un format que le client n'a pas demandé.
