**HTTPS** est simplement **HTTP** envoyé sur une connexion chiffrée par **TLS** — le modèle requête/réponse ne change absolument pas, seul le transport en dessous change. TLS (Transport Layer Security) est ce qui fournit :

- **Le chiffrement** — personne entre le client et le serveur ne peut lire le trafic.
- **L'intégrité** — personne entre les deux ne peut modifier le trafic sans que les deux côtés ne le remarquent.
- **L'authentification** — le client obtient une preuve cryptographique qu'il parle bien au serveur qu'il croit (via le certificat du serveur).

## Ce que HTTPS ne protège pas

TLS sécurise la connexion, pas les deux extrémités. Il n'empêche pas :

- Un serveur compromis de divulguer des données qu'il détient en clair.
- Un logiciel malveillant sur le client de lire les données avant qu'elles ne soient chiffrées ou après qu'elles ont été déchiffrées.
- Un utilisateur trompé par hameçonnage pour visiter `paypa1.com` au lieu de `paypal.com` — c'est une connexion HTTPS valide vers un serveur *erroné mais réel*.
