Au-delà de [HTML](/fr/web-platform/html), [CSS](/fr/web-platform/css) et du [DOM](/fr/web-platform/dom), le navigateur expose un grand ensemble d'API JavaScript intégrées — des capacités qui ne font pas partie du langage JavaScript lui-même, mais que fournit l'environnement navigateur dans lequel JavaScript s'exécute. Node.js exécute le même langage avec un ensemble d'API intégrées complètement différent, ce qui est la façon la plus claire de voir qu'il s'agit de fonctionnalités de plateforme, pas de langage.

## Détection de fonctionnalités plutôt que reniflage de navigateur

Comme tous les navigateurs (ou toutes les versions) ne supportent pas chaque API, le code qui dépend de l'une d'elles devrait vérifier directement son existence plutôt que d'essayer d'identifier le navigateur :

```js
if ("clipboard" in navigator) {
  await navigator.clipboard.writeText("copied!");
} else {
  // fall back to a manual copy affordance
}
```

## Permissions

Plusieurs de ces API (géolocalisation, notifications, presse-papiers, caméra/microphone) sont conditionnées à une invite de permission explicite de l'utilisateur la première fois qu'une page les demande — et la plupart ne fonctionnent même que dans un contexte sécurisé (`https://` ou `localhost`), une contrainte délibérée puisqu'elles exposent une véritable capacité de l'appareil ou de l'utilisateur.
