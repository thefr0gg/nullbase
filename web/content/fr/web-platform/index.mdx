Tout ce qui se trouve dans [Web Fundamentals](/fr/web-fundamentals) et [Web APIs](/fr/web-apis) concerne la façon dont les données passent d'un serveur à un navigateur. Cette section porte sur ce qui se passe une fois qu'elles y sont arrivées — les langages et les API que le navigateur lui-même met à disposition d'une page.

## Les langages de base

- **[HTML](/fr/web-platform/html)** — structure et sémantique.
- **[CSS](/fr/web-platform/css)** — comment le navigateur décide de l'apparence d'une page.
- **[JavaScript](/fr/web-platform/javascript)** — le langage, et la façon dont le navigateur l'exécute réellement.
- **[Le DOM](/fr/web-platform/dom)** — l'arbre vivant que JavaScript manipule réellement.

## Ce que le navigateur vous donne

- **[Browser APIs](/fr/web-platform/browser-apis)** — les capacités intégrées au-delà des langages de base.
- **[Cookies](/fr/web-platform/cookies)** — de petits morceaux d'état qu'un serveur peut demander au navigateur de conserver et de renvoyer.
- **[Web Storage](/fr/web-platform/web-storage)** — un stockage clé-valeur plus grand, côté client uniquement.

## Exécuter du code hors du thread principal

- **[Service Workers](/fr/web-platform/service-workers)** — un script qui se place entre la page et le réseau.
- **[Web Workers](/fr/web-platform/web-workers)** — du JavaScript en arrière-plan, hors du thread d'interface utilisateur.

## Construire ses propres éléments

- **[Web Components](/fr/web-platform/web-components)** — des éléments HTML personnalisés et réutilisables, avec un style encapsulé.
