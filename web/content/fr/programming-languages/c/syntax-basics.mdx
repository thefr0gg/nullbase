C est typé statiquement et (surtout) faiblement : chaque variable a un type fixe déclaré à l'avance, mais le compilateur vous laissera souvent convertir entre les types sans grande protestation, tronquant ou réinterprétant parfois silencieusement les données au passage. Comprendre les types de base de C et comment ils sont déclarés est le fondement de tout le reste dans le langage.

## Types de base et déclarations

Les types intégrés de C décrivent des tailles de stockage brutes, pas des concepts de haut niveau comme « un nombre entier » — `int` fait généralement 32 bits, mais le standard C ne garantit qu'une plage minimale, pas une taille exacte, ce qui explique l'existence de types à largeur fixe comme `int32_t` quand la taille exacte compte.

```c
#include <stdio.h>

int main(void) {
    int count = 42;          /* whole numbers */
    float price = 19.99f;    /* single-precision floating point */
    double precise = 3.14159265358979; /* double-precision floating point */
    char grade = 'B';        /* a single byte, usually holding one character */
    unsigned int score = 100; /* no sign bit, so it can't go negative */

    printf("count=%d price=%.2f grade=%c\n", count, price, grade);
    return 0;
}
```

Chaque variable doit être déclarée avec un type avant d'être utilisée, et les variables locales non initialisées contiennent les bits résiduels qui se trouvaient déjà dans cette zone mémoire — C ne les remettra pas à zéro pour vous et ne se plaindra pas à la compilation si vous en lisez une avant de l'avoir assignée.

## Opérateurs et E/S formatées

`printf` écrit une sortie formatée en utilisant des **spécificateurs de format** (`%d` pour `int`, `%f` pour un flottant, `%s` pour une chaîne, `%c` pour un caractère) qui doivent correspondre au type de l'argument passé — les faire correspondre incorrectement est du C légal mais produit des résultats aberrants ou un plantage, puisque `printf` n'a aucun moyen de vérifier les types par lui-même à la compilation. `scanf` lit l'entrée de la même manière, en sens inverse, et a besoin de l'*adresse* de la variable dans laquelle écrire (d'où le `&`) :

```c
#include <stdio.h>

int main(void) {
    int a, b;
    printf("Enter two integers: ");
    scanf("%d %d", &a, &b);

    int sum = a + b;
    int remainder = a % b;   /* modulo: remainder of a divided by b */

    printf("sum = %d, remainder = %d\n", sum, remainder);
    printf("a > b is %d\n", a > b); /* comparisons produce 0 or 1 as an int */
    return 0;
}
```

C n'a pas de type booléen dédié dans les anciens standards — des comparaisons comme `a > b` s'évaluent à l'`int` `0` (faux) ou `1` (vrai), et toute valeur non nulle est considérée comme « vraie » dans une condition. `stdbool.h` (C99 et versions ultérieures) ajoute un type `bool` avec `true`/`false` comme alias de `1`/`0`, mais en interne c'est toujours un simple entier.

## Constantes et portée

`const` marque une variable comme étant en lecture seule après son initialisation (le compilateur rejette toute réassignation), et `#define` crée une macro de préprocesseur qui est substituée textuellement avant même que la compilation ne commence :

```c
#include <stdio.h>

#define MAX_USERS 100   /* preprocessor macro, substituted as text */

const double PI = 3.14159; /* typed constant, checked by the compiler */

int main(void) {
    double radius = 2.0;
    double area = PI * radius * radius;
    printf("Area: %.2f, capacity: %d\n", area, MAX_USERS);
    return 0;
}
```

`MAX_USERS` n'existe en réalité jamais comme variable en mémoire — le préprocesseur remplace chaque occurrence du texte `MAX_USERS` par `100` avant même que le compilateur ne voie le code, alors que `PI` est une véritable variable typée que le compilateur peut vérifier.
