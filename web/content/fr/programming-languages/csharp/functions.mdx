En C#, les fonctions sont presque toujours déclarées comme des **méthodes**
— des membres d'une classe ou d'un struct — plutôt que comme des fonctions
libres autonomes (les fonctions locales sont l'exception, couvertes
ci-dessous). Une méthode déclare un type de retour, un nom, et une liste de
paramètres.

## Méthodes de base

```csharp
class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }

    // Expression-bodied method: shorthand for a single-expression body
    public int Square(int x) => x * x;
}

var calc = new Calculator();
Console.WriteLine(calc.Add(2, 3));    // 5
Console.WriteLine(calc.Square(4));    // 16
```

Une méthode qui ne retourne rien utilise `void`. Les méthodes `static`
appartiennent au type lui-même plutôt qu'à une instance, ce qui explique
pourquoi `Main` est toujours `static`.

## Paramètres optionnels et valeurs par défaut

Les paramètres peuvent déclarer une valeur par défaut, les rendant optionnels
au point d'appel — tout paramètre après un paramètre avec une valeur par
défaut doit lui aussi en avoir une :

```csharp
string Greet(string name, string greeting = "Hello", bool shout = false)
{
    string message = $"{greeting}, {name}!";
    return shout ? message.ToUpper() : message;
}

Console.WriteLine(Greet("Ada"));                        // Hello, Ada!
Console.WriteLine(Greet("Ada", "Hey"));                  // Hey, Ada!
Console.WriteLine(Greet("Ada", shout: true));            // HELLO, ADA!
```

## Arguments nommés

Tout appel peut passer des arguments par nom plutôt que par position, dans
n'importe quel ordre — c'est particulièrement utile pour sauter des
paramètres optionnels précédents, comme l'a fait `shout: true` ci-dessus.
Les arguments nommés rendent les points d'appel auto-documentés quand une
méthode prend plusieurs paramètres du même type :

```csharp
void CreateUser(string name, int age, bool isAdmin = false)
{
    Console.WriteLine($"{name}, {age}, admin={isAdmin}");
}

CreateUser(name: "Grace", age: 40, isAdmin: true);
CreateUser(age: 25, name: "Alan"); // order doesn't matter with names
```

## params et fonctions locales

`params` permet à une méthode d'accepter un nombre variable d'arguments
finaux comme un tableau, et les fonctions locales vous permettent d'imbriquer
une méthode auxiliaire à l'intérieur d'une autre :

```csharp
int Sum(params int[] numbers)
{
    int total = 0;
    foreach (int n in numbers)
    {
        total += n;
    }
    return total;
}

Console.WriteLine(Sum(1, 2, 3, 4)); // 10

int Outer(int x)
{
    int Double(int n) => n * 2; // local function, only visible inside Outer
    return Double(x) + 1;
}

Console.WriteLine(Outer(5)); // 11
```
