C# (prononcé « C sharp ») est un langage orienté objet et typé statiquement
créé par Microsoft en 2000, dirigé par Anders Hejlsberg (qui a aussi conçu
TypeScript plus tard). Il fonctionne sur .NET, un runtime managé avec un
modèle mémoire à ramasse-miettes, un compilateur juste-à-temps (et de plus en
plus ahead-of-time), et une immense bibliothèque standard. C# a depuis
largement dépassé Windows : le .NET moderne est multiplateforme, open source,
et exécute des charges de travail de production sur des conteneurs Linux,
dans des jeux Unity, et sur mobile via .NET MAUI.

C# a commencé comme un cousin proche de Java, mais les deux langages ont
rapidement divergé. C# a ajouté les génériques avec un vrai support à
l'exécution, les propriétés comme construction de langage de premier ordre,
LINQ (une syntaxe de requête intégrée au langage), et, plus récemment,
`async`/`await` pour le code asynchrone, les types de référence nullables
pour détecter les bugs liés au null à la compilation, et le filtrage par
motif qui ne cesse de s'étendre à chaque version.

## Ce qui rend C# distinctif

- **Des propriétés, pas seulement des champs.** C# intègre la syntaxe
  getter/setter directement dans le langage (`public int Age { get; set; }`),
  donc l'encapsulation n'exige pas d'écrire du code répétitif
  `getAge()`/`setAge()`.
- **`async`/`await` comme syntaxe de premier ordre.** Le code asynchrone et
  non bloquant se lit comme du code synchrone, porté par `Task` et `Task<T>`.
- **Des génériques forts.** Contrairement aux génériques à effacement de type
  de Java, les génériques de C# sont réifiés à l'exécution, ce qui les rend
  plus rapides et permet des choses comme `typeof(T)` à l'intérieur d'une
  méthode générique.
- **LINQ.** Interroger et transformer des collections avec une syntaxe façon
  SQL ou des chaînes de méthodes fluides (`.Where(...)`, `.Select(...)`)
  intégrées directement dans le langage et la bibliothèque standard.
- **Les types de référence nullables.** Depuis C# 8, le compilateur peut vous
  avertir à la compilation quand une référence censée ne jamais être `null`
  pourrait l'être.

Voici un programme C# minimal et complet :

```csharp
Console.WriteLine("Hello, nullbase!");
```

Le C# moderne (depuis les instructions de premier niveau de C# 9) n'exige pas
d'enveloppe `class` et méthode `Main` pour les programmes simples — le
compilateur en génère une pour vous en coulisses. Le code plus ancien, et la
plupart des projets réels, l'écrivent encore explicitement :

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, nullbase!");
        }
    }
}
```

## Quand se tourner vers C#

C# est le choix par défaut pour les API et backends web ASP.NET Core, les
logiciels de bureau Windows et d'entreprise, et — via le moteur de jeu Unity —
une énorme part des jeux commerciaux. Sa combinaison de performance, de
sécurité mémoire, et d'une riche bibliothèque standard en fait un choix
généraliste solide partout où l'écosystème JVM pourrait autrement être
envisagé.
