C# fournit un petit ensemble de types de collection qui couvrent la plupart
des besoins quotidiens : les tableaux de taille fixe, le `List<T>`
redimensionnable, et le `Dictionary<TKey, TValue>` clé-valeur. Les trois sont
génériques, donc ils sont sûrs quant aux types sans transtypage.

## Tableaux

Les tableaux ont une taille fixe une fois créés et sont indexés à partir de
zéro :

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };
Console.WriteLine(numbers.Length); // 5
Console.WriteLine(numbers[0]);     // 1

numbers[0] = 100;

int[] empty = new int[3]; // [0, 0, 0] — value types default to their zero value

int[,] grid = new int[2, 3]; // a 2D array, 2 rows by 3 columns
grid[0, 1] = 7;
```

Comme les tableaux ne peuvent ni grandir ni rétrécir, la plupart du code qui
a besoin d'une collection de taille dynamique se tourne plutôt vers
`List<T>`.

## List\<T\>

`List<T>` est une collection ordonnée et redimensionnable — le cheval de
bataille quotidien pour les séquences d'éléments :

```csharp
using System.Collections.Generic;
using System.Linq;

List<string> names = new List<string> { "Ada", "Grace" };
names.Add("Alan");
names.Remove("Grace");

Console.WriteLine(names.Count);    // 2
Console.WriteLine(names[0]);       // Ada
Console.WriteLine(names.Contains("Alan")); // True

foreach (string name in names)
{
    Console.WriteLine(name);
}

// LINQ works directly on List<T> and most other collections
List<int> evens = new List<int> { 1, 2, 3, 4, 5, 6 }
    .Where(n => n % 2 == 0)
    .ToList();
```

## Dictionary\<TKey, TValue\>

`Dictionary<TKey, TValue>` stocke des paires clé-valeur avec une recherche
rapide par clé :

```csharp
using System.Collections.Generic;

Dictionary<string, int> ages = new Dictionary<string, int>
{
    ["Ada"] = 36,
    ["Grace"] = 85,
};

ages["Alan"] = 41; // adds a new key
ages["Ada"] = 37;  // updates an existing key

if (ages.TryGetValue("Grace", out int graceAge))
{
    Console.WriteLine(graceAge); // 85
}

foreach (KeyValuePair<string, int> pair in ages)
{
    Console.WriteLine($"{pair.Key} is {pair.Value}");
}

Console.WriteLine(ages.ContainsKey("Nobody")); // False
```

`TryGetValue` est la façon idiomatique de rechercher une clé qui pourrait ne
pas exister — indexer avec `ages["Nobody"]` sur une clé manquante lève une
`KeyNotFoundException` au lieu de retourner `null` ou une valeur par défaut.
