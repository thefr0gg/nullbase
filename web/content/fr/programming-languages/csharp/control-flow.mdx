Le flux de contrôle de C# commence de façon familière — `if`/`else`, `for`,
`while` — puis va plus loin que la plupart des langages de la famille C avec
des expressions `switch` qui filtrent sur le type et la structure, pas
seulement l'égalité.

## if / else et boucles

```csharp
int score = 82;

if (score >= 90)
{
    Console.WriteLine("A");
}
else if (score >= 80)
{
    Console.WriteLine("B");
}
else
{
    Console.WriteLine("C or below");
}

for (int i = 0; i < 3; i++)
{
    Console.WriteLine($"Iteration {i}");
}

int n = 5;
while (n > 0)
{
    Console.WriteLine(n);
    n--;
}
```

`foreach` itère sur n'importe quel `IEnumerable<T>` — tableaux, listes,
dictionnaires — sans gérer d'index :

```csharp
string[] fruits = { "apple", "banana", "cherry" };
foreach (string fruit in fruits)
{
    Console.WriteLine(fruit);
}
```

## Le switch classique

L'instruction `switch` traditionnelle compare une valeur à un ensemble de cas
constants et exige un `break` explicite (ou une autre instruction de saut)
par cas — tomber au cas suivant est une erreur de compilation sauf si le
corps du cas est vide :

```csharp
int day = 3;
switch (day)
{
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        Console.WriteLine("Weekday");
        break;
    case 6:
    case 7:
        Console.WriteLine("Weekend");
        break;
    default:
        Console.WriteLine("Invalid day");
        break;
}
```

## Filtrage par motif avec les expressions switch

Depuis C# 8, `switch` peut être utilisé comme une *expression* qui retourne
une valeur, et ses motifs vont bien au-delà de l'égalité : les motifs de
type, les motifs relationnels, et les motifs de propriété vous permettent de
brancher sur la forme d'un objet en un seul endroit.

```csharp
object shape = new { Kind = "circle", Radius = 3.0 };

string Describe(object value) => value switch
{
    int n when n < 0 => "negative integer",
    int n => $"non-negative integer: {n}",
    string s when s.Length == 0 => "empty string",
    string s => $"string of length {s.Length}",
    null => "nothing at all",
    _ => "something else",
};

Console.WriteLine(Describe(-5));   // negative integer
Console.WriteLine(Describe("hi")); // string of length 2
Console.WriteLine(Describe(null)); // nothing at all
```

Les motifs de propriété peuvent déstructurer et filtrer directement sur les
membres d'un objet, ce qui est courant lors de la manipulation de types
record :

```csharp
record Point(int X, int Y);

string Classify(Point p) => p switch
{
    { X: 0, Y: 0 } => "origin",
    { X: 0 } => "on the Y axis",
    { Y: 0 } => "on the X axis",
    { X: > 0, Y: > 0 } => "first quadrant",
    _ => "elsewhere",
};

Console.WriteLine(Classify(new Point(0, 0))); // origin
Console.WriteLine(Classify(new Point(3, 5))); // first quadrant
```

Les expressions `switch` avec filtrage par motif doivent être exhaustives du
point de vue du compilateur — un bras `_` de rejet est le moyen habituel de
le garantir, similaire à `default` dans une instruction `switch` classique.
