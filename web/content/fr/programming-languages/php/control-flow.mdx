Le flux de contrôle de PHP paraîtra immédiatement familier si vous connaissez
un langage de la famille C, avec quelques ajouts spécifiques à PHP qui
valent la peine d'être connus : `match` (ajouté dans PHP 8.0) et une syntaxe
alternative à deux-points conçue pour mélanger PHP avec des templates HTML.

## if / elseif / else

Notez l'orthographe : `elseif` (un seul mot), pas `else if`, bien que PHP
accepte les deux — `elseif` est le style conventionnel dans les bases de code
PHP.

```php
<?php

function classify(int $score): string {
    if ($score >= 90) {
        return "A";
    } elseif ($score >= 80) {
        return "B";
    } else {
        return "F";
    }
}

echo classify(85) . "\n"; // B
```

## Boucles

PHP a `while`, `do...while`, `for`, et `foreach` — foreach étant celle vers
laquelle vous vous tournerez constamment, puisqu'elle fonctionne directement
sur les tableaux :

```php
<?php

$fruits = ["apple", "banana", "cherry"];

foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit\n";
}
```

`for` et `while` se comportent exactement comme en C :

```php
<?php

for ($i = 0; $i < 3; $i++) {
    echo "count: $i\n";
}

$n = 1;
while ($n < 100) {
    $n *= 2;
}
echo $n . "\n"; // 128
```

## switch

`switch` en PHP utilise la **comparaison laxiste** (`==`) par défaut et
tombe à travers les cas à moins de `break` — le piège classique de style C :

```php
<?php

$role = "editor";

switch ($role) {
    case "admin":
        echo "full access\n";
        break;
    case "editor":
    case "author":
        echo "can publish\n";
        break;
    default:
        echo "read only\n";
}
```

## match — une alternative plus stricte, basée sur des expressions

`match` (PHP 8.0+) corrige les deux plus gros pièges de switch : il compare
avec une sémantique stricte (`===`), et il n'y a pas de chute à travers les
cas — chaque branche est une seule expression, et `match` lui-même s'évalue
en une valeur.

```php
<?php

$role = "editor";

$access = match ($role) {
    "admin" => "full access",
    "editor", "author" => "can publish",
    default => "read only",
};

echo $access . "\n"; // can publish
```

Contrairement à `switch`, une valeur non trouvée sans branche `default` lève
une `UnhandledMatchError` plutôt que de ne rien faire silencieusement — une
amélioration de sécurité délibérée.

## La syntaxe alternative à deux-points

À l'intérieur de templates qui mélangent PHP et HTML, PHP propose une
syntaxe basée sur les deux-points pour `if`, `foreach`, `for`, et `while` qui
évite un mur d'accolades :

```php
<?php $items = ["tea", "coffee"]; ?>
<ul>
<?php foreach ($items as $item): ?>
    <li><?= $item ?></li>
<?php endforeach; ?>
</ul>
```

`<?= $item ?>` est un raccourci pour `<?php echo $item; ?>` et est courant
dans les fichiers de template exactement pour cette raison.
