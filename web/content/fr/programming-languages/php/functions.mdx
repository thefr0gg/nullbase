Les fonctions en PHP sont déclarées avec le mot-clé `function` et peuvent
apparaître au premier niveau (PHP n'exige pas que le code vive à l'intérieur
d'une classe). Depuis PHP 7, les paramètres et les valeurs de retour peuvent
porter des indications de type, que le moteur applique à l'exécution.

## Déclaration de base

```php
<?php

function greet(string $name): string {
    return "Hello, $name!";
}

echo greet("Ada") . "\n";
```

## Arguments par défaut

N'importe quel paramètre peut avoir une valeur par défaut, ce qui permet aux
appelants de l'omettre. Les paramètres par défaut doivent venir après les
paramètres sans valeur par défaut :

```php
<?php

function makeGreeting(string $name, string $greeting = "Hello"): string {
    return "$greeting, $name!";
}

echo makeGreeting("Grace") . "\n";              // Hello, Grace!
echo makeGreeting("Grace", "Welcome") . "\n";    // Welcome, Grace!
```

## Arguments nommés

PHP 8.0 a ajouté les arguments nommés, qui permettent à un appelant de
sauter des valeurs par défaut antérieures sans les répéter positionnellement :

```php
<?php

function connect(string $host, int $port = 5432, bool $ssl = false): string {
    return ($ssl ? "ssl://" : "") . "$host:$port";
}

echo connect("db.internal", ssl: true) . "\n"; // ssl://db.internal:5432
```

## Fonctions variadiques

Préfixer le dernier paramètre avec `...` rassemble n'importe quel nombre
d'arguments finaux dans un tableau — l'équivalent en PHP de `*args` :

```php
<?php

function sum(int ...$numbers): int {
    $total = 0;
    foreach ($numbers as $n) {
        $total += $n;
    }
    return $total;
}

echo sum(1, 2, 3, 4) . "\n"; // 10
echo sum() . "\n";            // 0
```

L'opérateur de dispersion `...` fait l'inverse lors de l'appel d'une
fonction : il déballe un tableau en arguments positionnels.

```php
<?php

$values = [3, 6, 9];
echo sum(...$values) . "\n"; // 18
```

## Passage par référence

Par défaut, les arguments sont passés par valeur — une fonction reçoit une
copie. Ajouter `&` avant un paramètre le passe par référence à la place,
permettant à la fonction de muter la variable de l'appelant :

```php
<?php

function increment(int &$n): void {
    $n++;
}

$counter = 10;
increment($counter);
echo $counter . "\n"; // 11
```

## Fonctions anonymes et fonctions fléchées

PHP supporte les closures via `function` (avec une clause `use` explicite
pour capturer les variables externes) et la syntaxe plus concise `fn` de
fonction fléchée, qui capture automatiquement par valeur :

```php
<?php

$multiplier = 3;

$classic = function (int $n) use ($multiplier): int {
    return $n * $multiplier;
};

$arrow = fn(int $n): int => $n * $multiplier;

echo $classic(5) . " " . $arrow(5) . "\n"; // 15 15
```
