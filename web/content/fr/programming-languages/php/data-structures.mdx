PHP a exactement une structure de données composée intégrée : `array`. Là où
de nombreux langages donnent un type liste séparé et un type map/dictionnaire
séparé, le tableau de PHP est les deux à la fois, soutenu en interne par une
table de hachage ordonnée. C'est l'une des choses les plus spécifiques à PHP
avec lesquelles se familiariser, car cela signifie que « array » en PHP est
un concept beaucoup plus large que « array » en C, Java, ou Rust.

## Tableaux indexés

Sans clés explicites, PHP assigne des clés entières séquentielles commençant
à 0 — c'est le cas d'usage « liste » :

```php
<?php

$colors = ["red", "green", "blue"];

echo $colors[0] . "\n";   // red
echo count($colors) . "\n"; // 3

$colors[] = "yellow"; // append
foreach ($colors as $color) {
    echo $color . "\n";
}
```

## Tableaux associatifs

Le même type `array` accepte des clés arbitraires — des chaînes, dans ce
cas — en faisant une table de hachage :

```php
<?php

$user = [
    "name" => "Ada",
    "role" => "admin",
    "age"  => 36,
];

echo $user["name"] . "\n"; // Ada

foreach ($user as $key => $value) {
    echo "$key: $value\n";
}
```

## La particularité : c'est le même type, et vous pouvez les mélanger

Comme les tableaux indexés et associatifs sont la même structure sous-jacente,
rien n'empêche de mélanger des clés entières et des clés chaîne dans un même
tableau — et l'ordre des clés de PHP est **l'ordre d'insertion**, pas trié,
ce qui surprend les personnes venant de langages avec un type map de
hachage séparé :

```php
<?php

$mixed = [
    "name" => "Grace",
    0      => "first positional",
    "role" => "engineer",
    1      => "second positional",
];

foreach ($mixed as $key => $value) {
    echo "$key => $value\n";
}
// Prints in insertion order: name, 0, role, 1 — not sorted by key type or value
```

Cela signifie aussi qu'une « liste » en PHP n'est en réalité qu'une
convention (des clés entières séquentielles à partir de 0), pas une garantie
— `array_filter()` sur un tableau indexé préserve les clés originales et peut
laisser des trous, ce qui est une source de bugs très courante quand le code
suppose que les indices restent contigus :

```php
<?php

$numbers = [10, 20, 30, 40];
$evens = array_filter($numbers, fn($n) => $n % 2 === 0);

print_r($evens);
// [1 => 20, 3 => 40]  — original keys kept, index 0 and 2 are gone
echo array_values($evens)[0] . "\n"; // array_values() re-indexes from 0
```

## Fonctions de tableau courantes

La bibliothèque standard de PHP a bien plus d'une centaine de fonctions
`array_*`. Quelques-unes qui reviennent constamment :

```php
<?php

$nums = [5, 3, 8, 1];

sort($nums);                          // [1, 3, 5, 8], sorts in place
echo implode(", ", $nums) . "\n";      // "1, 3, 5, 8"

$doubled = array_map(fn($n) => $n * 2, $nums);
$total = array_reduce($nums, fn($carry, $n) => $carry + $n, 0);

echo implode(", ", $doubled) . "\n"; // 2, 6, 10, 16
echo $total . "\n";                   // 17
```
