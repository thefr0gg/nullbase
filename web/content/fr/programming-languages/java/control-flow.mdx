Les constructions de flux de contrôle de Java vous sembleront familières si
vous connaissez le C, le C++, ou JavaScript — les accolades délimitent les
blocs et les conditions doivent être de véritables expressions `boolean`,
pas des valeurs truthy/falsy converties depuis des nombres ou des objets.

## if / else

```java
int score = 82;

if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("C or below");
}
```

À la différence du C, `if (score)` ne compile pas quand `score` est un
`int` — la condition doit être une expression `boolean` comme
`score != 0`. Cela élimine toute une classe de bugs « assignation au lieu
de comparaison », puisque `if (score = 0)` est aussi une erreur de
compilation plutôt qu'une assignation silencieuse.

## switch : forme classique et forme en flèche

Le `switch` classique tombe au cas suivant à moins que vous ne fassiez
`break` :

```java
int day = 3;
String name;
switch (day) {
    case 1:
        name = "Monday";
        break;
    case 2:
        name = "Tuesday";
        break;
    case 3:
        name = "Wednesday";
        break;
    default:
        name = "Unknown";
}
System.out.println(name);
```

Java 14 a introduit la forme en flèche, qui ne tombe pas au cas suivant et
peut produire une valeur directement avec `yield` (ou comme une
expression) :

```java
int day = 3;
String name = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Unknown";
};
System.out.println(name);
```

La forme en flèche est généralement préférée en Java moderne : il est plus
difficile de tomber au cas suivant par accident, et l'utiliser comme
expression signifie que le compilateur peut vérifier que chaque branche
produit une valeur du même type.

## Boucles

Java a trois formes de boucle. `for` avec un compteur explicite :

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

Le `for` amélioré (un « for-each ») pour itérer une collection ou un
tableau sans indexation manuelle :

```java
int[] scores = {70, 85, 92};
for (int score : scores) {
    System.out.println(score);
}
```

`while` et `do-while`, distingués par le moment où la condition est
vérifiée — `while` vérifie avant la première itération, `do-while`
exécute toujours le corps au moins une fois :

```java
int n = 5;
while (n > 0) {
    System.out.println(n);
    n--;
}

int attempts = 0;
do {
    attempts++;
} while (attempts < 3);
System.out.println(attempts);
```

`break` quitte entièrement une boucle ; `continue` passe à l'itération
suivante. Les deux acceptent une étiquette (`outer:`) pour cibler une
boucle englobante quand des boucles sont imbriquées.
