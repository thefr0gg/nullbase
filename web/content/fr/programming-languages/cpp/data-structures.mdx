C++ vous offre un choix de conteneurs selon que la taille est connue à l'avance et selon que vous avez besoin d'une recherche rapide par clé plutôt que par position — choisir le mauvais est une source courante à la fois de bugs et de lenteur inutile.

## Tableaux

```cpp
#include <iostream>

int main() {
    int scores[5] = {90, 85, 77, 92, 60};

    for (int i = 0; i < 5; i++) {
        std::cout << "scores[" << i << "] = " << scores[i] << "\n";
    }
    return 0;
}
```

Un tableau de style C comme `scores` a une taille fixée à la compilation et aucune vérification des limites — lire ou écrire `scores[5]` compile proprement mais lit au-delà de la mémoire du tableau, un comportement indéfini qui peut corrompre silencieusement des données sans rapport. Sa taille n'est pas non plus suivie à l'exécution ; une fonction recevant `scores` a besoin que la longueur soit passée séparément.

## `std::vector`

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores;
    scores.push_back(90);
    scores.push_back(85);
    scores.push_back(77);

    scores.push_back(100);
    std::cout << "Count: " << scores.size() << "\n";

    for (int s : scores) {
        std::cout << s << " ";
    }
    std::cout << "\n";

    scores.pop_back();
    std::cout << "After pop_back, count: " << scores.size() << "\n";
    return 0;
}
```

`std::vector<int>` est un tableau redimensionnable : `push_back` ajoute un élément et fait grandir automatiquement le stockage sous-jacent, `size()` rapporte le nombre d'éléments actuel, et `pop_back()` supprime le dernier élément. Contrairement à un tableau brut, un vector connaît toujours sa propre longueur et gère sa propre mémoire — c'est pourquoi `std::vector` est le choix par défaut pour une séquence de valeurs en C++ moderne, réservant un tableau de style C à taille fixe uniquement pour les cas où la taille est véritablement constante et connue à la compilation (ou en utilisant `std::array`, qui offre la même garantie de taille fixe avec une interface plus sûre).

## `std::map`

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> ages;
    ages["Ada"] = 36;
    ages["Grace"] = 85;
    ages["Alan"] = 41;

    ages["Ada"] = 37; // overwrites the existing entry

    for (const auto& pair : ages) {
        std::cout << pair.first << " -> " << pair.second << "\n";
    }
    return 0;
}
```

`std::map<K, V>` stocke des paires clé-valeur et les garde ordonnées par clé en interne (à l'aide d'un arbre binaire équilibré), donc itérer sur un map visite toujours les entrées dans l'ordre croissant des clés — ici, par ordre alphabétique de nom. Indexer avec `ages["Ada"]` insère une nouvelle entrée ou met à jour l'existante si la clé est déjà présente ; rechercher une clé qui n'existe pas avec `[]` l'insère silencieusement avec une valeur construite par défaut, ce qui est une surprise courante — `ages.find("Bob")` ou `ages.count("Bob")` sont les façons plus sûres de vérifier la présence sans insérer.
