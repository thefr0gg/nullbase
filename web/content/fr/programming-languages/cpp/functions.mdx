Une fonction C++ a un type de retour explicite, un nom, et une liste de paramètres fixe — le compilateur vérifie chaque point d'appel par rapport à cette signature, donc appeler une fonction avec le mauvais nombre ou le mauvais type d'arguments est une erreur de compilation, pas quelque chose découvert à l'exécution.

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

double average(int a, int b, int c) {
    return (a + b + c) / 3.0;
}

int main() {
    std::cout << add(4, 5) << "\n";
    std::cout << average(2, 4, 9) << "\n";
    return 0;
}
```

## Passage par valeur vs. passage par référence

```cpp
#include <iostream>

void incrementByValue(int n) {
    n = n + 1; // only modifies the local copy
}

void incrementByReference(int& n) {
    n = n + 1; // modifies the caller's variable
}

int main() {
    int x = 10;
    incrementByValue(x);
    std::cout << "After by-value: " << x << "\n"; // still 10

    incrementByReference(x);
    std::cout << "After by-reference: " << x << "\n"; // now 11
    return 0;
}
```

Par défaut, C++ passe les arguments **par valeur** — la fonction reçoit une copie, donc les changements effectués à l'intérieur n'affectent jamais la variable de l'appelant. Ajouter `&` au type d'un paramètre en fait un paramètre **référence** : `n` devient un autre nom pour la véritable variable de l'appelant, donc les modifications à l'intérieur de la fonction sont visibles à l'extérieur. C'est aussi comme cela que C++ évite de copier de gros objets : un paramètre `const std::string&`, par exemple, permet à une fonction de lire une chaîne sans la copier et sans permettre qu'elle soit modifiée.

## Arguments par défaut et surcharge

```cpp
#include <iostream>
#include <string>

void greet(const std::string& name, const std::string& greeting = "Hello") {
    std::cout << greeting << ", " << name << "!\n";
}

int multiply(int a, int b) {
    return a * b;
}

double multiply(double a, double b) {
    return a * b;
}

int main() {
    greet("Ada");                 // uses the default greeting
    greet("Grace", "Welcome");    // overrides it

    std::cout << multiply(3, 4) << "\n";       // calls the int version
    std::cout << multiply(2.5, 4.0) << "\n";   // calls the double version
    return 0;
}
```

La valeur par défaut de `greeting` signifie que les appelants peuvent l'omettre entièrement ; un argument par défaut doit venir après tous les paramètres qui n'en ont pas. La **surcharge** permet à plusieurs fonctions de partager un nom tant que leurs listes de paramètres diffèrent — le compilateur choisit la version correspondante en fonction des types d'arguments à chaque point d'appel, résolu entièrement à la compilation.
