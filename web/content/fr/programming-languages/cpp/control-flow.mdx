Les instructions de flux de contrôle décident quel code s'exécute réellement et combien de fois — sans elles, un programme C++ ne serait qu'une simple séquence linéaire d'instructions exécutées une fois, de haut en bas.

## `if` / `else if` / `else`

```cpp
#include <iostream>

int main() {
    int score = 82;

    if (score >= 90) {
        std::cout << "Grade: A\n";
    } else if (score >= 80) {
        std::cout << "Grade: B\n";
    } else if (score >= 70) {
        std::cout << "Grade: C\n";
    } else {
        std::cout << "Grade: F\n";
    }
    return 0;
}
```

Les conditions sont évaluées de haut en bas, et la première branche dont la condition est `true` s'exécute — le reste est ignoré, même si une condition ultérieure aurait aussi été `true`. Un simple `if` sans `else` correspondant ne fait simplement rien quand sa condition est `false`.

## `switch`

```cpp
#include <iostream>

int main() {
    int day = 3;

    switch (day) {
        case 1:
            std::cout << "Monday\n";
            break;
        case 2:
            std::cout << "Tuesday\n";
            break;
        case 3:
            std::cout << "Wednesday\n";
            break;
        default:
            std::cout << "Some other day\n";
            break;
    }
    return 0;
}
```

`switch` compare une valeur à un ensemble de cas constants. Chaque `case` nécessite un `break` explicite — sans cela, l'exécution **tombe à travers (fallthrough)** dans le cas suivant, que sa valeur corresponde ou non, une bizarrerie de C++ héritée de C qui est une source courante de bugs quand on l'oublie.

## Boucles

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores = {70, 85, 90, 60};

    // classic for loop, index-based
    for (int i = 0; i < scores.size(); i++) {
        std::cout << "Index " << i << ": " << scores[i] << "\n";
    }

    // range-based for (C++11), no index needed
    for (int score : scores) {
        if (score < 65) continue;
        std::cout << "Passed with " << score << "\n";
    }

    // while loop
    int attempts = 0;
    while (attempts < 3) {
        std::cout << "Attempt " << attempts << "\n";
        attempts++;
    }
    return 0;
}
```

Le classique `for (init; condition; increment)` donne un contrôle total sur la variable de boucle, ce qui compte quand vous avez besoin de l'index lui-même (comme ci-dessus, pour l'afficher) ou devez sauter de plus d'un. Le **for basé sur une plage**, ajouté en C++11, itère directement sur les éléments d'un conteneur sans indexation manuelle — c'est la forme privilégiée chaque fois que l'index n'est pas nécessaire, puisqu'il n'y a pas de décalage d'un cran (off-by-one) possible. `continue` saute directement à l'itération suivante ; `break` (non montré ici) quitterait la boucle entièrement. `while` s'exécute tant que sa condition est vraie, vérifiée avant chaque itération — si la condition est `false` dès le départ, le corps ne s'exécute jamais du tout, contrairement à `do...while`, qui exécute toujours le corps au moins une fois.
