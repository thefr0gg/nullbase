Python a quatre types de conteneurs intégrés au langage lui-même, sans import nécessaire, et choisir le bon est surtout une question de savoir si l'ordre compte, si le contenu doit changer, et si on cherche des éléments par position ou par nom.

Une **liste** est une séquence ordonnée et mutable — le choix par défaut quand on a une collection de choses qui pourraient grandir, rétrécir, ou être réordonnées.

```python
numbers = [3, 1, 4, 1, 5, 9]
numbers.append(2)
numbers.sort()
print(numbers)  # [1, 1, 2, 3, 4, 5, 9]
```

Un **tuple** ressemble à une liste mais est immuable — une fois créé, on ne peut pas y ajouter d'élément ni en réassigner un. Cette immuabilité rend les tuples utilisables comme clés de dict (les listes ne le peuvent pas) et signale une intention : un tuple dit « ceci est un groupe fixe et petit de valeurs », comme des coordonnées.

```python
point = (10, 20)  # tuples are immutable
x, y = point       # unpacking works the same as with lists
print(x, y)  # 10 20
```

Un **dict** stocke des paires clé-valeur et recherche les valeurs par clé plutôt que par position, ce qui en fait le choix naturel pour tout ce que l'on décrirait autrement comme « un enregistrement avec des champs nommés ».

```python
user = {"name": "Rae", "age": 29}
user["email"] = "rae@example.com"
for key, value in user.items():
    print(key, value)
```

Un **set** stocke des valeurs uniques et non ordonnées et rejette automatiquement les doublons à l'insertion — utile pour les tests d'appartenance (`x in my_set` est rapide) et pour dédupliquer une collection.

```python
unique_ids = {1, 2, 2, 3, 3, 3}
print(unique_ids)  # {1, 2, 3}
```

La seule chose à bien intégrer à propos des listes (et des dicts, et des sets) est qu'ils sont des *objets* mutables — une variable qui en contient un ne détient pas une copie de son contenu, elle détient une référence vers la même liste sous-jacente que tous les autres qui ont cette variable pointent aussi.
