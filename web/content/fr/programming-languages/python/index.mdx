Python est un langage interprété à typage dynamique dont le trait déterminant est de faire de la lisibilité une caractéristique du langage plutôt qu'une préférence de style : les blocs sont définis par l'indentation plutôt que par des accolades ou des mots-clés `end`, si bien que la structure visuelle d'un script et son flux de contrôle réel ne peuvent jamais diverger. Il n'y a pas d'étape de compilation séparée à exécuter — l'implémentation de référence, CPython, lit un fichier `.py` et l'exécute directement — ce qui explique en partie pourquoi Python se retrouve partout, des scripts ponctuels aux backends web de production, en passant par les pipelines de données et le code de machine learning.

```python
print("Hello, world!")

name = "Ada"
age = 36
print(f"{name} is {age} years old")
```

Deux choses ressortent déjà dans ce minuscule exemple. D'abord, il n'y a aucune déclaration de type nulle part — `name` et `age` tirent leur type des valeurs qui leur sont assignées, et une variable peut être réassignée à un type différent plus tard sans aucune protestation. Ensuite, la chaîne `f"..."` est une f-string : un littéral de chaîne avec des espaces réservés `{expression}` évalués en ligne, qui est la façon dont la plupart du code Python construit du texte formaté plutôt que de concaténer des morceaux avec `+`.

Python est aussi livré avec une grande bibliothèque standard et un immense écosystème de paquets tiers installables via `pip`, si bien qu'une quantité surprenante de travail réel — lire du JSON, faire des requêtes HTTP, analyser des dates — ne nécessite aucune dépendance au-delà de ce qui est déjà installé, ou d'un simple `pip install`.

```python
def fizzbuzz(n):
    for i in range(1, n + 1):
        if i % 15 == 0:
            print("FizzBuzz")
        elif i % 3 == 0:
            print("Fizz")
        elif i % 5 == 0:
            print("Buzz")
        else:
            print(i)

fizzbuzz(15)
```

Remarquez qu'il n'y a pas de parenthèses autour de la condition du `if`, pas de points-virgules terminant les instructions, et que l'étendue du corps de la fonction est définie uniquement par le niveau d'indentation de ses lignes — retirez l'indentation et c'est une erreur de syntaxe, pas simplement une mise en forme désordonnée.
