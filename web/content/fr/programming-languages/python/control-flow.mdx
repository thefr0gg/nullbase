Les instructions conditionnelles et de boucle de Python se lisent presque comme de l'anglais courant, mais la mécanique sous-jacente mérite d'être précise, en particulier les parties qui diffèrent des langages de la famille C.

```python
temperature = 72
if temperature > 80:
    print("hot")
elif temperature > 60:
    print("mild")
else:
    print("cold")
```

`elif` est la façon dont Python écrit « else if » — il n'y a pas de paire de mots-clés `else if` séparée, et les conditions n'ont jamais besoin de parenthèses autour d'elles (bien qu'on puisse en ajouter). N'importe quelle valeur peut être utilisée comme condition, pas seulement les booléens : `0`, `""`, `None`, et les collections vides (`[]`, `{}`, `()`) sont toutes « falsy », et tout le reste est « truthy », donc `if some_list:` est une façon idiomatique de vérifier « cette liste est-elle non vide » sans comparer explicitement les longueurs.

```python
fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(index, fruit)
```

La boucle `for` de Python itère directement sur les *éléments* d'une séquence — il n'y a pas de motif de comptage à la C-style `for (i = 0; i < len; i++)`. Quand l'index est réellement nécessaire en plus de la valeur, `enumerate()` enveloppe la séquence pour produire des paires `(index, value)`, ce qui est la façon idiomatique d'obtenir les deux sans suivre manuellement un compteur.

```python
n = 0
while n < 5:
    if n == 3:
        n += 1
        continue
    print(n)
    n += 1
```

Les boucles `while` s'exécutent tant que leur condition reste truthy ; `continue` saute directement à la prochaine vérification de condition de l'itération, et `break` sort entièrement de la boucle. Il n'y a pas non plus de `n++` — Python n'a pas d'opérateurs d'incrémentation/décrémentation, seulement `n += 1`.

Une fonctionnalité véritablement inhabituelle : les boucles `for` et `while` peuvent toutes deux avoir une clause `else`, qui ne s'exécute que si la boucle s'est terminée normalement — c'est-à-dire qu'elle n'a *pas* été arrêtée par un `break`.

```python
for i in range(2, 10):
    if i % 7 == 0:
        print("found a multiple of 7:", i)
        break
else:
    print("no multiples of 7 found")
```

Lisez `for...else` comme « si nous ne sommes jamais sortis de cette boucle avec break, alors... » — c'est le plus utile pour les boucles de recherche où `break` signifie « trouvé » et où tomber jusqu'à `else` signifie « tout cherché, rien trouvé ».
