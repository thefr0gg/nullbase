Go a trois types composites intégrés qu'il vaut la peine de bien
comprendre : les tableaux, les slices, et les maps. Les slices sont ce que
vous utiliserez presque tout le temps — les tableaux existent surtout comme
la chose sur laquelle les slices sont construites.

## Tableaux

Un tableau a une longueur fixe qui fait partie de son type : `[3]int` et
`[5]int` sont des types différents et ne peuvent pas être assignés l'un à
l'autre.

```go
var scores [3]int
scores[0] = 90
scores[1] = 85
scores[2] = 78
fmt.Println(scores) // [90 85 78]

primes := [5]int{2, 3, 5, 7, 11}
```

Parce que la taille est fixe et connue à la compilation, les tableaux sont
utilisés directement par valeur : assigner un tableau à un autre copie
chaque élément.

## Slices

Un slice est une vue sur un tableau sous-jacent : un pointeur, une
longueur, et une capacité. Les slices sont ce vers quoi vous vous tournez
presque toujours à la place des tableaux, parce qu'ils peuvent grandir.

```go
nums := []int{1, 2, 3}
nums = append(nums, 4)
fmt.Println(nums) // [1 2 3 4]
```

`make` crée un slice avec une longueur donnée (et optionnellement une
capacité) :

```go
buf := make([]int, 3)    // [0 0 0]
buf2 := make([]int, 0, 10) // longueur 0, capacité 10
```

Découper un slice existant (`s[low:high]`) ne **copie pas** — le nouveau
slice partage le même tableau sous-jacent que l'original. Modifier via l'un
est visible via l'autre, jusqu'à ce qu'un `append` force une réallocation :

```go
a := []int{1, 2, 3, 4, 5}
b := a[1:3] // [2 3], partage le tableau support de a
b[0] = 99
fmt.Println(a) // [1 99 3 4 5] — a a aussi changé
```

Cet aliasing est l'une des sources de surprise les plus courantes pour les
personnes venant de langages où découper copie toujours. Quand vous avez
besoin d'une copie indépendante, utilisez la fonction intégrée `copy` :

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
copy(dst, src)
```

## Maps

Une map est la table de hachage intégrée de Go, déclarée avec
`map[KeyType]ValueType` :

```go
ages := map[string]int{
	"ada":  36,
	"grace": 85,
}

ages["linus"] = 55
fmt.Println(ages["ada"]) // 36

value, ok := ages["missing"]
fmt.Println(value, ok) // 0 false — la valeur zéro, et ok signale l'absence
```

Supprimer une clé utilise la fonction intégrée `delete` :

```go
delete(ages, "grace")
```

Itérer une map avec `range` visite les entrées dans un **ordre aléatoire**
par conception — Go randomise délibérément l'ordre d'itération pour
empêcher du code de dépendre accidentellement de celui-ci. Triez vous-même
les clés si vous avez besoin d'un ordre stable.
