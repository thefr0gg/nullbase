Les fonctions en Go sont déclarées avec `func`, et le type de retour vient
après la liste de paramètres, pas avant le nom :

```go
func add(a int, b int) int {
	return a + b
}
```

Des paramètres consécutifs du même type peuvent partager une seule
annotation de type :

```go
func add(a, b int) int {
	return a + b
}
```

## Valeurs de retour multiples

C'est l'une des fonctionnalités les plus distinctives de Go, et elle est
utilisée partout dans la bibliothèque standard. Une fonction peut renvoyer
plus d'une valeur, séparées par des virgules :

```go
func divide(a, b int) (int, int) {
	quotient := a / b
	remainder := a % b
	return quotient, remainder
}

func main() {
	q, r := divide(17, 5)
	fmt.Println(q, r) // 3 2
}
```

L'usage le plus courant est d'associer un résultat à une erreur ou un
indicateur « ok », ce qui est la façon dont Go remplace les exceptions et
l'ambiguïté des retours nullables en un seul idiome :

```go
func lookup(m map[string]int, key string) (int, bool) {
	value, ok := m[key]
	return value, ok
}

func main() {
	scores := map[string]int{"ada": 100}
	if value, ok := lookup(scores, "ada"); ok {
		fmt.Println("score:", value)
	}
}
```

Si vous n'avez pas besoin d'une des valeurs de retour, ignorez-la avec `_` :

```go
_, remainder := divide(17, 5)
```

## Valeurs de retour nommées

Les valeurs de retour peuvent être nommées dans la signature. Un `return`
nu renvoie alors leurs valeurs actuelles — utile pour de courtes fonctions,
mais facile à mal utiliser jusqu'à produire du code illisible si on en
abuse :

```go
func split(sum int) (x, y int) {
	x = sum * 4 / 9
	y = sum - x
	return // returns x, y
}
```

## Paramètres variadiques

Un paramètre préfixé de `...` accepte n'importe quel nombre d'arguments,
rassemblés dans un slice à l'intérieur de la fonction :

```go
func sum(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

func main() {
	fmt.Println(sum(1, 2, 3))    // 6
	fmt.Println(sum())            // 0
}
```

## Les fonctions comme valeurs

Les fonctions sont des valeurs de première classe en Go — elles peuvent
être assignées à des variables, passées comme arguments, et renvoyées par
d'autres fonctions :

```go
func makeMultiplier(factor int) func(int) int {
	return func(n int) int {
		return n * factor
	}
}

func main() {
	double := makeMultiplier(2)
	fmt.Println(double(21)) // 42
}
```
