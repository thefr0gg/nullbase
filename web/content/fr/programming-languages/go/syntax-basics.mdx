Go est statiquement typé : chaque variable a un type fixe connu à la
compilation. À la différence du C cependant, Go vous laisse généralement
omettre le type — le compilateur l'infère à partir de la valeur que vous
assignez.

## Déclarer des variables

La forme verbeuse utilise `var` :

```go
var name string = "Ada"
var age int = 36
var isAdmin bool = false
```

Vous pouvez omettre le type quand la valeur le rend évident :

```go
var name = "Ada"
var age = 36
```

Mais à l'intérieur d'un corps de fonction, la forme idiomatique est `:=`, la
déclaration courte de variable. Elle déclare et initialise en une seule
étape, et ne fonctionne que pour de nouvelles variables à l'intérieur d'une
fonction (pas au niveau du package) :

```go
func main() {
	name := "Ada"
	age := 36
	isAdmin := false
	fmt.Println(name, age, isAdmin)
}
```

`var` et `:=` ne sont pas interchangeables dans tous les contextes : `var`
peut apparaître au niveau du package et permet de déclarer une variable sans
valeur initiale, tandis que `:=` exige au moins une nouvelle variable sur le
côté gauche et ne peut apparaître qu'à l'intérieur d'une fonction.

## Valeurs zéro

Go n'a pas de notion de variable non initialisée. Chaque type a une
**valeur zéro** qu'une variable reçoit automatiquement si elle est déclarée
sans initialiseur :

```go
var count int     // 0
var price float64 // 0.0
var label string  // "" (chaîne vide)
var ready bool    // false
var list []int    // nil (un slice nil, sûr à lire)
```

Cela élimine toute une classe de bugs de « variable non initialisée » qui
existent dans des langages comme le C.

## Types de base

Les types intégrés de Go incluent :

| Catégorie | Types |
|---|---|
| Entiers | `int`, `int8`, `int16`, `int32`, `int64`, et les variantes non signées `uint*` |
| Nombres à virgule flottante | `float32`, `float64` |
| Texte | `string`, `rune` (un point de code Unicode), `byte` (un alias pour `uint8`) |
| Autres | `bool`, `complex64`, `complex128` |

`int` est le type entier généraliste et fait 64 bits sur pratiquement toute
plate-forme moderne ; ne réservez un type dimensionné comme `int32` que
lorsque vous avez besoin d'une largeur spécifique (formats binaires,
interopérabilité).

## Constantes

`const` déclare une constante de compilation. Les constantes ne peuvent pas
utiliser `:=` et doivent avoir une valeur connue à la compilation :

```go
const MaxRetries = 3
const Pi = 3.14159

func main() {
	fmt.Println("Retrying up to", MaxRetries, "times")
}
```
