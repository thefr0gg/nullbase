Go (aussi appelé Golang) est un langage compilé et statiquement typé créé
chez Google en 2009 par Robert Griesemer, Rob Pike et Ken Thompson. Il a été
conçu comme une réaction à la complexité des grandes bases de code C++ : une
compilation rapide, une spécification de langage réduite, un ramasse-miettes
(garbage collector), et des primitives de concurrence intégrées directement
dans le langage plutôt qu'ajoutées comme une bibliothèque.

Go compile directement vers un unique binaire statique — pas de runtime à
installer, pas de machine virtuelle, pas d'arbre de dépendances à livrer avec
votre programme. Cette propriété, combinée à une bibliothèque standard livrée
avec tout le nécessaire (serveurs HTTP, encodage JSON, cryptographie), en a
fait le choix par défaut pour une énorme quantité de logiciels
d'infrastructure modernes : Docker, Kubernetes, Terraform, et les outils
d'edge de Cloudflare eux-mêmes sont tous écrits en Go.

## Ce qui rend Go distinctif

- **Goroutines et channels.** La concurrence est une fonctionnalité de
  première classe du langage, pas une bibliothèque. Démarrer une unité de
  travail concurrente tient en un mot-clé : `go`.
- **Gestion explicite des erreurs.** Go n'a pas d'exceptions. Les fonctions
  qui peuvent échouer renvoient une valeur `error` comme une valeur de retour
  ordinaire, et les appelants la vérifient immédiatement.
- **Pas d'héritage.** Il n'y a pas de classes. Le comportement est composé
  par embarquement de `struct` et satisfait implicitement par des
  `interface` — un type ne déclare jamais « j'implémente X », il le fait,
  tout simplement.
- **Formatage normatif.** `gofmt` fait partie de la chaîne d'outils et
  formate chaque fichier `.go` de la même façon. Les bases de code Go n'ont
  pas de débats de style sur le placement des accolades.
- **Builds rapides et simples.** `go build` produit un unique binaire natif
  sans dépendance runtime externe.

Voici un programme Go minimal et complet :

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, nullbase!")
}
```

Chaque programme Go exécutable a un `package main` et une fonction `main`
comme point d'entrée — il n'y a aucune ambiguïté sur l'endroit où l'exécution
commence, contrairement aux langages de script où les instructions de
premier niveau s'exécutent dans l'ordre du fichier.

## Quand se tourner vers Go

Go brille pour les services réseau, les outils en ligne de commande, et tout
ce pour quoi vous voulez un unique binaire déployable et des performances
prévisibles sans avoir à ajuster manuellement la gestion mémoire. Il est
moins adapté aux domaines qui reposent sur une abstraction fortement basée
sur les génériques ou le calcul numérique avec une riche surcharge
d'opérateurs, bien que les génériques (ajoutés dans Go 1.18) aient comblé
une partie de cet écart.
