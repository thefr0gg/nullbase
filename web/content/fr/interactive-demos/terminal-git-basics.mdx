Ceci est un véritable interpréteur de commandes (pas une vidéo ni un script) qui s'exécute sur un système de fichiers en mémoire — rien ici ne touche un vrai shell ni un vrai dépôt Git. Essayez `pwd`, `ls`, `cat README.md`, puis faites l'exercice ci-dessous avec `git status`, `git add` et `git commit`.
