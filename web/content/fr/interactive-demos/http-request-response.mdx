Une requête d'<GlossaryTerm id="api">API</GlossaryTerm> n'est que du texte transmis sur une connexion — une méthode, un chemin, une version, des en-têtes et (parfois) un corps. Choisissez une méthode et un chemin ci-dessous, ajustez les en-têtes si vous le souhaitez, puis envoyez. Rien ici ne quitte votre navigateur : un petit ensemble de routes est simulé côté client (voir `web/components/interactive/mock-api.ts`), mais la requête construite est exactement ce qu'un vrai client enverrait.

<RequestPlayground protocol="http" defaultTarget="/api/users/1" defaultMethod="GET" />

Essayez de passer la méthode à `POST` vers `/api/users` avec un corps JSON, ou demandez `/api/rate-limited` plusieurs fois de suite pour voir un `429` simulé se déclencher.
