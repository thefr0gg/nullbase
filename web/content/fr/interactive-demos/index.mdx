Les pages de référence de Nullbase ne se limitent pas à du texte et des blocs de code statiques — la plupart des widgets interactifs du site reposent sur un petit ensemble réutilisable de primitives (voir `web/components/interactive/`). Cette section en fait le tour concret : chaque page ci-dessous intègre une primitive avec des données réelles et exécutables, pour que vous voyiez exactement ce qu'un auteur écrit pour l'obtenir.

## Diagrammes et flux

- **[Anatomie et cycle de vie d'une URL](/fr/interactive-demos/url-anatomy-and-lifecycle)** — décomposer une URL en ses parties, puis suivre ce qui lui arrive.
- **[Sous le capot : une requête d'URL](/fr/interactive-demos/under-the-hood-url-request)** — une divulgation progressive qui cache un cycle de requête complet derrière un seul bouton.
- **[Cycle de vie d'une requête HTTP (machine à états)](/fr/interactive-demos/http-state-machine)** — des états et des transitions cliquables plutôt qu'un diagramme statique.

## Protocoles et comparaisons

- **[Requête et réponse HTTP](/fr/interactive-demos/http-request-response)** — construisez une vraie requête, obtenez une réponse simulée.
- **[TCP contre UDP](/fr/interactive-demos/tcp-vs-udp)** — une comparaison à développer au clic, plus un curseur montrant ce que contrôle réellement la taille de fenêtre TCP.

## Code et données

- **[Bac à sable de code JavaScript](/fr/interactive-demos/js-code-playground)** — du JavaScript modifiable et exécutable dans un iframe isolé (sandbox).
- **[SQL interactif](/fr/interactive-demos/sql-interactive)** — une vraie base SQLite, compilée en WebAssembly, exécutée dans votre navigateur.

## Pratique

- **[Devinez la sortie](/fr/interactive-demos/predict-the-output)** — un court quiz JavaScript avec une explication.
- **[Ordonnez la requête](/fr/interactive-demos/ordering-exercise)** — glissez ou réordonnez les parties d'une requête HTTP dans le bon ordre.
- **[Terminal : bases de Git](/fr/interactive-demos/terminal-git-basics)** — un shell simulé avec un petit exercice de commandes `git`.
