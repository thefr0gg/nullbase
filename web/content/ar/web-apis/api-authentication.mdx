## جرّبها

يتطلب `/api/profile` في واجهة برمجة التطبيقات الوهمية لهذا الموقع ترويسة `Authorization` — أرسل الطلب بدونها، ثم أضف `Authorization: Bearer demo-token` وأرسل مجدداً.

## رموز Bearer وJWT

**JWT** (JSON Web Token) هو الشكل الأكثر شيوعاً الذي يتخذه رمز Bearer: ثلاثة أجزاء base64url — ترويسة، وحمولة (ادعاءات مثل معرّف المستخدم ووقت انتهاء الصلاحية)، وتوقيع — مفصولة بنقاط. يتحقق الخادم من التوقيع ليثق بالادعاءات دون الحاجة لعملية بحث في قاعدة البيانات مع كل طلب، وهذا سبب شيوع JWT تحديداً لواجهات برمجة التطبيقات عديمة الحالة.

```
eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiI0MiIsImV4cCI6MTcwMDAwMDAwMH0.4f8s...
       header                    payload                  signature
```
