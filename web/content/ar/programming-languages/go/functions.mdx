تُصرَّح الدوال في Go بـ`func`، ويأتي نوع الإرجاع بعد قائمة المعاملات، وليس
قبل الاسم:

```go
func add(a int, b int) int {
	return a + b
}
```

يمكن للمعاملات المتتالية من نفس النوع أن تشترك في تعليق نوع واحد:

```go
func add(a, b int) int {
	return a + b
}
```

## قيم إرجاع متعددة

هذه إحدى أبرز ميزات Go المميّزة، وتُستخدم في كل مكان بالمكتبة القياسية.
يمكن لدالة أن تُعيد أكثر من قيمة، مفصولة بفواصل:

```go
func divide(a, b int) (int, int) {
	quotient := a / b
	remainder := a % b
	return quotient, remainder
}

func main() {
	q, r := divide(17, 5)
	fmt.Println(q, r) // 3 2
}
```

الاستخدام الأكثر شيوعاً هو إقران نتيجة بخطأ أو بعلامة "ok"، وهذه هي طريقة
Go لاستبدال الاستثناءات وغموض القيم القابلة للإرجاع الفارغ في اصطلاح واحد:

```go
func lookup(m map[string]int, key string) (int, bool) {
	value, ok := m[key]
	return value, ok
}

func main() {
	scores := map[string]int{"ada": 100}
	if value, ok := lookup(scores, "ada"); ok {
		fmt.Println("score:", value)
	}
}
```

إذا لم تحتج إحدى قيم الإرجاع، تجاهلها بـ`_`:

```go
_, remainder := divide(17, 5)
```

## قيم الإرجاع المسمّاة

يمكن تسمية قيم الإرجاع في التوقيع. تُعيد عبارة `return` مجردة بعدها قيمها
الحالية — مفيدة للدوال القصيرة، لكن يسهل إساءة استخدامها لتنتج كوداً صعب
القراءة إذا أُفرِط فيها:

```go
func split(sum int) (x, y int) {
	x = sum * 4 / 9
	y = sum - x
	return // يُعيد x, y
}
```

## المعاملات متغيرة العدد

معامل مسبوق بـ`...` يقبل أي عدد من الوسائط، تُجمَع في شريحة داخل الدالة:

```go
func sum(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

func main() {
	fmt.Println(sum(1, 2, 3))    // 6
	fmt.Println(sum())            // 0
}
```

## الدوال كقيم

الدوال قيم من الدرجة الأولى في Go — يمكن إسنادها إلى متغيرات، وتمريرها
كوسائط، وإعادتها من دوال أخرى:

```go
func makeMultiplier(factor int) func(int) int {
	return func(n int) int {
		return n * factor
	}
}

func main() {
	double := makeMultiplier(2)
	fmt.Println(double(21)) // 42
}
```
