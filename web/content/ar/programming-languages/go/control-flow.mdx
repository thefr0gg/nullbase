تُبقي Go التحكم بمسار التنفيذ بسيطاً عن قصد. لا يوجد `while`، ولا
`do-while`، ولا عامل شرطي ثلاثي — `for` تغطي كل حاجات التكرار، و`switch`
أكثر مرونة منها في معظم لغات عائلة C.

## if / else

لا تحتاج الشروط أبداً إلى أقواس، لكن القوس المفتوح يجب أن يكون في نفس سطر
`if` — قواعد Go النحوية تعتمد على إدراج الفاصلة المنقوطة التلقائي، وقوس
في سطر منفصل يكسر ذلك.

```go
func classify(score int) string {
	if score >= 90 {
		return "A"
	} else if score >= 80 {
		return "B"
	} else {
		return "F"
	}
}
```

يقبل `if` أيضاً عبارة تهيئة، محصورة في نطاق سلسلة `if`/`else` — تُستخدم
عادةً للتحقق من خطأ فور إنتاجه:

```go
if value, ok := lookup("key"); ok {
	fmt.Println("found:", value)
} else {
	fmt.Println("not found")
}
// value وok غير مرئيين هنا — يوجدان فقط داخل if/else
```

## for — الحلقة الوحيدة في Go

تملك Go كلمة مفتاحية واحدة للتكرار تغطي ما تقسّمه لغات أخرى إلى `for`
و`while` وحلقات لا نهائية.

الصيغة الكلاسيكية ثلاثية الأجزاء:

```go
for i := 0; i < 5; i++ {
	fmt.Println(i)
}
```

الشرط فقط — هذه هي `while` الخاصة بـGo:

```go
n := 1
for n < 100 {
	n *= 2
}
```

بلا شرط إطلاقاً — حلقة لا نهائية، تُقرَن عادةً بـ`break`:

```go
count := 0
for {
	count++
	if count == 3 {
		break
	}
}
```

`for ... range` تتكرر عبر الشرائح، والمصفوفات، والخرائط، والسلاسل النصية،
والقنوات:

```go
names := []string{"Ada", "Grace", "Linus"}
for i, name := range names {
	fmt.Println(i, name)
}
```

## switch

لا تنساب `switch` في Go افتراضياً إلى الحالة التالية (عكس C/Java)، لذا
نادراً ما تحتاج `break`. يمكن للحالات أيضاً أن تسرد قيماً متعددة أو تحذف
تعبير switch كلياً لتعمل كسلسلة if/else أنظف:

```go
func describe(n int) string {
	switch {
	case n < 0:
		return "negative"
	case n == 0:
		return "zero"
	case n%2 == 0:
		return "positive even"
	default:
		return "positive odd"
	}
}
```

استخدم `fallthrough` صراحةً في المناسبات النادرة التي تريد فيها تشغيل
الحالة التالية على أي حال:

```go
switch day := "sat"; day {
case "sat", "sun":
	fmt.Println("weekend")
default:
	fmt.Println("weekday")
}
```
