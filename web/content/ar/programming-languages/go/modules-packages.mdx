تنظّم Go الكود على مستويين: تجمع **الحزم** (packages) ملفات مصدر ذات صلة
داخل مجلد، وتجمع **الوحدات** (modules) الحزم في وحدة مُصدَرة وقابلة
للتوزيع بقائمة اعتماديات خاصة بها.

## الحزم

يبدأ كل ملف `.go` بتصريح `package`. يجب أن تُصرِّح كل الملفات في نفس
المجلد بنفس اسم الحزمة، ويصبح ذلك الاسم مساحة الأسماء التي يستوردها كود
آخر:

```go
package geometry

func Area(width, height float64) float64 {
	return width * height
}
```

يستوردها ملف آخر في مكان مختلف عبر مسار وحدته ويستدعي الاسم المُصدَّر
(بحرف كبير):

```go
package main

import (
	"fmt"

	"example.com/myapp/geometry"
)

func main() {
	fmt.Println(geometry.Area(3, 4)) // 12
}
```

يمكن لـ`import` جلب حزم متعددة دفعة واحدة داخل أقواس، كما في المثال
أعلاه. تُشحَن المكتبة القياسية كحزم عادية تستوردها بنفس الطريقة —
`"fmt"`, `"strings"`, `"net/http"` — دون خطوة تثبيت منفصلة.

## go.mod ووحدات Go

**الوحدة** (module) هي وحدة الإصدار وإدارة الاعتماديات — عادةً مستودع
Git واحد. ينشئ `go mod init` ملف `go.mod` يُصرِّح عن مسار الوحدة وإصدار
Go الذي تستهدفه:

```bash
go mod init example.com/myapp
```

```go
module example.com/myapp

go 1.22
```

إضافة استيراد لاعتمادية حقيقية وتشغيل `go build` (أو `go mod tidy`) يجلبها
ويسجّل إصدارها الدقيق في `go.mod`، مع مجموع اختباري (checksum) تشفيري لكل
اعتمادية في `go.sum`:

```go
module example.com/myapp

go 1.22

require github.com/google/uuid v1.6.0
```

`go.sum` ليس مقصوداً للتعديل اليدوي — إنه ملف قفل تحافظ عليه Go لضمان
بناءات قابلة لإعادة الإنتاج: نفس `go.mod` يُحلَّل دائماً إلى كود اعتماديات
مطابق تماماً (byte-identical).

## أوامر وحدات مفيدة

```bash
go mod init example.com/myapp   # بدء وحدة جديدة
go mod tidy                      # إضافة الاعتماديات الناقصة / إزالة غير المستخدَمة
go get github.com/some/pkg@v1.2.0  # إضافة أو ترقية اعتمادية واحدة
go build ./...                    # بناء كل حزمة في الوحدة
```

## الحزم الداخلية

يقيّد مجلد باسم `internal` ما يمكنه استيراده: الحزم تحت `internal/` قابلة
للاستيراد فقط من كود داخل شجرة الوحدة المتفرعة من والد `internal`. هذه
آلية Go المدمجة لتمييز الكود كـ"تفصيل تنفيذي، ليس جزءاً من واجهة برمجة
تطبيقاتك العامة"، يفرضها المصرّف وليس العُرف وحده.
