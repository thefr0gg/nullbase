التزامن هو السمة المميّزة لـGo. بدلاً من كشف خيوط نظام التشغيل الخام
والأقفال كأداة رئيسية، تمنحك Go **الگوروتينات (goroutines)** — وحدات
تنفيذ متزامن خفيفة للغاية تديرها بيئة تشغيل Go — و**القنوات (channels)**،
أنابيب مكتوبة (typed) تتواصل الگوروتينات عبرها بأمان. الفلسفة، المستعارة
من نموذج CSP لتوني هور، تُلخَّص في سطر من توثيق Go: "لا تتواصل بمشاركة
الذاكرة؛ بل شارك الذاكرة بالتواصل."

## الگوروتينات

بدء گوروتين يحتاج كلمة مفتاحية واحدة، `go`، توضع قبل استدعاء دالة. يعود
الاستدعاء فوراً، وتعمل الدالة بشكل متزامن:

```go
func sayHello() {
	fmt.Println("hello from a goroutine")
}

func main() {
	go sayHello()
	time.Sleep(100 * time.Millisecond) // إعطاؤها فرصة للعمل
	fmt.Println("main done")
}
```

الگوروتينات رخيصة — بضعة كيلوبايتات من المكدس تنمو حسب الحاجة، مقارنة
بميغابايتات لخيط نظام تشغيل — لذا من الطبيعي أن يُشغِّل برنامج Go آلاف
منها في آنٍ واحد. `time.Sleep` أعلاه طريقة خام للانتظار؛ الكود الحقيقي
يستخدم القنوات أو `sync.WaitGroup` بدلاً من ذلك، لأن النوم لمدة ثابتة
حالة تسابق (race condition) في انتظار الحدوث.

## القنوات

القناة موصل مكتوب ترسل قيماً إليه وتستقبل قيماً منه، تُنشأ بـ`make`:

```go
func main() {
	ch := make(chan string)

	go func() {
		ch <- "result from goroutine" // إرسال
	}()

	msg := <-ch // استقبال — يُحجَب حتى وصول قيمة
	fmt.Println(msg)
}
```

الإرسال والاستقبال على قناة غير مُخزَّنة (unbuffered) يُحجَبان كلاهما حتى
يصبح الطرف الآخر جاهزاً، وهذا ما يجعل القنوات مفيدة للتزامن، وليس فقط لنقل
البيانات: الاستقبال أعلاه لا يكتمل إلا بعد أن يرسل الگوروتين قيمته فعلياً،
مما يمنحك تسليماً آمناً بلا قفل صريح.

## القنوات المُخزَّنة والإغلاق

يُنشئ `make(chan T, n)` قناة بمساحة لـ`n` قيمة قبل أن يُحجَب إرسال. إغلاق
قناة بـ`close` يشير إلى عدم وصول مزيد من القيم، وهو ما تستخدمه `range`
لمعرفة متى تتوقف:

```go
func main() {
	results := make(chan int, 3)

	go func() {
		for i := 1; i <= 3; i++ {
			results <- i * i
		}
		close(results)
	}()

	for value := range results {
		fmt.Println(value) // 1، ثم 4، ثم 9
	}
}
```

## select

تنتظر `select` عمليات قناة متعددة في آنٍ واحد وتُتابع بأيها يصبح جاهزاً
أولاً — نظير التزامن لـ`switch` على القنوات:

```go
func main() {
	c1 := make(chan string)
	c2 := make(chan string)

	go func() { c1 <- "from c1" }()
	go func() { c2 <- "from c2" }()

	for i := 0; i < 2; i++ {
		select {
		case msg1 := <-c1:
			fmt.Println(msg1)
		case msg2 := <-c2:
			fmt.Println(msg2)
		}
	}
}
```
