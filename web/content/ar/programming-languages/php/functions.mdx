تُعرَّف الدوال في PHP بالكلمة المفتاحية `function` ويمكن أن تظهر على المستوى الأعلى (لا تشترط PHP أن يعيش الكود داخل فئة). منذ PHP 7، يمكن للوسائط وقيم الإرجاع أن تحمل تلميحات نوع، ينفّذها المحرّك أثناء التشغيل.

## التعريف الأساسي

```php
<?php

function greet(string $name): string {
    return "Hello, $name!";
}

echo greet("Ada") . "\n";
```

## الوسائط الافتراضية

يمكن لأي وسيطة أن تحمل قيمة افتراضية، ما يتيح للمستدعين حذفها. يجب أن تأتي الوسائط الافتراضية بعد الوسائط بلا قيم افتراضية:

```php
<?php

function makeGreeting(string $name, string $greeting = "Hello"): string {
    return "$greeting, $name!";
}

echo makeGreeting("Grace") . "\n";              // Hello, Grace!
echo makeGreeting("Grace", "Welcome") . "\n";    // Welcome, Grace!
```

## الوسائط المسمّاة

أضافت PHP 8.0 الوسائط المسمّاة، التي تتيح للمستدعي تخطي القيم الافتراضية السابقة دون تكرارها موضعياً:

```php
<?php

function connect(string $host, int $port = 5432, bool $ssl = false): string {
    return ($ssl ? "ssl://" : "") . "$host:$port";
}

echo connect("db.internal", ssl: true) . "\n"; // ssl://db.internal:5432
```

## الدوال متغيرة الوسائط

إضافة `...` قبل الوسيطة الأخيرة يجمع أي عدد من الوسائط اللاحقة في مصفوفة — مكافئ PHP لـ `*args`:

```php
<?php

function sum(int ...$numbers): int {
    $total = 0;
    foreach ($numbers as $n) {
        $total += $n;
    }
    return $total;
}

echo sum(1, 2, 3, 4) . "\n"; // 10
echo sum() . "\n";            // 0
```

يفعل عامل النشر `...` العكس عند استدعاء دالة: فهو يفكّك مصفوفة إلى وسائط موضعية.

```php
<?php

$values = [3, 6, 9];
echo sum(...$values) . "\n"; // 18
```

## التمرير بالمرجع

افتراضياً، تُمرَّر الوسائط بالقيمة — تحصل الدالة على نسخة. إضافة `&` قبل وسيطة تمرّرها بالمرجع بدلاً من ذلك، ما يتيح للدالة تغيير متغير المستدعي:

```php
<?php

function increment(int &$n): void {
    $n++;
}

$counter = 10;
increment($counter);
echo $counter . "\n"; // 11
```

## الدوال المجهولة ودوال السهم

تدعم PHP الإغلاقات عبر `function` (مع جملة `use` صريحة لالتقاط المتغيرات الخارجية) وصياغة `fn` الأكثر إيجازاً لدوال السهم، التي تلتقط تلقائياً بالقيمة:

```php
<?php

$multiplier = 3;

$classic = function (int $n) use ($multiplier): int {
    return $n * $multiplier;
};

$arrow = fn(int $n): int => $n * $multiplier;

echo $classic(5) . " " . $arrow(5) . "\n"; // 15 15
```
