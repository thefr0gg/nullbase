سيبدو التحكم بمسار التنفيذ في PHP مألوفاً فوراً إن كنت تعرف أي لغة من عائلة C، مع بضع إضافات خاصة بـ PHP تستحق المعرفة: `match` (أُضيفت في PHP 8.0) وبنية نقطتين بديلة مصمَّمة لخلط PHP بقوالب HTML.

## if / elseif / else

لاحظ الإملاء: `elseif` (كلمة واحدة)، وليس `else if`، رغم أن PHP تقبل كليهما — `elseif` هو الأسلوب المتعارف عليه في مشاريع PHP.

```php
<?php

function classify(int $score): string {
    if ($score >= 90) {
        return "A";
    } elseif ($score >= 80) {
        return "B";
    } else {
        return "F";
    }
}

echo classify(85) . "\n"; // B
```

## الحلقات

تملك PHP `while`، و`do...while`، و`for`، و`foreach` — وforeach هي التي ستلجأ إليها باستمرار، لأنها تعمل مباشرة على المصفوفات:

```php
<?php

$fruits = ["apple", "banana", "cherry"];

foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit\n";
}
```

تتصرف `for` و`while` تماماً كما في C:

```php
<?php

for ($i = 0; $i < 3; $i++) {
    echo "count: $i\n";
}

$n = 1;
while ($n < 100) {
    $n *= 2;
}
echo $n . "\n"; // 128
```

## switch

تستخدم `switch` في PHP **مقارنة فضفاضة** (`==`) افتراضياً وتستمر بالتنفيذ (تسقط للأسفل) ما لم تستخدم `break` — الفخ الكلاسيكي بأسلوب C:

```php
<?php

$role = "editor";

switch ($role) {
    case "admin":
        echo "full access\n";
        break;
    case "editor":
    case "author":
        echo "can publish\n";
        break;
    default:
        echo "read only\n";
}
```

## match — بديل أكثر صرامة قائم على التعبيرات

تصلح `match` (PHP 8.0+) أكبر خطأين شائعين في switch: فهي تقارن بدلالة صارمة (`===`)، ولا يوجد فيها سقوط للأسفل — كل ذراع تعبير واحد، و`match` نفسها تُقيَّم إلى قيمة.

```php
<?php

$role = "editor";

$access = match ($role) {
    "admin" => "full access",
    "editor", "author" => "can publish",
    default => "read only",
};

echo $access . "\n"; // can publish
```

بخلاف `switch`، فإن قيمة غير مطابَقة بلا ذراع `default` تطلق `UnhandledMatchError` بدلاً من عدم فعل شيء بصمت — تحسين أمان متعمَّد.

## بنية النقطتين البديلة

داخل القوالب التي تخلط PHP وHTML، توفّر PHP بنية قائمة على النقطتين لـ `if`، و`foreach`، و`for`، و`while` تتجنب جداراً من الأقواس المعقوفة:

```php
<?php $items = ["tea", "coffee"]; ?>
<ul>
<?php foreach ($items as $item): ?>
    <li><?= $item ?></li>
<?php endforeach; ?>
</ul>
```

`<?= $item ?>` هو اختصار لـ `<?php echo $item; ?>` وشائع في ملفات القوالب لهذا السبب بالضبط.
