تملك PHP ميزات كائنية التوجه منذ PHP 4، ونموذج فئات حديث وتقليدي إلى حد ما منذ PHP 5 — وراثة أحادية، وواجهات، ومحدِّدات رؤية، وفئات مجردة. منذ PHP 8، اكتسب نموذج الكائن ترقية خصائص المُنشئ (constructor property promotion)، والخصائص للقراءة فقط، والتعدادات (enums)، ما ضيّق الفجوة مع اللغات الأحدث.

## الفئات

```php
<?php

class User {
    public function __construct(
        public string $name,
        public string $role = "member",
    ) {}

    public function describe(): string {
        return "{$this->name} ({$this->role})";
    }
}

$user = new User("Ada", "admin");
echo $user->describe() . "\n"; // Ada (admin)
```

يستخدم ذلك المُنشئ **ترقية خصائص المُنشئ** (PHP 8.0+): كتابة محدِّد رؤية مباشرة على وسيطة مُنشئ تعرّف الخاصية وتسندها في آن واحد، لتحل محل ما كان يستغرق سابقاً ثلاثة أسطر (`public string $name;` بالإضافة إلى وسيطة بالإضافة إلى إسناد `$this->name = $name;`) بسطر واحد.

## الوراثة

تدعم فئات PHP الوراثة الأحادية عبر `extends`. تستدعي `parent::` تنفيذ الفئة الأصل صراحة:

```php
<?php

class Shape {
    public function area(): float {
        return 0.0;
    }
}

class Circle extends Shape {
    public function __construct(private float $radius) {}

    public function area(): float {
        return M_PI * $this->radius ** 2;
    }
}

$circle = new Circle(2.0);
echo round($circle->area(), 2) . "\n"; // 12.57
```

## الواجهات

تعلن `interface` عن عقد بلا تنفيذ. يمكن لفئة تنفيذ أي عدد من الواجهات، بخلاف الفئة الواحدة التي يمكنها التوسّع منها:

```php
<?php

interface Comparable {
    public function compareTo(self $other): int;
}

class Money implements Comparable {
    public function __construct(public int $cents) {}

    public function compareTo(self $other): int {
        return $this->cents <=> $other->cents;
    }
}

$a = new Money(500);
$b = new Money(300);
echo $a->compareTo($b) . "\n"; // 1
```

## السمات (traits) — آلية الخلط الخاصة بـ PHP

هذه هي القطعة الخاصة بـ PHP: لا تسمح PHP بالوراثة المتعددة، لكن يمكن لفئة أن تستخدم `use` مع أي عدد من **السمات** لسحب دوال منفَّذة مباشرة، كما لو أنها نُسخت ولُصقت داخل الفئة. هذه هي كيفية مشاركة PHP سلوكاً ملموساً عبر تسلسلات فئات غير مترابطة بخلاف ذلك.

```php
<?php

trait Loggable {
    public function log(string $message): void {
        echo "[" . static::class . "] $message\n";
    }
}

trait Timestamped {
    private ?string $createdAt = null;

    public function touch(): void {
        $this->createdAt = date("Y-m-d");
    }

    public function createdAt(): ?string {
        return $this->createdAt;
    }
}

class Order {
    use Loggable, Timestamped;
}

$order = new Order();
$order->touch();
$order->log("created on " . $order->createdAt());
```

الفئة التي تستخدم سمتين تعرّفان نفس الدالة يجب أن تحل التعارض صراحة بـ `insteadof`/`as` — لن تختار PHP واحدة بصمت، ما يتجنب غموض "مشكلة الماسة" الكلاسيكية التي تواجهها الوراثة المتعددة في لغات أخرى.
