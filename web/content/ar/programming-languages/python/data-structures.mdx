تملك Python أربعة أنواع أوعية مدمجة في اللغة نفسها، دون الحاجة لأي استيراد، واختيار النوع الصحيح هو غالباً مسألة ما إذا كان الترتيب مهماً، وما إذا كانت المحتويات ستتغير، وما إذا كنت تبحث عن العناصر بالموضع أو بالاسم.

**القائمة (list)** تسلسل مرتّب وقابل للتغيير — الخيار الافتراضي عندما تملك مجموعة من الأشياء قد تكبر أو تصغر أو تُعاد ترتيبها.

```python
numbers = [3, 1, 4, 1, 5, 9]
numbers.append(2)
numbers.sort()
print(numbers)  # [1, 1, 2, 3, 4, 5, 9]
```

**الصف (tuple)** يشبه القائمة لكنه غير قابل للتغيير — بمجرد إنشائه، لا يمكن الإضافة إليه أو إعادة إسناد عنصر فيه. عدم القابلية للتغيير هذا يجعل الصفوف صالحة كمفاتيح قاموس (لا يمكن للقوائم ذلك) ويوضّح النية: يقول الصف "هذه مجموعة صغيرة وثابتة من القيم"، مثل الإحداثيات.

```python
point = (10, 20)  # tuples are immutable
x, y = point       # unpacking works the same as with lists
print(x, y)  # 10 20
```

**القاموس (dict)** يخزّن أزواج مفتاح-قيمة ويبحث عن القيم بالمفتاح بدلاً من الموضع، ما يجعله الخيار الطبيعي لأي شيء يمكن وصفه بخلاف ذلك بأنه "سجلّ بحقول مسمّاة".

```python
user = {"name": "Rae", "age": 29}
user["email"] = "rae@example.com"
for key, value in user.items():
    print(key, value)
```

**المجموعة (set)** تخزّن قيماً فريدة وغير مرتّبة وتتجاهل التكرارات تلقائياً عند الإدراج — مفيدة لاختبارات العضوية (`x in my_set` سريعة) ولإزالة التكرار من مجموعة.

```python
unique_ids = {1, 2, 2, 3, 3, 3}
print(unique_ids)  # {1, 2, 3}
```

الشيء الوحيد الذي يجب استيعابه بخصوص القوائم (والقواميس، والمجموعات) هو أنها *كائنات* قابلة للتغيير — المتغير الذي يحمل واحدة منها لا يحمل نسخة من محتوياتها، بل مرجعاً إلى نفس القائمة الأساسية التي يشير إليها أيضاً كل من يملك ذلك المتغير.
