تُقرأ جمل الشرط والحلقات في Python قريباً من الإنجليزية العادية، لكن الآلية الكامنة تستحق الدقة، خصوصاً الأجزاء التي تختلف عن لغات عائلة C.

```python
temperature = 72
if temperature > 80:
    print("hot")
elif temperature > 60:
    print("mild")
else:
    print("cold")
```

`elif` هي طريقة Python لكتابة "else if" — لا يوجد زوج كلمات مفتاحية منفصل لـ `else if`، ولا تحتاج الشروط أبداً إلى أقواس محيطة (رغم إمكانية إضافتها). يمكن استخدام أي قيمة كشرط، وليس فقط القيم المنطقية: `0`، و`""`، و`None`، والمجموعات الفارغة (`[]`، `{}`، `()`) كلها "زائفة" (falsy)، وكل شيء آخر "صادق" (truthy)، لذا فإن `if some_list:` طريقة اصطلاحية للتحقق من "هل هذه القائمة غير فارغة" دون مقارنة الأطوال صراحة.

```python
fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(index, fruit)
```

تتكرر حلقة `for` في Python مباشرة على *عناصر* التسلسل — لا يوجد نمط عدّ بأسلوب C مثل `for (i = 0; i < len; i++)`. عندما تكون الحاجة فعلياً إلى الفهرس إلى جانب القيمة، تغلّف `enumerate()` التسلسل لتُنتج أزواج `(index, value)`، وهذه هي الطريقة الاصطلاحية للحصول على الاثنين معاً دون تتبّع عدّاد يدوياً.

```python
n = 0
while n < 5:
    if n == 3:
        n += 1
        continue
    print(n)
    n += 1
```

تُنفَّذ حلقات `while` طالما بقي شرطها صادقاً؛ يقفز `continue` مباشرة إلى فحص شرط التكرار التالي، بينما يخرج `break` من الحلقة تماماً. كما لا يوجد `n++` — لا تملك Python عوامل زيادة/نقصان، فقط `n += 1`.

هناك ميزة غريبة حقاً: يمكن لكل من حلقتي `for` و`while` أن تملكا جملة `else`، تُنفَّذ فقط إذا انتهت الحلقة بشكل طبيعي — أي أنها *لم* تتوقف بسبب `break`.

```python
for i in range(2, 10):
    if i % 7 == 0:
        print("found a multiple of 7:", i)
        break
else:
    print("no multiples of 7 found")
```

اقرأ `for...else` على أنها "إن لم نخرج من هذه الحلقة عبر break، فإذن..." — وهي أكثر فائدة في حلقات البحث حيث يعني `break` "وجدناه"، بينما يعني الوصول إلى `else` "بحثنا في كل شيء ولم نجد شيئاً".
