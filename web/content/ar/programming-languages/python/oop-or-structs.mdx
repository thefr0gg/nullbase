تُعرَّف فئة Python باستخدام `class`، وتبدأ كل فئة تقريباً بدالة `__init__` — المُنشئ (constructor)، الذي يُستدعى تلقائياً عند إنشاء نسخة جديدة — والذي يهيّئ سمات النسخة عبر `self`.

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} says Woof!"

rex = Dog("Rex", "Labrador")
print(rex.bark())  # Rex says Woof!
```

`self` هو النسخة التي استُدعيت الدالة عليها — تمرّرها Python صراحة كأول وسيطة لكل دالة نسخة، بدلاً من جعلها كلمة مفتاحية ضمنية مثل `this` في لغات أخرى. `rex.bark()` هي في الحقيقة `Dog.bark(rex)` تحت الغطاء.

تتيح الوراثة لفئة إعادة استخدام وتوسيع سلوك فئة أخرى. تستدعي الفئة الفرعية `super().__init__(...)` لتشغيل مُنشئ الفئة الأصل قبل إضافة تهيئتها الخاصة، ويمكنها إعادة تعريف أي دالة، بما فيها الدوال التي تعرّفها الفئة الأصل بالفعل.

```python
class Puppy(Dog):
    def __init__(self, name, breed, age_months):
        super().__init__(name, breed)
        self.age_months = age_months

    def bark(self):
        return f"{self.name} says Yip!"

buddy = Puppy("Buddy", "Poodle", 4)
print(buddy.bark())  # Buddy says Yip!
```

دوال "dunder" (ذات الشرطتين السفليتين) هي كيفية ربط الفئة بعوامل Python المدمجة ودوالها بدلاً من الحاجة إلى واجهة برمجية خاصة بها. تتحكم `__repr__` بما تعرضه `print()` وREPL لنسخة ما؛ وتتحكم `__eq__` بما تفعله `==` بين نسختين.

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

p1 = Point(1, 2)
p2 = Point(1, 2)
print(p1 == p2)  # True — because __eq__ compares the coordinates
print(p1)         # Point(1, 2) — because __repr__ formats it
```

بدون `__eq__`، تعود `==` إلى مقارنة الهوية — أي ما إذا كان الاسمان يشيران إلى نفس الكائن بالضبط في الذاكرة — وهذا نادراً ما يكون المطلوب لفئة تشبه القيمة مثل `Point`.
