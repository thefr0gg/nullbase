لا تحتوي Python على أقواس، ولا كلمات مفتاحية مثل `end`، ولا فواصل منقوطة تنهي الجمل — تُحدَّد الكتلة (جسم `if`، أو حلقة، أو دالة) بالكامل عبر مستوى إزاحتها. الإزاحة المتسقة ليست خياراً أسلوبياً يفرضه أداة تدقيق (linter)؛ إنها البنية النحوية الفعلية التي يحلّلها المفسِّر، وخلط علامات التبويب بالمسافات أو الإزاحة غير المتسقة يؤدي إلى `SyntaxError` أو `IndentationError`.

```python
# comments start with a hash and run to the end of the line
count = 10          # int
price = 3.14         # float
name = "Nova"         # str
is_ready = True        # bool
result = None            # NoneType — Python's "no value" singleton

print(type(count), type(name), type(is_ready))
```

المتغيرات في Python ذات كتابة ديناميكية: الاسم لا يصرّح بنوع مسبقاً، بل هو مجرد تسمية تشير إلى آخر قيمة أُسندت إليه، ونوع تلك القيمة هو ما تبلّغ عنه `type()`. إعادة الإسناد لاحقاً بـ `count = "ten"` مسموحة تماماً — يشير المتغير الآن إلى سلسلة نصية بدلاً من عدد صحيح — وهذا مريح للسكربتات السريعة لكنه يعني أن الأخطاء المتعلقة بالأنواع تظهر أثناء التشغيل وليس أثناء الترجمة، ما لم تُضِف تلميحات نوع (type hints) وتشغّل أداة فحص منفصلة مثل `mypy`.

```python
a, b = 1, 2
a, b = b, a  # swap without a temporary variable
print(a, b)  # 2 1
```

يعمل هذا التبديل لأن الطرف الأيمن `b, a` يُقيَّم بالكامل — ببناء زوج مؤقت `(2, 1)` — قبل إعادة إسناد `a` أو `b` في الطرف الأيسر. هذه الآلية نفسها، آلية تفكيك الصفوف (tuple-unpacking)، هي كيف "تُعيد" دوال Python "قيماً متعددة": هي في الحقيقة تُعيد صفاً واحداً يفكّكه المستدعي.

```python
score = 87
message = f"You scored {score} points ({score / 100:.0%})"
print(message)  # You scored 87 points (87%)
```

سلاسل f-string (السلاسل الحرفية المسبوقة بـ `f`) هي الطريقة القياسية لبناء نص منسّق: كل ما بداخل `{}` يُقيَّم كتعبير Python، و`:format_spec` اختياري بعد `:` يتحكم بكيفية عرضه — `.0%` أعلاه يحوّل `0.87` إلى `"87%"`.
