**المزخرف (decorator)** دالة تأخذ دالة وتُعيد دالة جديدة تغلّفها — تُستخدم لإضافة سلوك (تسجيل، توقيت، فحوصات وصول) دون لمس جسم الدالة الأصلية. صياغة `@decorator` فوق `def` هي مجرد اختصار لإعادة إسناد الدالة إلى القيمة التي يُعيدها المزخرف.

```python
def logged(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@logged
def add(a, b):
    return a + b

print(add(2, 3))
# Calling add
# 5
```

`@logged` فوق `def add(...)` يعادل كتابة `add = logged(add)` مباشرة بعد تعريفها — كل استدعاء لـ `add` الآن يستدعي فعلياً `wrapper`، التي تطبع، ثم تستدعي `add` الأصلية عبر الإغلاق على `func`، وتُعيد نتيجتها. هذه نفس آلية الإغلاق المشروحة في [الدوال](/ar/programming-languages/python/functions)، مطبَّقة هنا لتغليف سلوك بدلاً من مجرد التقاط قيمة.

**المولد (generator)** دالة تُنتج تسلسلاً من القيم كسولياً، واحدة تلو الأخرى، باستخدام `yield` بدلاً من `return`. استدعاء دالة مولّد لا ينفّذ جسمها فوراً — بل يُعيد كائن مولّد، ولا يتقدم الجسم إلا حتى `yield` التالية في كل مرة تُطلب فيها قيمة.

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for number in countdown(3):
    print(number)
# 3
# 2
# 1
```

يستأنف كل تكرار لحلقة `for` تنفيذ `countdown` مباشرة بعد `yield`، بدلاً من إعادة تشغيل الدالة كاملة من الصفر — تُحفَظ حالة الدالة المحلية (`n`، وموضعها ضمن حلقة `while`) بين كل يول ويول. هذا ما يجعل المولّدات فعّالة من حيث الذاكرة للتسلسلات الكبيرة أو غير المحدودة: لا يحتاج أي شيء يتجاوز القيمة الحالية إلى الوجود في الذاكرة دفعة واحدة.

**تعبير مولّد (generator expression)** — `(expr for item in iterable)` — هو النظير الكسول لفهم القائمة (list comprehension)، ينتج نفس نوع المولّد الذي يُنتج قيمة واحدة كل مرة دون `def` أو `yield` على الإطلاق.

```python
squares = (x * x for x in range(5))
print(next(squares))       # 0
print(next(squares))       # 1
print(list(squares))       # [4, 9, 16] — the rest, in one go
```

تسحب `next()` قيمة واحدة بالضبط من المولّد في كل مرة تُستدعى فيها؛ بينما تستنزف `list()` كل ما تبقّى. لاحظ أن أول قيمتين (`0`، `1`) قد اختفتا بالفعل بحلول وقت تشغيل `list()` — يُنتج المولّد كل قيمة مرة واحدة فقط، ولا توجد طريقة "لإرجاعه للخلف".
