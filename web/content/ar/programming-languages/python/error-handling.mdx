تُشير Python إلى الفشل بإطلاق استثناءات، ومعالجة استثناء تعني تغليف الكود المحفوف بالمخاطر داخل كتلة `try` مع جملة أو أكثر من `except` تلتقط أنواع استثناءات محددة.

```python
try:
    value = int(input("Enter a number: "))
except ValueError:
    print("That wasn't a valid number.")
else:
    print(f"You entered {value}")
finally:
    print("Done processing input.")
```

لكل جملة دور مميز: تحتوي كتلة `try` على الكود الذي قد يفشل؛ تلتقط `except ValueError` فقط ذلك الخطأ المحدد (أي `TypeError` في مكان آخر من الكتلة سينتشر دون التقاط)؛ تُنفَّذ `else` فقط إذا اكتملت كتلة `try` دون أي استثناء على الإطلاق؛ وتُنفَّذ `finally` دائماً — سواء حدث استثناء أم لا، أو حدث `return` أم لا — ما يجعلها المكان الصحيح لعمليات التنظيف مثل إغلاق ملف أو تحرير قفل.

التقاط `except ValueError` تحديداً، بدلاً من `except:` مجردة، أمر مهم: تبتلع `except` المجردة *كل شيء*، بما في ذلك الأخطاء المطبعية التي تطلق `NameError` والمقاطعات مثل `KeyboardInterrupt`، ما يجعل الأخطاء الحقيقية تختفي بصمت بدلاً من الظهور.

الاستثناءات المخصصة هي مجرد فئات ترث من `Exception` (أو استثناء مدمج أكثر تحديداً)، ما يتيح للكود المستدعي التقاط نمط الفشل الخاص بك بالاسم بدلاً من التخمين اعتماداً على رسائل نصية.

```python
class InsufficientFundsError(Exception):
    """Raised when a withdrawal exceeds the account balance."""

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(f"Cannot withdraw {amount}, balance is {balance}")
    return balance - amount

try:
    withdraw(100, 150)
except InsufficientFundsError as e:
    print(e)  # Cannot withdraw 150, balance is 100
```

`raise` هي كيف يشير الكود إلى الفشل صراحة؛ وتربط `except ... as e` نسخة الاستثناء المُلتقطة باسم بحيث يمكن فحص رسالتها (أو أي بيانات إضافية مرفقة بها).

```python
def read_config(path):
    try:
        with open(path) as f:
            return f.read()
    except FileNotFoundError:
        return "{}"
```

هنا تُعالَج حالة فشل محددة ومتوقعة (الملف غير موجود بعد) بقيمة احتياطية معقولة، بينما يُترك أي خطأ آخر — مشكلة أذونات، عطل في القرص — لينتشر، إذ إن ابتلاع تلك الأخطاء بصمت سيخفي مشكلة حقيقية.
