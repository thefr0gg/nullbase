تُعرَّف الدوال باستخدام `def`، ولا تتطلب Python التصريح بنوع الإرجاع أو أنواع الوسائط — لكن يمكن إعطاء الوسائط قيماً افتراضية، ما يجعلها اختيارية عند نقطة الاستدعاء.

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Sam"))                 # Hello, Sam!
print(greet("Sam", greeting="Hey"))  # Hey, Sam!
```

يعطي `greeting="Hello"` تلك الوسيطة قيمة افتراضية، بحيث يمكن للمستدعين حذفها تماماً. يمكن أيضاً تمرير الوسائط بالاسم (`greeting="Hey"`) بدلاً من الموضع، وهذا مفيد بمجرد أن تأخذ الدالة عدة وسائط ويصبح موضع الاستدعاء بخلاف ذلك قائمة قيم مجردة مربكة.

أحياناً لا يكون عدد الوسائط التي ينبغي أن تقبلها الدالة ثابتاً مسبقاً. يجمع `*args` أي وسائط موضعية إضافية في صف (tuple)، ويجمع `**kwargs` أي وسائط مسماة إضافية في قاموس — الاسمان `args`/`kwargs` مجرد اصطلاح، بينما البادئتان `*`/`**` هما ما يهم فعلياً.

```python
def total(*args, **kwargs):
    print("positional:", args)     # (1, 2, 3)
    print("keyword:", kwargs)       # {'label': 'sum'}
    return sum(args)

result = total(1, 2, 3, label="sum")
print(result)  # 6
```

يظهر هذا النمط باستمرار في كود المكتبات — دالة غلاف (wrapper) تحتاج إلى قبول "أياً كانت الوسائط التي يقبلها الشيء الذي تغلّفه" دون معرفة توقيعه مسبقاً تستخدم `def wrapper(*args, **kwargs)` وتمررها عبر `wrapped(*args, **kwargs)`.

الدوال أيضاً كائنات عادية: يمكن إسنادها إلى متغيرات، وتمريرها كوسائط، وإرجاعها من دوال أخرى، وهذا ما يجعل الإغلاقات (closures) ممكنة.

```python
def make_multiplier(factor):
    def multiplier(x):
        return x * factor
    return multiplier

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(5), triple(5))  # 10 15
```

"تتذكر" `multiplier` قيمة `factor` من الاستدعاء الذي أنشأها، حتى بعد أن تكون `make_multiplier` قد أنهت تنفيذها بالفعل — هذا إغلاق (closure)، وهو الآلية وراء مزخرفات (decorators) Python.
