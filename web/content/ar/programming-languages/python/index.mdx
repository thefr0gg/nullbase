Python لغة مفسَّرة ذات كتابة ديناميكية، وسمتها المميزة أنها تجعل قابلية القراءة سمة في اللغة نفسها بدلاً من كونها مجرد تفضيل أسلوبي: تُحدَّد الكتل بالإزاحة (indentation) بدلاً من الأقواس أو كلمات مفتاحية مثل `end`، لذلك لا يمكن للبنية البصرية للسكربت وتدفق التحكم الفعلي فيه أن ينفصلا عن بعضهما. لا توجد خطوة ترجمة (compile) منفصلة لتشغيل الكود — التطبيق المرجعي، CPython، يقرأ ملف `.py` وينفّذه مباشرة — وهذا جزء من سبب ظهور Python في كل مكان بدءاً من السكربتات السريعة وصولاً إلى خلفيات ويب في الإنتاج وخطوط معالجة بيانات وكود تعلّم آلي.

```python
print("Hello, world!")

name = "Ada"
age = 36
print(f"{name} is {age} years old")
```

يبرز أمران حتى في هذا المثال الصغير. أولاً، لا يوجد أي تصريح بنوع في أي مكان — يحصل `name` و`age` على نوعيهما من القيم المسندة إليهما، ويمكن إعادة إسناد متغير لنوع مختلف لاحقاً دون أي اعتراض. ثانياً، السلسلة `f"..."` هي f-string: سلسلة نصية حرفية تحتوي على عناصر نائبة `{expression}` تُقيَّم مباشرة، وهذه هي الطريقة التي يبني بها معظم كود Python مخرجات منسّقة بدلاً من ضم القطع باستخدام `+`.

تأتي Python أيضاً مع مكتبة قياسية كبيرة ونظام حزم خارجية ضخم يُثبَّت عبر `pip`، لذا فإن قدراً مفاجئاً من العمل الحقيقي — قراءة JSON، إجراء طلبات HTTP، تحليل التواريخ — لا يحتاج إلى أي اعتماديات إضافية غير ما هو مثبّت بالفعل أو أمر واحد من `pip install`.

```python
def fizzbuzz(n):
    for i in range(1, n + 1):
        if i % 15 == 0:
            print("FizzBuzz")
        elif i % 3 == 0:
            print("Fizz")
        elif i % 5 == 0:
            print("Buzz")
        else:
            print(i)

fizzbuzz(15)
```

لاحظ عدم وجود أقواس حول شرط `if`، ولا فواصل منقوطة تنهي الجمل، وأن امتداد جسم الدالة يُحدَّد فقط بمقدار إزاحة أسطره — أزل الإزاحة وستحصل على خطأ نحوي، وليس مجرد تنسيق غير مرتب.
