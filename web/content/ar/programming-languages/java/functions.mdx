لا تملك Java دوالاً حرة. كل قطعة من الكود القابل لإعادة الاستخدام
والاستدعاء هي **تابع (method)**، مُصرَّح داخل صنف أو واجهة. حتى نقطة دخول
البرنامج، `main`، هي تابع `static` على صنف ما — لا سبيل لكتابة دالة تعوم
خارج جسم صنف.

## تصريح تابع

يسرد تصريح التابع (بالترتيب) مُعدِّل وصول، ومُعدِّلات اختيارية مثل
`static`، ونوع إرجاع، واسماً، وقائمة معاملات:

```java
public class MathUtils {
    public static int square(int n) {
        return n * n;
    }

    public static void printSquare(int n) {
        System.out.println(square(n));
    }
}
```

تنتمي توابع `static` إلى الصنف نفسه ويمكن استدعاؤها دون إنشاء نسخة
(`MathUtils.square(5)`). توابع النسخة (بلا `static`) تعمل على كائن معيّن
وتُستدعى عبر إحالة إليه (`someObject.someMethod()`).

## void مقابل إرجاع قيمة

يُصرِّح التابع الذي لا ينتج قيمة `void` كنوع إرجاعه ولا يستخدم ببساطة
`return` مع تعبير:

```java
public static void greet(String name) {
    System.out.println("Hello, " + name);
    return; // اختياري هنا — الوصول إلى نهاية تابع void يعمل أيضاً
}
```

يجب أن يُعيد التابع بنوع إرجاع حقيقي قيمة في كل مسار ممكن، وإلا رفضه
المصرّف:

```java
public static String describe(int n) {
    if (n < 0) {
        return "negative";
    } else {
        return "non-negative";
    }
    // لا حاجة إلى return نهائية — كل مسار أعلاه يُعيد بالفعل
}
```

## التحميل الزائد للتوابع (Overloading)

تسمح Java بتوابع متعددة بـ**نفس الاسم** في نفس الصنف طالما تختلف قوائم
معاملاتها في العدد أو النوع — هذا هو **التحميل الزائد (overloading)**،
ويُحَل بالكامل وقت التصريف بناءً على أنواع الوسائط في موقع الاستدعاء:

```java
public class Printer {
    public static void print(int value) {
        System.out.println("int: " + value);
    }

    public static void print(double value) {
        System.out.println("double: " + value);
    }

    public static void print(String value) {
        System.out.println("String: " + value);
    }
}
```

استدعاء `Printer.print(5)` يختار نسخة `int`، و`Printer.print(5.0)` يختار
نسخة `double`، و`Printer.print("five")` يختار نسخة `String` — يختار
المصرّف بناءً على الأنواع الساكنة للوسائط، وليس بأي فحص وقت التشغيل.
التحميل الزائد مختلف عن **التجاوز (overriding)** (يُغطَّى في صفحة
[الأصناف والواجهات](/ar/programming-languages/java/oop-or-structs))، الذي
يستبدل سلوك تابع في صنف فرعي بنفس التوقيع *تماماً*.

## المعاملات متغيرة العدد (Varargs)

يمكن لتابع أن يقبل عدداً متغيراً من الوسائط الأخيرة بـ`...`، يراها جسم
التابع كمصفوفة:

```java
public static int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) {
        total += n;
    }
    return total;
}

// sum(1, 2, 3) وsum() كلاهما استدعاء صحيح
```
