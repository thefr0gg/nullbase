ستبدو بنى التحكم بمسار التنفيذ في Java مألوفة إذا كنت تعرف C أو ++C أو
JavaScript — الأقواس تحدّ الكتل ويجب أن تكون الشروط تعبيرات `boolean`
حقيقية، وليست قيماً صحيحة/زائفة مُحوَّلة من أرقام أو كائنات.

## if / else

```java
int score = 82;

if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("C or below");
}
```

خلافاً لـC، لا يُصرَّف `if (score)` عندما تكون `score` من نوع `int` — يجب
أن يكون الشرط تعبير `boolean` مثل `score != 0`. هذا يستبعد فئة كاملة من
أخطاء "الإسناد بدلاً من المقارنة"، بما أن `if (score = 0)` أيضاً خطأ
تصريف وليس إسناداً صامتاً.

## switch: الصيغة الكلاسيكية والسهمية

تنساب `switch` الكلاسيكية إلى الحالة التالية ما لم تستخدم `break`:

```java
int day = 3;
String name;
switch (day) {
    case 1:
        name = "Monday";
        break;
    case 2:
        name = "Tuesday";
        break;
    case 3:
        name = "Wednesday";
        break;
    default:
        name = "Unknown";
}
System.out.println(name);
```

أدخلت Java 14 الصيغة السهمية، التي لا تنساب ويمكنها إنتاج قيمة مباشرة
بـ`yield` (أو كتعبير):

```java
int day = 3;
String name = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Unknown";
};
System.out.println(name);
```

الصيغة السهمية مفضَّلة عموماً في Java الحديثة: يصعب الانسياب فيها عن غير
قصد، واستخدامها كتعبير يعني أن المصرّف يستطيع التحقق من أن كل فرع ينتج
قيمة من نفس النوع.

## الحلقات

تملك Java ثلاث صيغ حلقات. `for` بعدّاد صريح:

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

`for` المُحسَّنة ("for-each") لتكرار مجموعة أو مصفوفة دون فهرسة يدوية:

```java
int[] scores = {70, 85, 92};
for (int score : scores) {
    System.out.println(score);
}
```

`while` و`do-while`، تُميَّزان بتوقيت التحقق من الشرط — تتحقق `while` قبل
التكرار الأول، بينما تُشغِّل `do-while` الجسم مرة واحدة على الأقل دائماً:

```java
int n = 5;
while (n > 0) {
    System.out.println(n);
    n--;
}

int attempts = 0;
do {
    attempts++;
} while (attempts < 3);
System.out.println(attempts);
```

يخرج `break` من الحلقة كلياً؛ يتخطى `continue` إلى التكرار التالي. يقبل
كلاهما تسمية (`outer:`) لاستهداف حلقة محيطة عندما تكون الحلقات متداخلة.
