تمنحك Java طبقتين من الحاويات: **المصفوفات** المدمجة، ثابتة الحجم بمجرد
إنشائها، و**إطار المجموعات** (`java.util`)، الذي تلجأ إليه معظم الأكواد
اليومية فعلياً بأنواعه العامة القابلة لتغيير الحجم مثل `ArrayList`
و`HashMap`.

## المصفوفات

تحتفظ المصفوفة بعدد ثابت من عناصر نوع واحد، مُخصَّص مسبقاً:

```java
int[] scores = new int[3];
scores[0] = 70;
scores[1] = 85;
scores[2] = 92;

int[] literal = {70, 85, 92}; // مصفوفة حرفية، الحجم مُستنتَج

System.out.println(scores.length); // 3، حقل، وليس استدعاء تابع
```

المصفوفات مُفهرَسة من الصفر، والقراءة أو الكتابة خارج `[0, length)` ترمي
`ArrayIndexOutOfBoundsException` وقت التشغيل بدلاً من إفساد الذاكرة
بصمت. `length` حقل `final` على كائن المصفوفة، وليس تابعاً — خلافاً لـ
`String.length()` أو `List.size()`، وهما تابعان.

## ArrayList

`ArrayList<T>` قائمة قابلة لتغيير الحجم، مدعومة بمصفوفة، من `java.util`.
بما أن الأنواع العامة في Java لا يمكنها احتواء الأنواع الأولية مباشرة،
يجب أن يكون `T` نوعاً مرجعياً — استخدم صنف الغلاف (`Integer`، وليس `int`)
لأنواع العناصر الأولية:

```java
import java.util.ArrayList;
import java.util.List;

List<String> names = new ArrayList<>();
names.add("Ada");
names.add("Linus");
names.add(1, "Grace"); // إدراج عند الفهرس 1، مع إزاحة العناصر اللاحقة يميناً

System.out.println(names);       // [Ada, Grace, Linus]
System.out.println(names.get(0)); // Ada
System.out.println(names.size()); // 3

names.remove("Linus");
System.out.println(names); // [Ada, Grace]
```

تصريح المتغير كـ`List<String>` (الواجهة) بدلاً من `ArrayList<String>`
(الصنف الملموس) اصطلاحي — يتيح لك استبدال تنفيذ `List` مختلف لاحقاً دون
لمس كود يستدعي توابع الواجهة فقط.

## HashMap

يخزّن `HashMap<K, V>` أزواج مفتاح-قيمة بمتوسط O(1) للبحث والإدراج
والحذف، مدعوماً بجدول تجزئة. لا يضمن أي ترتيب للتكرار:

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> ages = new HashMap<>();
ages.put("Ada", 36);
ages.put("Linus", 54);

System.out.println(ages.get("Ada"));          // 36
System.out.println(ages.get("Grace"));         // null: المفتاح غير موجود
System.out.println(ages.getOrDefault("Grace", 0)); // 0: قيمة افتراضية آمنة
System.out.println(ages.containsKey("Linus")); // true

for (Map.Entry<String, Integer> entry : ages.entrySet()) {
    System.out.println(entry.getKey() + " is " + entry.getValue());
}
```

`get` على مفتاح مفقود تُعيد `null` بدلاً من الرمي، وهو مصدر شائع لأخطاء
`NullPointerException` إذا استُخدمت النتيجة دون تحقق من null أو
`getOrDefault`. إذا احتجت ترتيب تكرار يمكن التنبؤ به، يحافظ
`LinkedHashMap` على ترتيب الإدراج ويحافظ `TreeMap` على ترتيب المفاتيح
مُرتَّبة.
