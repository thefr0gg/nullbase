Java ثابتة الأنواع: نوع كل متغير ثابت وقت التصريف ويُتحقَّق منه قبل أن
يعمل البرنامج مطلقاً. خلافاً للغات ديناميكية الأنواع، لا يمكنك إعادة
إسناد متغير إلى قيمة من نوع غير متوافق — يرفضها المصرّف قبل أن تحصل على
الفرصة.

## تصريح المتغيرات

الصيغة الصريحة تذكر النوع، ثم الاسم، ثم مُهيِّئ اختياري:

```java
int age = 36;
double price = 19.99;
boolean isAdmin = false;
String name = "Ada";
```

منذ Java 10، يتيح `var` للمصرّف استنتاج النوع من المُهيِّئ داخل جسم
تابع. لا تزال ثابتة الأنواع — `var` مجرد اختصار لاستنتاج المصرّف النوع
وقت التصريف، وليست نوعاً ديناميكياً:

```java
var age = 36;        // مُستنتَج كـint
var name = "Ada";    // مُستنتَج كـString
var isAdmin = false; // مُستنتَج كـboolean
```

لا يمكن استخدام `var` للحقول أو معاملات التوابع أو أنواع الإرجاع، ويتطلب
مُهيِّئاً كي يكون للمصرّف ما يستنتج منه — `var x;` لا يُصرَّف.

## الأنواع الأولية مقابل أصناف الغلاف

تملك Java ثمانية أنواع **أولية** مدمجة ليست كائنات وتحمل قيمتها مباشرة،
دون إحالة بمؤشر:

| الفئة | الأنواع |
|---|---|
| الأعداد الصحيحة | `byte`, `short`, `int`, `long` |
| الأعداد العشرية | `float`, `double` |
| أخرى | `char` (وحدة رمز UTF-16)، `boolean` |

لكل نوع أولي **صنف غلاف (wrapper class)** مقابل (`Integer`، `Double`،
`Boolean`، وهكذا) يُغلِّفه في كائن — مطلوب كلما احتجت لنوع أولي أن يتصرف
كـكائن، مثل تخزينه في مجموعة كـ`ArrayList<Integer>`، لأن المجموعات العامة
(generic) لا يمكنها احتواء الأنواع الأولية مباشرة:

```java
int primitive = 42;
Integer boxed = 42;          // تغليف تلقائي: int -> Integer ضمنياً
int backToPrimitive = boxed; // فك تغليف تلقائي: Integer -> int ضمنياً
```

يُسمّى هذا التحويل الضمني التغليف وفك التغليف التلقائيين. إنه مريح لكنه
ليس مجانياً — التغليف يخصص كائناً — وغلاف `null` يُفَك تغليفه إلى نوع
أولي يرمي `NullPointerException` وقت التشغيل.

## الثوابت بـfinal

`final` على متغير محلي أو حقل يعني أنه يمكن إسناده مرة واحدة بالضبط. إنها
أقرب مكافئ في Java للثابت:

```java
final double PI = 3.14159;
final int MAX_RETRIES = 3;

// PI = 3.0; // خطأ تصريف: لا يمكن إسناد قيمة إلى المتغير النهائي PI
```

بالعُرف، تُسمّى حقول `final` المقصودة كثوابت بصيغة `SCREAMING_SNAKE_CASE`.
