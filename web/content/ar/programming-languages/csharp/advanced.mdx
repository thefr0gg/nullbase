ميزة التزامن المميِّزة لـC# هي `async`/`await` المبنية فوق
`Task` و`Task<T>` — عمليات غير متزامنة تمثل "قيمة ستكون متاحة
لاحقاً" (أشبه بـ`Promise` في JavaScript، رغم أن `Task` سبقت
الاستخدام الواسع لذلك النمط وهي مدعومة بمجمع خيوط .NET بدلاً من
حلقة أحداث أحادية الخيط).

## Task وTask\<T\>

تمثل `Task` عملية جارية بلا نتيجة؛ وتمثل `Task<T>` عملية ستنتج
في النهاية قيمة من النوع `T`:

```csharp
using System.Threading;
using System.Threading.Tasks;

Task<int> task = Task.Run(() =>
{
    Thread.Sleep(1000); // simulate slow work
    return 42;
});

Console.WriteLine("Started, doing other work...");
int result = task.Result; // blocks until the task completes
Console.WriteLine(result); // 42
```

التعطيل على `.Result` يهزم معظم الغاية من عدم التزامن — يستخدم
الكود غير المتزامن الحقيقي `await` بدلاً من ذلك، الذي يُعلِّق
التابع الحالي دون تعطيل الخيط الأساسي.

## async / await

وضع علامة `async` على تابع يتيح له استخدام `await` للتعليق حتى
تكتمل `Task`، دون تعطيل الخيط المستدعي. تُرجع تابع `async` نفسه
`Task` (أو `Task<T>`)، بحيث يستطيع المستدعون انتظارها (`await`)
بدورهم:

```csharp
using System.Net.Http;
using System.Threading.Tasks;

async Task<string> FetchGreetingAsync()
{
    await Task.Delay(500); // simulates an I/O-bound wait, non-blocking
    return "Hello from the async world";
}

async Task RunAsync()
{
    Console.WriteLine("Before await");
    string greeting = await FetchGreetingAsync();
    Console.WriteLine(greeting);
    Console.WriteLine("After await");
}

await RunAsync();
```

لا يعطّل التابع خيطاً أثناء الانتظار على `Task.Delay` — يعود
التحكم إلى المستدعي، ويستأنف باقي `FetchGreetingAsync` على خيط من
مجمع الخيوط بمجرد انتهاء التأخير. هذا سبب كون `async`/`await`
اصطلاح الاختيار للعمل المرتبط بالإدخال/الإخراج (استدعاءات
الشبكة، والوصول للملفات، واستعلامات قواعد البيانات): لا تُهدَر
الخيوط بالجلوس عاطلة في انتظار الإدخال/الإخراج.

## تشغيل المهام بتزامن

انتظار المهام واحدة تلو الأخرى يشغّلها بالتسلسل. تبدأ
`Task.WhenAll` عدة مهام وتنتظرها جميعاً معاً، مُشغِّلة العمل
المستقل بتزامن:

```csharp
async Task<int> FetchLengthAsync(string url)
{
    await Task.Delay(300); // stands in for an HTTP call
    return url.Length;
}

async Task RunAllAsync()
{
    Task<int> t1 = FetchLengthAsync("https://a.example");
    Task<int> t2 = FetchLengthAsync("https://b.example");
    Task<int> t3 = FetchLengthAsync("https://c.example");

    int[] lengths = await Task.WhenAll(t1, t2, t3);
    Console.WriteLine(string.Join(", ", lengths));
}

await RunAllAsync();
```

بما أن `t1` و`t2` و`t3` جميعها تبدأ قبل أي `await`، تتداخل
استدعاءاتها لـ`Task.Delay(300)` — يستغرق التابع بأكمله نحو
300 مللي ثانية إجمالاً، لا 900، بخلاف انتظار كل واحدة فور بدئها.
