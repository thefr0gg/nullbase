تنظّم C# الكود بـ**المساحات الاسمية (namespaces)** (تجميع منطقي،
مستقل عن تخطيط الملفات) وتدير التبعيات الخارجية بحزم **NuGet**
المُصرَّح عنها في ملف `.csproj` الخاص بمشروع. بخلاف بعض اللغات،
لا يجب أن تطابق المساحة الاسمية في C# بنية المجلدات على القرص،
رغم أن معظم المشاريع تبقيها متوافقة كعُرف.

## المساحات الاسمية وusing

تجمّع المساحة الاسمية أنواعاً مرتبطة وتتجنب تصادم الأسماء بين
مكتبات تعرّف مصادفةً نوعاً بالاسم نفسه:

```csharp
namespace Nullbase.Payments
{
    public class Invoice
    {
        public decimal Amount { get; set; }
    }
}

namespace Nullbase.App
{
    using Nullbase.Payments; // brings Invoice into scope unqualified

    class Program
    {
        static void Main()
        {
            var invoice = new Invoice { Amount = 42.50m };
            Console.WriteLine(invoice.Amount);
        }
    }
}
```

بدون توجيه `using Nullbase.Payments;`، ستحتاج `Invoice` أن تُكتَب
بالكامل كـ`Nullbase.Payments.Invoice` في كل مكان تُستخدَم فيه.

تدعم C# الحديثة (10+) أيضاً **المساحات الاسمية على مستوى الملف**،
التي تتجنب مستوى إزاحة إضافياً للحالة الشائعة لمساحة اسمية واحدة
لكل ملف:

```csharp
namespace Nullbase.Payments; // applies to the rest of the file — no braces

public class Invoice
{
    public decimal Amount { get; set; }
}
```

## توجيهات using العامة

يمكن لمشروع التصريح عن توجيهات `using` مرة واحدة، على مستوى
المشروع بأكمله، بدلاً من تكرارها في كل ملف — مفيد لمساحات اسمية
مثل `System` التي يحتاجها كل ملف تقريباً:

```csharp
// GlobalUsings.cs
global using System;
global using System.Collections.Generic;
global using System.Linq;
```

## .csproj وNuGet

يُوصَف كل مشروع C# بملف `.csproj` بصيغة XML: إطار العمل
المستهدف، والملفات المصدرية (مُدرَجة ضمنياً بحسب المجلد في تنسيق
SDK-style)، ومراجع الحزم. NuGet هو مدير الحزم والسجل العام لـ
.NET، ويلعب الدور نفسه الذي يلعبه `npm` لـNode.js:

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net8.0</TargetFramework>
    <Nullable>enable</Nullable>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="Newtonsoft.Json" Version="13.0.3" />
  </ItemGroup>

</Project>
```

عادةً ما تُضاف تبعية من سطر الأوامر بدلاً من تحرير XML يدوياً:

```bash
dotnet add package Newtonsoft.Json
dotnet restore
dotnet build
dotnet run
```

يكتب `dotnet add package` مدخل `<PackageReference>` في `.csproj`
وتُنزِّل `dotnet restore` الحزمة (وتبعياتها العابرة) إلى ذاكرة
NuGet المحلية المؤقتة، على غرار كيفية ملء `npm install` لـ
`node_modules` من `package.json`.
