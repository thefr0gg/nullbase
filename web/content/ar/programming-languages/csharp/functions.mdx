في C#، تُصرَّح الدوال دائماً تقريباً كـ**توابع (methods)** — أعضاء
صنف أو بُنية — بدلاً من دوال حرة مستقلة (الدوال المحلية استثناء،
مشمولة أدناه). تصرّح الدالة عن نوع إرجاع، واسم، وقائمة معاملات.

## الدوال الأساسية

```csharp
class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }

    // Expression-bodied method: shorthand for a single-expression body
    public int Square(int x) => x * x;
}

var calc = new Calculator();
Console.WriteLine(calc.Add(2, 3));    // 5
Console.WriteLine(calc.Square(4));    // 16
```

تستخدم الدالة التي لا تُرجع شيئاً `void`. تنتمي التوابع `static`
إلى النوع نفسه بدلاً من نسخة، وهذا سبب كون `Main` دائماً `static`.

## المعاملات الاختيارية والقيم الافتراضية

يمكن أن تصرّح المعاملات عن قيمة افتراضية، ما يجعلها اختيارية في
موقع الاستدعاء — يجب أن يمتلك أي معامل بعد معامل ذي قيمة افتراضية
قيمة افتراضية أيضاً:

```csharp
string Greet(string name, string greeting = "Hello", bool shout = false)
{
    string message = $"{greeting}, {name}!";
    return shout ? message.ToUpper() : message;
}

Console.WriteLine(Greet("Ada"));                        // Hello, Ada!
Console.WriteLine(Greet("Ada", "Hey"));                  // Hey, Ada!
Console.WriteLine(Greet("Ada", shout: true));            // HELLO, ADA!
```

## الوسائط المُسماة

يمكن لأي استدعاء تمرير الوسائط بالاسم بدلاً من الموضع، بأي ترتيب —
هذا مفيد خصوصاً عند تجاوز معاملات اختيارية سابقة، كما فعلت
`shout: true` أعلاه. تجعل الوسائط المُسماة مواقع الاستدعاء موثِّقة
ذاتياً عندما يأخذ تابع عدة معاملات من النوع نفسه:

```csharp
void CreateUser(string name, int age, bool isAdmin = false)
{
    Console.WriteLine($"{name}, {age}, admin={isAdmin}");
}

CreateUser(name: "Grace", age: 40, isAdmin: true);
CreateUser(age: 25, name: "Alan"); // order doesn't matter with names
```

## params والدوال المحلية

تتيح `params` لتابع قبول عدد متغير من الوسائط الزائدة كمصفوفة،
وتتيح الدوال المحلية تضمين تابع مساعد داخل آخر:

```csharp
int Sum(params int[] numbers)
{
    int total = 0;
    foreach (int n in numbers)
    {
        total += n;
    }
    return total;
}

Console.WriteLine(Sum(1, 2, 3, 4)); // 10

int Outer(int x)
{
    int Double(int n) => n * 2; // local function, only visible inside Outer
    return Double(x) + 1;
}

Console.WriteLine(Outer(5)); // 11
```
