C# (تُنطَق "سي شارب") لغة ثابتة الأنواع كائنية التوجه
أنشأتها مايكروسوفت عام 2000، بقيادة أندرس هيلسبرغ (الذي صمم أيضاً
TypeScript لاحقاً). تعمل على .NET، بيئة تشغيل مُدارة بنموذج
ذاكرة مُجمَّعة القمامة، ومترجم فوري (وبشكل متزايد مسبق)، ومكتبة قياسية
ضخمة. نمت C# منذ ذلك الحين إلى ما وراء ويندوز بكثير: .NET
الحديثة عابرة للمنصات، ومفتوحة المصدر، وتشغّل أحمال عمل إنتاجية على حاويات
لينكس، وفي ألعاب Unity، وعلى الجوال عبر .NET MAUI.

بدأت C# كابنة عم قريبة لـ Java، لكن اللغتين تباعدتا سريعاً.
أضافت C# الأنواع العامة (generics) بدعم حقيقي في وقت التشغيل، والخصائص
(properties) كبنية لغوية أصيلة، وLINQ (بنية استعلام مدمجة في اللغة)،
ومؤخراً أكثر، `async`/`await` للكود غير المتزامن، وأنواع المراجع القابلة
للإفراغ (nullable reference types) لالتقاط أخطاء ذات صلة بـnull في وقت
الترجمة، ومطابقة الأنماط التي تستمر بالتوسع مع كل إصدار.

## ما يميّز C#

- **الخصائص، لا الحقول فحسب.** تدمج C# بنية getter/setter في اللغة نفسها
  (`public int Age { get; set; }`)، لذا لا يتطلب التغليف كتابة
  `getAge()`/`setAge()` نمطية.
- **`async`/`await` كبنية أصيلة.** يُقرأ الكود غير المتزامن وغير المُعطِّل
  مثل الكود المتزامن، مدعوماً بـ`Task` و`Task<T>`.
- **أنواع عامة قوية.** بخلاف الأنواع العامة في Java التي تُمحى نوعيتها،
  تُجسَّد أنواع C# العامة في وقت التشغيل، ما يجعلها أسرع ويتيح لك فعل
  أشياء مثل `typeof(T)` داخل تابع عام.
- **LINQ.** استعلم عن المجموعات وحوّلها ببنية شبيهة بـSQL أو بسلاسل توابع
  انسيابية (`.Where(...)`، و`.Select(...)`) مدمجة مباشرة في اللغة والمكتبة
  القياسية.
- **أنواع المراجع القابلة للإفراغ.** منذ C# 8، يستطيع المترجم تحذيرك في
  وقت الترجمة عندما يمكن لمرجع لا يُفترض أن يكون `null` أن يكونه.

إليك برنامج C# بسيط ومكتمل:

```csharp
Console.WriteLine("Hello, nullbase!");
```

لا تتطلب C# الحديثة (منذ العبارات على المستوى الأعلى في C# 9) غلاف
`class` و`Main` للبرامج البسيطة — يُولّد المترجم واحداً لك خلف
الكواليس. لا يزال الكود الأقدم، ومعظم المشاريع الواقعية، يكتبه صراحة:

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, nullbase!");
        }
    }
}
```

## متى تختار C#

C# هي الخيار الافتراضي لواجهات برمجة تطبيقات الويب وخلفيات ASP.NET Core،
وبرمجيات سطح مكتب ويندوز والمهام التجارية للمؤسسات، و — عبر محرك ألعاب
Unity — حصة ضخمة من الألعاب التجارية. مزيجها من الأداء، وأمان الذاكرة،
ومكتبة قياسية غنية يجعلها خياراً عاماً قوياً في أي مكان قد يُنظَر فيه
لبيئة JVM بدلاً منها.

## ما القادم

تشرح الصفحات التالية C# من البنية إلى البرمجة غير المتزامنة:
المتغيرات والأنواع، والتحكم بمسار التنفيذ، والتوابع، وهياكل البيانات
المدمجة، والأصناف والواجهات، ومعالجة الأخطاء، ونظام المساحات
الاسمية/الحزم، وتنتهي بـ`async`/`await` و`Task`.
