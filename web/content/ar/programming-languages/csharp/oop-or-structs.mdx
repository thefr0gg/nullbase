C# كائنية التوجه بشكل كامل: تدعم الأصناف الوراثة الفردية، وتدعم
الواجهات عقود تنفيذ متعددة، ويُبنى التغليف في اللغة عبر
**الخصائص (properties)** بدلاً من تركه للعُرف.

## الأصناف والحقول

يجمع الصنف الحالة (الحقول) والسلوك (التوابع) معاً:

```csharp
class Dog
{
    private string name;

    public Dog(string name)
    {
        this.name = name;
    }

    public void Bark()
    {
        Console.WriteLine($"{name} says Woof!");
    }
}

var rex = new Dog("Rex");
rex.Bark(); // Rex says Woof!
```

حقل `private` بسيط مثل `name` ليس له أي تحقق ولا طريقة لاعتراض
القراءات أو الكتابات من خارج الصنف — لهذا وُجدت الخصائص.

## الخصائص: ميزة لغوية، لا عُرف

بخلاف Java أو C++، حيث تعني "الحقول المُغلَّفة" كتابة توابع
`getName()`/`setName()` يدوياً، تبني C# بنية getter/setter مباشرة
في اللغة نفسها. تبدو الخاصية كحقل للمستدعين لكن يمكنها تشغيل كود
عند كل قراءة أو كتابة:

```csharp
class Person
{
    private int age;

    public string Name { get; set; } // auto-implemented property: compiler
                                      // generates the backing field for you

    public int Age
    {
        get => age;
        set
        {
            if (value < 0)
            {
                throw new ArgumentException("Age cannot be negative");
            }
            age = value;
        }
    }

    public string Greeting => $"Hi, I'm {Name}"; // read-only, expression-bodied

    public Person(string name, int age)
    {
        Name = name;
        Age = age;
    }
}

var p = new Person("Ada", 36);
Console.WriteLine(p.Greeting); // Hi, I'm Ada
p.Age = -5; // throws ArgumentException
```

يكتب المستدعون `p.Age = 30;` تماماً كما لو كانت `Age` حقلاً — يعمل
منطق التحقق في كتلة `set` بشفافية. هذا سبب تفضيل أسلوب C# بقوة
للخصائص العامة على الحقول العامة: يمكنك البدء بخاصية ذاتية التنفيذ
وإضافة منطق لاحقاً دون كسر أي مستدعٍ.

## الواجهات والوراثة

تصرّح الواجهة عن عقد بلا تنفيذ (باستثناء توابع الواجهة الافتراضية)؛
يُنفِّذ صنف واجهة واحدة أو أكثر ويرث من صنف أساسي واحد كحد أقصى:

```csharp
interface IShape
{
    double Area();
}

class Circle : IShape
{
    public double Radius { get; }

    public Circle(double radius) => Radius = radius;

    public double Area() => Math.PI * Radius * Radius;
}

class Square : IShape
{
    public double Side { get; }

    public Square(double side) => Side = side;

    public double Area() => Side * Side;
}

List<IShape> shapes = new List<IShape> { new Circle(2), new Square(3) };
foreach (IShape shape in shapes)
{
    Console.WriteLine(shape.Area());
}
```

يستخدم وراثة الصنف الأساسي نفس بنية `:` والكلمة المفتاحية
`override` لتعدد الأشكال:

```csharp
class Animal
{
    public virtual string Speak() => "...";
}

class Cat : Animal
{
    public override string Speak() => "Meow";
}

Animal a = new Cat();
Console.WriteLine(a.Speak()); // Meow — resolved at runtime via the actual type
```
