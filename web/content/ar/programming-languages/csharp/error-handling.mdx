تستخدم C# الاستثناءات لمعالجة الأخطاء بدلاً من قيم إرجاع الخطأ.
أي شيء من فهرس مصفوفة غير صالح إلى استدعاء شبكة فاشل يرمي كائناً
مشتقاً من `System.Exception`، ويمكن للكود الأعلى في مكدس
الاستدعاء التقاطه.

## try / catch / finally

```csharp
try
{
    int[] numbers = { 1, 2, 3 };
    Console.WriteLine(numbers[10]); // throws IndexOutOfRangeException
}
catch (IndexOutOfRangeException ex)
{
    Console.WriteLine($"Caught: {ex.Message}");
}
finally
{
    Console.WriteLine("This always runs, exception or not.");
}
```

تعمل `finally` سواء أُطلق استثناء أم لا، وحتى لو أرجعت كتلة
`try` أو `catch` مبكراً — إنها المكان المناسب للتنظيف مثل إغلاق
ملف أو اتصال.

تتيح لك عدة كتل `catch` معالجة أنواع استثناءات مختلفة بشكل
مختلف؛ تُفحص من الأعلى إلى الأسفل، لذا ضع الأنواع الأكثر تحديداً
أولاً:

```csharp
try
{
    string input = "not a number";
    int value = int.Parse(input);
}
catch (FormatException ex)
{
    Console.WriteLine($"Bad format: {ex.Message}");
}
catch (Exception ex)
{
    Console.WriteLine($"Something else went wrong: {ex.Message}");
}
```

يتيح مرشِّح استثناء (`when`) لعبارة `catch` واحدة أن تُطلَق فقط
تحت شروط إضافية، دون ابتلاع استثناءات لا تطابقها:

```csharp
try
{
    throw new InvalidOperationException("disk full");
}
catch (InvalidOperationException ex) when (ex.Message.Contains("disk"))
{
    Console.WriteLine("Handling a disk-related failure specifically.");
}
```

## الاستثناءات المخصصة

اشتقاق نوع استثناء خاص بك من `Exception` (أو صنف أساسي أكثر
تحديداً) يتيح للكود المستدعي التقاط الفشل الذي يهمه بالضبط،
ويتيح لك إرفاق بيانات خاصة بمجالك:

```csharp
class InsufficientFundsException : Exception
{
    public decimal Shortfall { get; }

    public InsufficientFundsException(decimal shortfall)
        : base($"Insufficient funds: short by {shortfall:C}")
    {
        Shortfall = shortfall;
    }
}

class Account
{
    public decimal Balance { get; private set; } = 100m;

    public void Withdraw(decimal amount)
    {
        if (amount > Balance)
        {
            throw new InsufficientFundsException(amount - Balance);
        }
        Balance -= amount;
    }
}

var account = new Account();
try
{
    account.Withdraw(150m);
}
catch (InsufficientFundsException ex)
{
    Console.WriteLine(ex.Message);      // Insufficient funds: short by $50.00
    Console.WriteLine(ex.Shortfall);    // 50
}
```

يجب أن تستدعي الاستثناءات المخصصة دائماً المُنشئ الأساسي
(`: base(message)`) حتى تستمر خاصية `.Message` القياسية وآلية
تتبع المكدس في العمل كما هو متوقع.
