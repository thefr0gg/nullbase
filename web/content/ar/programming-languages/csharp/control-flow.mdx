يبدأ التحكم بمسار التنفيذ في C# مألوفاً — `if`/`else`، و`for`،
و`while` — ثم يذهب أبعد من معظم لغات عائلة C بتعبيرات
`switch` التي تطابق على النوع والبنية، لا المساواة فحسب.

## if / else والحلقات

```csharp
int score = 82;

if (score >= 90)
{
    Console.WriteLine("A");
}
else if (score >= 80)
{
    Console.WriteLine("B");
}
else
{
    Console.WriteLine("C or below");
}

for (int i = 0; i < 3; i++)
{
    Console.WriteLine($"Iteration {i}");
}

int n = 5;
while (n > 0)
{
    Console.WriteLine(n);
    n--;
}
```

تُكرر `foreach` على أي `IEnumerable<T>` — المصفوفات، والقوائم،
والقواميس — دون إدارة فهرس:

```csharp
string[] fruits = { "apple", "banana", "cherry" };
foreach (string fruit in fruits)
{
    Console.WriteLine(fruit);
}
```

## switch الكلاسيكية

تطابق عبارة `switch` التقليدية قيمة مقابل مجموعة من الحالات
الثابتة وتتطلب `break` صريحة (أو عبارة قفز أخرى) لكل حالة — الانزلاق
إلى الحالة التالية خطأ ترجمة ما لم يكن جسم الحالة فارغاً:

```csharp
int day = 3;
switch (day)
{
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        Console.WriteLine("Weekday");
        break;
    case 6:
    case 7:
        Console.WriteLine("Weekend");
        break;
    default:
        Console.WriteLine("Invalid day");
        break;
}
```

## مطابقة الأنماط بتعبيرات switch

منذ C# 8، يمكن استخدام `switch` كـ*تعبير* يُرجع قيمة، وتذهب
أنماطها إلى أبعد من المساواة بكثير: أنماط النوع، والأنماط
العلائقية، وأنماط الخصائص تتيح لك التفرّع على شكل كائن في مكان
واحد.

```csharp
object shape = new { Kind = "circle", Radius = 3.0 };

string Describe(object value) => value switch
{
    int n when n < 0 => "negative integer",
    int n => $"non-negative integer: {n}",
    string s when s.Length == 0 => "empty string",
    string s => $"string of length {s.Length}",
    null => "nothing at all",
    _ => "something else",
};

Console.WriteLine(Describe(-5));   // negative integer
Console.WriteLine(Describe("hi")); // string of length 2
Console.WriteLine(Describe(null)); // nothing at all
```

يمكن لأنماط الخصائص تفكيك أعضاء كائن ومطابقتها مباشرة، وهذا شائع
عند التعامل مع أنواع السجلات (records):

```csharp
record Point(int X, int Y);

string Classify(Point p) => p switch
{
    { X: 0, Y: 0 } => "origin",
    { X: 0 } => "on the Y axis",
    { Y: 0 } => "on the X axis",
    { X: > 0, Y: > 0 } => "first quadrant",
    _ => "elsewhere",
};

Console.WriteLine(Classify(new Point(0, 0))); // origin
Console.WriteLine(Classify(new Point(3, 5))); // first quadrant
```

يجب أن تكون تعبيرات `switch` مطابقة الأنماط شاملة من وجهة نظر
المترجم — ذراع تجاهل `_` هي الطريقة المعتادة لضمان ذلك، مشابهة
لـ`default` في عبارة `switch` الكلاسيكية.
