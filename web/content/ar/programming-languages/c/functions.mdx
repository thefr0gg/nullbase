دوال C تُمرَّر بالقيمة فقط: يُنسَخ كل وسيط إلى المعاملات المحلية للدالة، لذا لا يمكن لدالة تعديل متغير المستدعي مباشرة أبداً — فقط نسختها الخاصة. هذه الحقيقة الواحدة تشكّل جزءاً كبيراً من كود C الاصطلاحي، بما في ذلك سبب تمرير "المعاملات المُخرَجة" كمؤشرات بدلاً من إرجاعها مباشرة، وسبب كون فهم التمرير بالقيمة شرطاً أساسياً لفهم المؤشرات على الإطلاق.

## تصريح دالة واستدعاؤها

للدالة نوع إرجاع، واسم، وقائمة معاملات، وجسم. تميّز C أيضاً بين **النموذج الأولي** (التوقيع وحده، منتهياً بـ`;`) و**التعريف** (التوقيع مع الجسم) — يسمح لك النموذج الأولي باستدعاء دالة قبل أن يرى المترجم تعريفها الكامل:

```c
#include <stdio.h>

int add(int a, int b); /* prototype: tells the compiler this function exists */

int main(void) {
    int result = add(3, 4); /* can be called here even though add is defined below */
    printf("3 + 4 = %d\n", result);
    return 0;
}

int add(int a, int b) { /* definition */
    return a + b;
}
```

بدون النموذج الأولي، سيكون استدعاء `add` قبل ظهور تعريفها في الملف خطأ ترجمة في C الحديثة — يحتاج المترجم لمعرفة توقيع الدالة قبل أن يتمكن من توليد كود يستدعيها بشكل صحيح.

## التمرير بالقيمة ولماذا يهم

```c
#include <stdio.h>

void tryToDouble(int n) {
    n = n * 2; /* only modifies the local copy */
}

void doubleViaPointer(int *n) {
    *n = *n * 2; /* dereferences the pointer to modify the caller's variable */
}

int main(void) {
    int x = 5;

    tryToDouble(x);
    printf("after tryToDouble: %d\n", x); /* still 5 */

    doubleViaPointer(&x); /* pass the address of x */
    printf("after doubleViaPointer: %d\n", x); /* now 10 */

    return 0;
}
```

تستقبل `tryToDouble` نسخة من قيمة `x` ولا يمكنها التأثير على الأصل. أما `doubleViaPointer` فتستقبل بدلاً من ذلك *عنوان* `x`، وتُفكك المؤشر (dereference) بـ `*n` للوصول إلى ذاكرة المستدعي مباشرة — هكذا تحاكي C "التمرير بالمرجع"، وهذا سبب احتياج دوال مثل `scanf` إلى `&variable` لكل قيمة تحتاج للكتابة فيها.

## الاستدعاء الذاتي (Recursion)

تعمل دالة تستدعي نفسها تماماً كما لو كانت تكراراً، شريطة وجود حالة أساسية توقف الاستدعاء الذاتي:

```c
#include <stdio.h>

long factorial(int n) {
    if (n <= 1) {
        return 1; /* base case */
    }
    return n * factorial(n - 1); /* recursive case */
}

int main(void) {
    for (int i = 1; i <= 6; i++) {
        printf("%d! = %ld\n", i, factorial(i));
    }
    return 0;
}
```

يحصل كل استدعاء لـ `factorial` على إطار مكدس خاص به بنسخته الخاصة من `n` — يستهلك الاستدعاء الذاتي في C ذاكرة مكدس حقيقية لكل استدعاء، وتؤدي حالة أساسية مفقودة أو غير قابلة للوصول إلى فيضان في المكدس بدلاً من حلقة لا نهائية تعلق فقط.
