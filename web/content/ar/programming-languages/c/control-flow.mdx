سيبدو التحكم بمسار التنفيذ في C مألوفاً لأي شخص استخدم لغة من عائلة C (JavaScript، Java، C#، Go) — وهذا ليس صدفة، إذ استعارت جميعها بنية `if` و`for` و`while` مباشرة من C. ما يميّز C فعلاً هو غياب الضمانات: تقبل الشروط أي عدد صحيح (وليس فقط `bool`)، وينزلق `switch` عبر الحالات بشكل افتراضي ما لم تستخدم `break`، ولا تزال `goto` كلمة مفتاحية فعلية وعاملة.

## if / else والقيم المنطقية الضمنية

أي تعبير يُقيَّم إلى قيمة غير صفرية يُعامَل كـ"صحيح" في شرط — لا يوجد اشتراط لنوع منطقي مخصص:

```c
#include <stdio.h>

int main(void) {
    int age = 20;

    if (age < 13) {
        printf("child\n");
    } else if (age < 20) {
        printf("teenager\n");
    } else {
        printf("adult\n");
    }

    int flag = 5; /* nonzero, so this branch runs even though 5 isn't 1 */
    if (flag) {
        printf("flag is truthy: %d\n", flag);
    }

    return 0;
}
```

تلك الكتلة الأخيرة مصدر شائع للأخطاء: `if (flag)` صحيحة لأي عدد صحيح، لذا فإن خطأ كتابي مثل `if (result = 0)` (إسناد، لا مقارنة) يُترجَم بصمت ويُقيَّم دائماً إلى خطأ، لأن `0` نفسها خاطئة — تحذّر معظم المترجمات من هذا مع `-Wall`، لكنه ليس خطأً.

## switch والانزلاق عبر الحالات

يقفز `switch` إلى تسمية `case` المطابقة ثم **يستمر في تنفيذ كل عبارة بعدها** حتى يصل إلى `break` أو نهاية الكتلة — لا يوجد break ضمني كما في بعض اللغات الأخرى:

```c
#include <stdio.h>

int main(void) {
    int day = 3;

    switch (day) {
        case 1:
        case 2:
        case 3:
        case 4:
        case 5:
            printf("weekday\n");
            break;
        case 6:
        case 7:
            printf("weekend\n");
            break;
        default:
            printf("invalid day\n");
    }

    return 0;
}
```

تكديس `case 1:` حتى `case 5:` دون أي عبارات بينها انزلاق مقصود، مُستخدَم هنا لتجميع عدة قيم تحت إجراء واحد. نسيان `break` حيث لم *تقصد* الانزلاق أحد أكثر أخطاء C شيوعاً.

## الحلقات: while وdo-while وfor

```c
#include <stdio.h>

int main(void) {
    int i = 0;
    while (i < 3) {          /* checks condition before each iteration */
        printf("while: %d\n", i);
        i++;
    }

    int j = 0;
    do {                       /* always runs at least once */
        printf("do-while: %d\n", j);
        j++;
    } while (j < 3);

    for (int k = 0; k < 5; k++) {
        if (k == 2) continue;  /* skip the rest of this iteration */
        if (k == 4) break;     /* exit the loop entirely */
        printf("for: %d\n", k);
    }

    return 0;
}
```

`do-while` هي الحلقة الوحيدة المضمونة أن تنفذ جسمها مرة واحدة على الأقل، لأن الشرط يُفحَص *بعد* المرور الأول — وهذا مفيد لأمور مثل "اطلب من المستخدم إدخالاً، ثم أعد الطلب طالما الإدخال غير صالح."
