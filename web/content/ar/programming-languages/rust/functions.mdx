تُعرَّف الدوال في Rust بـ `fn`، وتحتاج كل وسيطة إلى تصريح نوع صريح — بخلاف روابط `let`، لا تستنتج Rust أنواع الوسائط أو الإرجاع من كيفية استدعاء الدالة، لأن ذلك كان سيجعل توقيع الدالة يعتمد على مواضع استدعائها بدلاً من كونه عقداً ثابتاً.

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b // no semicolon: this is the returned expression
}

fn main() {
    let sum = add(3, 4);
    println!("{sum}");
}
```

## التعبيرات مقابل الجمل كقيم إرجاع

آخر تعبير في جسم الدالة يصبح تلقائياً قيمة إرجاعها، *طالما لا توجد فاصلة منقوطة لاحقة له*. أضف فاصلة منقوطة وسيصبح جملة تُقيَّم إلى `()`، ما يغيّر بصمت ما تُعيده الدالة:

```rust
fn add_broken(a: i32, b: i32) -> i32 {
    a + b; // semicolon turns this into a statement, not a return value
} // error: mismatched types — expected i32, found ()
```

لا يزال بإمكانك استخدام الكلمة المفتاحية `return` صراحة — وهي ضرورية للإرجاع المبكر من منتصف دالة — لكن الاعتماد على التعبير اللاحق لمسار الخروج "العادي" هو الأسلوب الاصطلاحي.

```rust
fn classify(n: i32) -> &'static str {
    if n < 0 {
        return "negative"; // early return, semicolon required after return
    }
    if n == 0 {
        "zero"
    } else {
        "positive"
    } // trailing expression: the normal-path return value
}
```

## الإغلاقات (Closures)

**الإغلاق** دالة مجهولة يمكنها التقاط متغيرات من النطاق الذي عُرِّفت فيه — تُكتَب بأنابيب حول وسائطها (`|x| ...`) بدلاً من `fn name(x: T)`. تُستخدم الإغلاقات بكثافة مع دوال المكرِّرات مثل `map` و`filter`.

```rust
fn main() {
    let threshold = 10;
    let numbers = vec![4, 12, 7, 15, 3];

    // the closure captures `threshold` from the surrounding scope
    let above: Vec<i32> = numbers.into_iter().filter(|n| *n > threshold).collect();

    println!("{above:?}"); // [12, 15]
}
```

بخلاف `fn` عادية، يستطيع هذا الإغلاق رؤية `threshold` دون تمريره صراحة — تستعير الإغلاقات أو تنقل المتغيرات التي تشير إليها من بيئتها، وهذا بالضبط ما يتيح لإغلاق `filter` المقارنة بقيمة معرَّفة خارجه.
