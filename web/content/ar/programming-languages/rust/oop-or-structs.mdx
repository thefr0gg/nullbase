لا تملك Rust كلمة مفتاحية `class` ولا وراثة بين أنواع البيانات. بدلاً من ذلك، تقسّم الشيئين اللذين تجمعهما الفئة عادة إلى بنيتين منفصلتين: تحمل **`struct`** البيانات، وتُلحِق كتلة **`impl`** دوالاً بتلك البنية. السلوك المشترك عبر أنواع غير مترابطة — ما تلجأ إليه لغات أخرى كواجهات أو وراثة للتعبير عنه — يُنجَز بـ **السمات (traits)**.

## البنى (Structs)

```rust
struct Rectangle {
    width: f64,
    height: f64,
}

fn main() {
    let rect = Rectangle { width: 30.0, height: 10.0 };
    println!("area: {}", rect.width * rect.height);
}
```

## كتل `impl`: الدوال والدوال المرتبطة

تُلحِق كتلة `impl` دوالاً ببنية. تأخذ الدالة `&self` (أو `&mut self`، أو `self`) كوسيطتها الأولى وتُستدعى بصياغة النقطة؛ أما **الدالة المرتبطة (associated function)** (بلا وسيطة `self`) فتُستدعى على النوع نفسه، وأكثرها شيوعاً كمُنشئ يُسمى `new` بالعرف.

```rust
struct Rectangle {
    width: f64,
    height: f64,
}

impl Rectangle {
    // associated function — no `self`, called as Rectangle::square(5.0)
    fn square(size: f64) -> Rectangle {
        Rectangle { width: size, height: size }
    }

    // method — takes &self, called as rect.area()
    fn area(&self) -> f64 {
        self.width * self.height
    }

    fn scale(&mut self, factor: f64) {
        self.width *= factor;
        self.height *= factor;
    }
}

fn main() {
    let mut sq = Rectangle::square(5.0);
    println!("area before scale: {}", sq.area());

    sq.scale(2.0);
    println!("area after scale: {}", sq.area());
}
```

تستعير `&self` النسخة بشكل غير قابل للتغيير (كافٍ لـ `area`، التي تقرأ فقط)، بينما تستعير `&mut self` النسخة بشكل قابل للتغيير (مطلوب لـ `scale`، التي تكتب إلى `width` و`height`). هذه نفس قاعدة الاستعارة التي تحكم كل مرجع آخر في Rust — الدوال ليست حالة خاصة.

## السمات (Traits): سلوك مشترك دون وراثة

تعرّف **السمة (trait)** مجموعة دوال يَعِد نوع ما بتنفيذها — إجابة Rust عن الواجهة. بخلاف وراثة الفئات، تنفيذ سمة لا يمنح نوعاً أي حقول أو سلوك مجاناً؛ إنه فقط يتطلب من النوع توفير الدوال التي تعلنها السمة (يمكن للسمات أيضاً توفير أجسام دوال افتراضية قد يعيد المنفِّذون تعريفها).

```rust
trait Describe {
    fn describe(&self) -> String;
}

struct Rectangle {
    width: f64,
    height: f64,
}

struct Circle {
    radius: f64,
}

impl Describe for Rectangle {
    fn describe(&self) -> String {
        format!("a {}x{} rectangle", self.width, self.height)
    }
}

impl Describe for Circle {
    fn describe(&self) -> String {
        format!("a circle with radius {}", self.radius)
    }
}

fn print_description(shape: &dyn Describe) {
    println!("{}", shape.describe());
}

fn main() {
    let rect = Rectangle { width: 3.0, height: 4.0 };
    let circle = Circle { radius: 2.0 };

    print_description(&rect);
    print_description(&circle);
}
```

لا تشترك `Rectangle` و`Circle` في أي سلف مشترك ولا حقول — يرتبطان فقط بتنفيذ كليهما لـ `Describe`. تقبل `print_description` نوع `&dyn Describe`، بمعنى "مرجع إلى أي شيء ينفّذ هذه السمة"، وهذه هي كيفية تحقيق Rust للتعددية الشكلية دون تسلسل فئات: العقد المشترك هو السمة، وليس نوعاً أساسياً مشتركاً.
