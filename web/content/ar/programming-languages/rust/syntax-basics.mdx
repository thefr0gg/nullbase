تُعرَّف روابط Rust باستخدام `let`، وكل رابط **غير قابل للتغيير افتراضياً**. هذا هو عكس الافتراضي في معظم اللغات، وهو متعمَّد: يريد المترجم منك اختيار القابلية للتغيير صراحة بـ `mut`، لأن القيمة غير القابلة للتغيير شيء واحد أقل يجب تتبعه عند التفكير في ما يمكن لقطعة كود فعله بها.

```rust
fn main() {
    let x = 5;
    // x = 6; // error: cannot assign twice to immutable variable `x`

    let mut y = 5;
    y = 6; // fine — y was declared mutable
    println!("x = {x}, y = {y}");
}
```

## التظليل (Shadowing)

تتيح لك Rust أيضاً تعريف رابط جديد بنفس *الاسم* لرابط سابق — يُسمى هذا **التظليل** — وهو مختلف عن التغيير. ينشئ التظليل متغيراً جديداً تماماً (يمكن أن يكون له حتى نوع مختلف)، بينما تغيّر `mut` قيمة المتغير الموجود في مكانه.

```rust
fn main() {
    let spaces = "   "; // a &str
    let spaces = spaces.len(); // now a usize — a new binding, same name

    println!("{spaces}"); // 3
}
```

محاولة فعل هذا بـ `mut` بدلاً من ذلك (`let mut spaces = "   "; spaces = spaces.len();`) ستفشل في الترجمة — يحتفظ رابط `mut` بنوعه الأصلي إلى الأبد؛ فقط التظليل يتيح تغيير النوع.

## الأنواع القياسية (Scalar)

أنواع Rust الأولية ثابتة الحجم ومعروفة أثناء الترجمة: أعداد صحيحة موقّعة/غير موقّعة بعدة عروض (`i32`، `u32`، `i64`، `u64`، `usize`، ...)، وأعداد عشرية (`f32`، `f64`)، و`bool`، و`char` (قيمة يونيكود قياسية من 4 بايتات، وليست بايتاً واحداً). تُعامَل حرفيات الأعداد الصحيحة افتراضياً كـ `i32` وحرفيات الأعداد العشرية كـ `f64` ما لم يتطلب السياق غير ذلك.

```rust
fn main() {
    let age: u8 = 30;          // explicit type annotation
    let pi = 3.14159;           // inferred as f64
    let is_active = true;
    let grade: char = 'A';

    println!("{age} {pi} {is_active} {grade}");
}
```

## استنتاج الأنواع والتصريحات

تستنتج Rust الأنواع في معظم الحالات، لذا فإن `let x = 5;` لا تحتاج إلى تصريح — يستنتج المترجم `x: i32` بمفرده. تصبح التصريحات إلزامية عندما لا يستطيع المترجم فعلياً معرفة النوع، مثل تحليل سلسلة نصية إلى رقم:

```rust
fn main() {
    let guess: u32 = "42".parse().expect("not a number");
    println!("{guess}");
}
```

بدون التصريح `: u32` هنا، لا تملك `parse()` طريقة لمعرفة أي نوع رقمي عليها إنتاجه، ويرفض المترجم التخمين — هذا أحد الأماكن القليلة التي يحتاج فيها استنتاج الأنواع إلى تلميح منك.
