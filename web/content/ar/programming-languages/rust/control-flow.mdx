ستبدو بنى التحكم بمسار التنفيذ في Rust مألوفة قادماً من لغات عائلة C، لكن مع التفاف متكرر واحد: `if`، و`loop`، و`match` هي **تعبيرات** — تُنتج قيمة — وليست مجرد جمل. يمكن إسناد تلك القيمة مباشرة إلى متغير، ما يزيل فئة كاملة من الحشو من نوع "أعلن المتغير، ثم أسنده شرطياً في كل فرع".

## `if`/`else` كتعبير

```rust
fn main() {
    let temperature = 15;

    let description = if temperature > 25 {
        "hot"
    } else if temperature > 10 {
        "mild"
    } else {
        "cold"
    };

    println!("It's {description} today");
}
```

يجب أن ينتج كل فرع نفس النوع (هنا، `&str`)، ولا توجد فاصلة منقوطة لاحقة على تعبيرات الفروع — الفاصلة المنقوطة كانت ستحوّل `"mild"` إلى جملة تُقيَّم إلى `()` (الوحدة)، ما لن يطابق نوع الفروع الأخرى وسيفشل في الترجمة.

## الحلقات: `loop`، و`while`، و`for`

تعمل `loop` إلى الأبد حتى `break` صريح، و— مثل `if` — يمكن لـ `loop` أيضاً أن تُنتج قيمة، عبر تمريرها إلى `break`:

```rust
fn main() {
    let mut attempts = 0;

    let result = loop {
        attempts += 1;
        if attempts == 3 {
            break attempts * 10; // loop evaluates to this value
        }
    };

    println!("Succeeded on attempt {attempts}, result = {result}");
}
```

`while` هي الحلقة الشرطية التي تتوقعها من أي لغة عائلة C، و`for` هي طريقة Rust المفضّلة للتكرار — تقريباً دائماً على مدى أو مكرِّر (iterator)، بدلاً من فهرس مُدار يدوياً:

```rust
fn main() {
    let numbers = [10, 20, 30, 40];

    // while: keep going as long as a condition holds
    let mut i = 0;
    while i < numbers.len() {
        println!("index {i}: {}", numbers[i]);
        i += 1;
    }

    // for: iterate directly over the collection, no index bookkeeping
    for n in numbers.iter() {
        println!("value: {n}");
    }
}
```

نسخة `for` هي Rust الاصطلاحية — لا يمكنها الخروج عن الحدود لأنه لا يوجد فهرس ليُخطئ فيه، وتُقرأ كـ "لكل قيمة في هذه المجموعة" بدلاً من "عُد حتى هذا الطول وافهرس داخله".

## `match`

تقارن `match` قيمة بسلسلة من الأنماط وتنفّذ كود أول نمط يناسب. بخلاف `switch` في لغات عائلة C، فإن `match` في Rust **شاملة (exhaustive)** — يرفض المترجم `match` لا تغطي كل قيمة ممكنة ما لم تضف ذراع شمولية `_`.

```rust
fn describe(n: i32) -> &'static str {
    match n {
        0 => "zero",
        1 | 2 | 3 => "small",
        4..=9 => "medium",
        n if n < 0 => "negative",
        _ => "large",
    }
}

fn main() {
    for n in [-5, 0, 2, 7, 100] {
        println!("{n} is {}", describe(n));
    }
}
```

تُظهر هذه الـ `match` الواحدة عدة أشكال أنماط في آن واحد: قيمة محددة (`0`)، وبدائل (`1 | 2 | 3`)، ومدى شامل (`4..=9`)، وشرط حارس (`n if n < 0`)، والشمولية `_`. لأن `match` شاملة، حذف ذراع `_` هنا سيكون خطأ ترجمة — يستطيع المترجم إثبات وجود قيم `i32` لا تغطيها أي ذراع أخرى.
