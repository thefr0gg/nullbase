ستبدو بنى التحكم بمسار التنفيذ في JavaScript مألوفة إذا استخدمت أي لغة
من عائلة C، مع بضع راحات خاصة بـJavaScript فوقها: التسلسل الاختياري
(optional chaining)، والدمج اللاغيابي (nullish coalescing)، وحفنة من
أنماط الحلقات المصمَّمة لتكرار المجموعات بدلاً من نطاقات فهرسة خام.

## الشروط

تعمل `if`/`else if`/`else` كما هو متوقع. تملك JavaScript أيضاً عامل
ثلاثي لتعبيرات شرطية مختصرة، وعاملين يستحقان معرفة جيدة: `??` (الدمج
اللاغيابي) و`?.` (التسلسل الاختياري).

```js
function describe(temp) {
  if (temp < 0) {
    return "freezing";
  } else if (temp < 20) {
    return "cool";
  } else {
    return "warm";
  }
}

console.log(describe(-5)); // "freezing"

const label = temp => (temp < 20 ? "cool" : "warm"); // ثلاثي، بلا حاجة لأقواس
```

يُعيد `??` طرفه الأيمن فقط عندما يكون الطرف الأيسر `null` أو `undefined`
— خلافاً لـ`||`، التي تنتقل أيضاً عند `0` و`""` و`false`. يقصّر `?.`
الدائرة إلى `undefined` بدلاً من الرمي عندما يصادف وصول خاصية `null`/
`undefined` في منتصف السلسلة.

```js
const config = { retries: 0 };

console.log(config.retries || 3);  // 3  — 0 زائفة، لذا || تتجاوزها (عادةً خطأ!)
console.log(config.retries ?? 3);  // 0  — 0 ليست لاغية، لذا ?? تحافظ عليها (عادةً ما تريده)

console.log(config.server?.host ?? "localhost"); // "localhost"، بلا تعطّل عند غياب server
```

## الحلقات

توجد `for` و`while` و`do...while` جميعها بدلالاتها المعتادة. يوجد نمطا
حلقة إضافيان يتكرران عبر المجموعات مباشرة: `for...of` (قيم قابل تكرار —
مصفوفات، سلاسل نصية، `Map`، `Set`) و`for...in` (*مفاتيح* خاصية قابلة
للعد لكائن، محجوز عموماً للكائنات وليس المصفوفات).

```js
const scores = [88, 92, 79];

for (const score of scores) {
  console.log(score);
}
// 88
// 92
// 79

for (let i = 0; i < scores.length; i++) {
  console.log(`index ${i}: ${scores[i]}`);
}

const user = { name: "ada", role: "admin" };
for (const key in user) {
  console.log(key, user[key]);
}
```

يخرج `break` من الحلقة كلياً؛ يتخطى `continue` إلى التكرار التالي.
يمكن لكليهما استهداف حلقة خارجية مُسمّاة عندما تحتاج للهروب من حلقات
متداخلة من الداخل.

## switch

تقارن `switch` بـ`===` مقابل كل `case`. نسيان `break` أحد أكثر أخطاء
JavaScript شيوعاً — ينساب التنفيذ إلى الحالة التالية ما لم توقفه صراحة.

```js
function trafficAction(color) {
  switch (color) {
    case "red":
      return "stop";
    case "yellow":
      return "slow down";
    case "green":
      return "go";
    default:
      return "unknown signal";
  }
}

console.log(trafficAction("yellow")); // "slow down"
```
