أنشأ Brendan Eich لغة JavaScript عام 1995 في نحو عشرة أيام، بهدف أصلي هو
جعل صفحات الويب تفاعلية داخل Netscape Navigator. رغم تلك النشأة المتسرعة
— واسم اختير لأسباب تسويقية أكثر من أي قرابة حقيقية بـJava — أصبحت اللغة
الوحيدة التي تعمل أصلياً في كل متصفح ويب، ومنذ ظهور Node.js عام 2009،
خياراً من الدرجة الأولى للخوادم وأدوات سطر الأوامر وتطبيقات سطح المكتب
أيضاً. اللغة نفسها موحَّدة تحت اسم ECMAScript، وتبدو JavaScript الحديثة
(تُسمّى عادةً "ES6+" نسبةً إلى مراجعة 2015) مختلفة تماماً عن JavaScript
أوائل الألفينيات.

JavaScript ديناميكية الأنواع (تُفحَص أنواع المتغيرات وقت التشغيل، وليس
وقت التصريف)، وأحادية الخيط بحلقة أحداث (event loop) للتزامن، ومبنية على
النماذج الأولية (prototype-based) في جوهرها رغم أنها تعرض الآن صيغة
`class` فوق ذلك. كما أنها معروفة بتساهلها: عمليات ستكون خطأ تصريف في
لغات كثيرة — مقارنة سلسلة نصية برقم، استدعاء تابع على `undefined` — غالباً
ما تُسمَح وتنتج نتيجة، مفاجئة أحياناً.

## ما الذي يميز JavaScript

- **تعمل في كل مكان.** المتصفحات، الخوادم (Node.js، Deno، Bun)، الأجهزة
  المحمولة (React Native)، وحتى الأجهزة المدمجة. لا لغة أخرى لها هذا
  الانتشار.
- **أحادية الخيط بحلقة أحداث.** لا تُشغِّل JavaScript أبداً قطعتين من
  الكود في آنٍ واحد. تُعالَج عمليات الإدخال/الإخراج الطويلة (طلبات
  الشبكة، قراءات الملفات، المؤقتات) بشكل غير متزامن عبر ردود النداء
  (callbacks) أو Promises أو `async`/`await`، دون حجب بقية البرنامج.
- **ديناميكية وضعيفة الأنواع.** لا نوع مُعلَن للمتغيرات؛ يمكن لنفس
  المتغير أن يحمل رقماً، ثم سلسلة نصية، ثم دالة.
- **دوال من الدرجة الأولى.** الدوال قيم — يمكنك تخزينها في متغيرات،
  وتمريرها كوسائط، وإعادتها من دوال أخرى. هذا ما يجعل الإغلاقات
  (closures) وواجهات ردود النداء طبيعية في JS.
- **كائنات مبنية على النماذج الأولية.** ترث الكائنات مباشرة من كائنات
  أخرى عبر سلسلة نماذج أولية، وليس من أصناف بالمعنى الكلاسيكي. صيغة
  `class` (المضافة في ES6) سكّر لغوي مريح فوق هذه الآلية، وليست نموذج
  وراثة مختلفاً.

إليك مثالاً صغيراً لكنه كامل:

```js
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("nullbase"));
```

تشغيل هذا بـNode.js (`node greet.js`) أو لصقه في وحدة تحكم متصفح ينتج نفس
المخرجات — لا خطوة تصريف، ونفس الصيغة تعمل في كلتا البيئتين.

## متى تلجأ إلى JavaScript

JavaScript الخيار الوحيد لمنطق جانب العميل في صفحة ويب، وخيار قوي
للخوادم عندما تريد مشاركة كود (منطق التحقق، نماذج البيانات) بين الواجهة
الأمامية والخلفية، أو عندما يكون حِمل عملك ثقيل الإدخال/الإخراج — طلبات
شبكة متزامنة كثيرة — بدلاً من ثقيل المعالجة. إنها خيار أضعف للحساب
الرقمي كثيف المعالجة أو برمجة الأنظمة، حيث تمنح اللغات المصرَّفة ثابتة
الأنواع أداءً يمكن التنبؤ به أكثر وتلتقط أخطاء أكثر قبل أن يعمل الكود
مطلقاً.

## ما التالي

تستعرض الصفحات التالية JavaScript من الأساس: المتغيرات والبنية، والتحكم
بمسار التنفيذ، والدوال والإغلاقات، وهياكل البيانات المدمجة، والأصناف
والوراثة النموذجية الأولية، ومعالجة الأخطاء، ونظام الوحدات وnpm، لتنتهي
بالبرمجة غير المتزامنة بـPromises وasync/await.
