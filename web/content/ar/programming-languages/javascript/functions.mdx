الدوال في JavaScript قيم: يمكنك إسنادها إلى متغيرات، وتمريرها كوسائط،
وتخزينها في مصفوفات، وإعادتها من دوال أخرى. هذه الخاصية "الدوال من الدرجة
الأولى" هي الأساس لردود النداء (callbacks)، وتوابع المصفوفة مثل
`map`/`filter`، والإغلاقات.

## تصريح الدوال

توجد ثلاث طرق شائعة لكتابة دالة، وتختلف في أكثر من مجرد الصيغة.

```js
// تصريح دالة — مرفوعة (hoisted)، يمكن استدعاؤها قبل ظهور تعريفها
function add(a, b) {
  return a + b;
}

// تعبير دالة — غير مرفوع، يوجد فقط بمجرد تنفيذ هذا السطر
const subtract = function (a, b) {
  return a - b;
};

// دالة سهم — صيغة موجزة، بلا `this` أو `arguments` خاصين بها
const multiply = (a, b) => a * b;
```

تُرفَع تصريحات الدوال بجسمها الكامل، لذا استدعاء إحداها قبل سطرها في
الملف يعمل بلا مشكلة. تعبيرات الدوال ودوال الأسهم المُسنَدة إلى
`const`/`let` لا تُرفَع — يوجد المتغير (في "منطقة ميتة مؤقتة") لكنه غير
قابل للاستدعاء حتى يُنفَّذ الإسناد.

## دوال الأسهم

دوال الأسهم أكثر من مجرد اختصار. ليس لها `this` أو `arguments` أو
`super` خاصة بها — بل تلتقطها من النطاق المحيط بدلاً من ذلك. هذا يجعلها
الخيار الصحيح لردود النداء التي تريد فيها بقاء `this` مرتبطاً بالسياق
المحيط، والخيار الخاطئ لتوابع الكائنات التي تحتاج `this` خاصة بها.

```js
const doubled = [1, 2, 3].map(n => n * 2);
console.log(doubled); // [2, 4, 6]

const counter = {
  count: 0,
  incrementBad: () => {
    this.count++; // `this` هنا ليست كائن counter — دوال الأسهم
                  // لا تحصل على `this` خاصة بها، لذا هذا لا يفعل شيئاً مفيداً بصمت
  },
  incrementGood() {
    this.count++; // تابع عادي — تشير `this` بشكل صحيح إلى counter
  },
};
```

## المعاملات الافتراضية والباقية (Rest)

يمكن أن تحمل المعاملات قيماً افتراضية، تُستخدَم فقط عندما يكون الوسيط
`undefined` (وليس لأي قيمة زائفة أخرى). تجمع معاملات rest أي وسائط متبقية
في مصفوفة حقيقية.

```js
function createUser(name, role = "member") {
  return { name, role };
}

console.log(createUser("ada"));            // { name: "ada", role: "member" }
console.log(createUser("grace", "admin")); // { name: "grace", role: "admin" }

function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

console.log(sum(1, 2, 3, 4)); // 10
```

## الإغلاقات (Closures)

الإغلاق دالة "تتذكر" متغيرات النطاق الذي أُنشئت فيه، حتى بعد انتهاء تنفيذ
ذلك النطاق الخارجي. هكذا تحصل على حالة خاصة دون أصناف: كل استدعاء لدالة
خارجية يُنشئ نطاقاً جديداً ومعزولاً يمكن للدوال الداخلية الاستمرار في
الإشارة إليه.

```js
function makeCounter() {
  let count = 0; // خاصة بكل عدّاد — غير قابلة للوصول من الخارج

  return {
    increment() {
      count += 1;
      return count;
    },
    reset() {
      count = 0;
    },
  };
}

const counterA = makeCounter();
const counterB = makeCounter();

console.log(counterA.increment()); // 1
console.log(counterA.increment()); // 2
console.log(counterB.increment()); // 1 — count منفصلة تماماً
```

كل استدعاء لـ`makeCounter()` يُنشئ متغير `count` جديداً، وتشكّل التوابع
المُعادَة إغلاقاً حول تلك المتغيرة المحدَّدة — لا تتداخل `counterA` و
`counterB` أبداً مع بعضهما بعضاً.
