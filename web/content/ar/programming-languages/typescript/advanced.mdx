**الأنواع العامة (generics)** هي الميزة المتوسطة المميزة لـTypeScript —
الأداة لكتابة كود يعمل مع أنواع كثيرة دون اللجوء إلى `any` وفقدان أمان
الأنواع تماماً. تأخذ الدالة أو النوع العام **معامل نوع (type parameter)**،
يُسمَّى اصطلاحياً `T`، يعمل كعنصر نائب يُملَأ بنوع محدَّد في كل موضع
استدعاء.

## المشكلة التي تحلها الأنواع العامة

دون الأنواع العامة، إما أن تكتب دالة لكل نوع على حدة، أو توسّع إلى `any`
وتفقد كل الفحص:

```ts
function firstAny(arr: any[]): any {
  return arr[0];
}

const num = firstAny([1, 2, 3]); // typed any — no error if you misuse it
num.toUpperCase(); // no compile error, but this crashes at runtime
```

تُترجَم `firstAny` بنجاح لأي مصفوفة، لكن قيمة الإرجاع من نوع `any`، لذا
فإن استدعاء `.toUpperCase()` على رقم يمرّ مباشرة عبر فاحص الأنواع
وينفجر أثناء التشغيل.

## كتابة دالة عامة

```ts
function first<T>(arr: T[]): T {
  return arr[0];
}

const num = first([1, 2, 3]); // T inferred as number; num: number
const str = first(["a", "b"]); // T inferred as string; str: string

num.toUpperCase(); // Type error: Property 'toUpperCase' does not exist on type 'number'
```

لا تزال `first<T>` تعمل مع مصفوفة من أي نوع، تماماً مثل `firstAny` —
لكن نوع الإرجاع الآن مرتبط بما استُنتِج له `T` في ذلك الاستدعاء المحدَّد.
تُعيد `first([1, 2, 3])` النوع `number`، لذا يُكتشَف استدعاء
`.toUpperCase()` على النتيجة فوراً، خلافاً للنسخة المبنية على `any`.

## تقييد معامل النوع

يُقيِّد `extends` ما يمكن أن يكونه معامل النوع، حتى تتمكن من استخدام
عمليات لا معنى لها إلا لمجموعة فرعية من الأنواع بأمان:

```ts
function getLength<T extends { length: number }>(value: T): number {
  return value.length;
}

getLength("hello"); // 5 — string has .length
getLength([1, 2, 3]); // 3 — array has .length
getLength(42); // Type error: Argument of type 'number' is not assignable to parameter of type '{ length: number }'
```

تعني `T extends { length: number }`: "يمكن أن يكون `T` أي شيء، طالما
أن له خاصية `.length` من نوع number" — لا تحصر هذه العبارة `T` في نوع
محدَّد واحد، بل فقط في الأشكال التي تجعل كتابة `value.length` آمنة.

## الأنواع والواجهات العامة

لا تقتصر الأنواع العامة على الدوال — يمكن لـ`type` أو `interface` أيضاً
أن تأخذ معامل نوع، وهذا ما يتيح لشكل واحد قابل لإعادة الاستخدام مثل
`Box<T>` أن يصف صندوقاً يحمل أي نوع من المحتوى:

```ts
interface Box<T> {
  contents: T;
}

const numberBox: Box<number> = { contents: 42 };
const stringBox: Box<string> = { contents: "hello" };

numberBox.contents = "oops"; // Type error: Type 'string' is not assignable to type 'number'
```

بمجرد إعلان `numberBox` كـ`Box<number>`، يصبح `T` ثابتاً عند `number`
لذلك الصندوق تحديداً — لا يمكن أن تحمل `contents` أبداً `string`، رغم أن
`Box<T>` نفسها كُتبت مرة واحدة فقط وتعمل مع أي `T`.
