يجمع **الصنف** في C++ البيانات (المتغيرات الأعضاء) والسلوك (الدوال الأعضاء) في نوع واحد. بخلاف `struct` بسيطة في C، يتحكم صنف C++ بدقة في أي أجزاء من تلك الحزمة يُسمح للكود الخارجي بلمسها — الآلية التي تجعل التغليف (encapsulation) ممكناً.

## المُنشئات ومحددات الوصول

```cpp
#include <iostream>
#include <string>

class BankAccount {
private:
    std::string owner;
    double balance;

public:
    // constructor: runs automatically when a BankAccount is created
    BankAccount(std::string ownerName, double startingBalance) {
        owner = ownerName;
        balance = startingBalance;
    }

    void deposit(double amount) {
        balance += amount;
    }

    double getBalance() const {
        return balance;
    }
};

int main() {
    BankAccount account("Ada", 100.0);
    account.deposit(50.0);
    std::cout << account.getBalance() << "\n"; // 150

    // account.balance = 1000000;  // would fail to compile: balance is private
    return 0;
}
```

الأعضاء `private` (`owner`، و`balance`) يمكن الوصول إليها فقط من داخل الدوال الأعضاء الخاصة بالصنف نفسه؛ بينما تشكّل الأعضاء `public` واجهة الصنف الخارجية. هذا سبب عدم إمكانية لمس `account.balance` مباشرة من `main` — يجب أن يمر كل وصول عبر `deposit()` و`getBalance()`، مما يتيح للصنف فرض قواعده الخاصة (مثل رفض إيداع سالب) بدلاً من الوثوق بكل مستدعٍ ليفعل الصواب. **المُنشئ** — دالة بنفس اسم الصنف وبلا نوع إرجاع — يعمل تلقائياً كلما أُنشئ كائن، ما يضمن أن كل `BankAccount` يبدأ في حالة صالحة بدلاً من الاعتماد على استدعاء `init()` منفصل يسهل نسيانه.

## الوراثة

```cpp
#include <iostream>
#include <string>

class Animal {
protected:
    std::string name;

public:
    Animal(std::string animalName) : name(animalName) {}

    virtual std::string speak() const {
        return name + " makes a sound.";
    }
};

class Dog : public Animal {
public:
    Dog(std::string dogName) : Animal(dogName) {}

    std::string speak() const override {
        return name + " barks.";
    }
};

int main() {
    Animal generic("Creature");
    Dog rex("Rex");

    std::cout << generic.speak() << "\n"; // Creature makes a sound.
    std::cout << rex.speak() << "\n";     // Rex barks.
    return 0;
}
```

تجعل `class Dog : public Animal` صنف `Dog` يرث أعضاء `Animal` — الأعضاء `protected` (مثل `name`) مرئية للأصناف المشتقة لكنها لا تزال مخفية عن الكود الخارجي، حل وسط بين `private` و`public`. يستدعي `Animal(dogName)` في قائمة تهيئة مُنشئ `Dog` مُنشئ الصنف الأساسي صراحة، لأن الصنف المشتق لا يعرف تلقائياً كيفية تهيئة الجزء الأساسي من نفسه. وضع علامة `virtual` على `speak()` في الصنف الأساسي و`override` في المشتق يُفعّل **تعدد الأشكال (polymorphism)**: استدعاء `speak()` عبر مرجع أو مؤشر للصنف الأساسي يُرسل إلى نسخة النوع المشتق الفعلي في وقت التشغيل، بدلاً من استدعاء `Animal::speak()` دائماً.
