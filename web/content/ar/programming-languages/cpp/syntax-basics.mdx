تتمتع C++ بنوعية **ثابتة**: لكل متغير نوع ثابت في وقت الترجمة، ويرفض المترجم برنامجاً لا تطابق فيه قيمة النوع المُسندة إليه. هذا يلتقط فئة كاملة من الأخطاء قبل أن يعمل البرنامج أصلاً، بثمن الاضطرار لكتابة الأنواع (أو استنتاجها) مسبقاً بدلاً من تقريرها في وقت التشغيل.

```cpp
#include <iostream>
#include <string>

int main() {
    int age = 30;
    double price = 19.99;
    char grade = 'A';
    bool isActive = true;
    std::string name = "Ada";

    std::cout << name << " is " << age << " years old.\n";
    return 0;
}
```

الأنواع المدمجة الأساسية هي `int` (أعداد صحيحة)، و`double`/`float` (أعداد فاصلة عائمة)، و`char` (بايت واحد، عادة حرف واحد)، و`bool` (`true`/`false`). أما `std::string`، من رأس `<string>`، فليست نوعاً مدمجاً بل جزءاً من المكتبة القياسية — تدير ذاكرتها الخاصة، لذا فهي بخلاف مصفوفة أحرف على طراز C الخام تنمو وتتقلص بأمان مع إسناد نص إليها.

## `auto` و`const`

```cpp
#include <iostream>

int main() {
    auto count = 42;          // deduced as int
    auto ratio = 3.14;        // deduced as double
    const int maxRetries = 5; // cannot be reassigned

    std::cout << "count=" << count << " ratio=" << ratio << " max=" << maxRetries << "\n";
    return 0;
}
```

يطلب `auto` من المترجم استنتاج نوع متغير من قيمته الابتدائية بدلاً من كتابته صراحة — يظل المتغير ثابت النوع، لكنه مُستنتَج بدلاً من مكتوب صراحة. تُميّز `const` متغيراً كغير قابل للتعديل بعد التهيئة؛ محاولة `maxRetries = 10;` لاحقاً في الدالة ستفشل في الترجمة. استخدام `const` أينما لا ينبغي لقيمة أن تتغير فعلياً يوثّق تلك النية للقارئ ويتيح للمترجم التقاط إعادة إسناد عرضية.

## قراءة الإدخال

```cpp
#include <iostream>

int main() {
    std::string name;
    int age;

    std::cout << "Enter your name: ";
    std::cin >> name;
    std::cout << "Enter your age: ";
    std::cin >> age;

    std::cout << name << " is " << age << " years old.\n";
    return 0;
}
```

تقرأ `std::cin` (المُصرَّح عنها في `<iostream>`) من الإدخال القياسي بنفس الطريقة التي تكتب بها `std::cout` إلى الإخراج القياسي، باستخدام `>>` بدلاً من `<<`. بشكل افتراضي تقرأ `std::cin >> name` رمزاً واحداً مفصولاً بمسافة بيضاء، لا سطراً كاملاً — قراءة `"Ada Lovelace"` بهذه الطريقة ستلتقط فقط `"Ada"`؛ يتطلب السطر الكامل `std::getline(std::cin, name)` بدلاً من ذلك.
