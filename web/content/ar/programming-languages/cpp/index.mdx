**C++** لغة برمجة مُترجمة، وثابتة الأنواع، ومتعددة الأنماط، صممها في الأصل بيارن ستروستروب في أوائل الثمانينيات باسم "C مع الأصناف" — امتداد لـ C أضاف ميزات كائنية التوجه دون التخلي عن تحكم C منخفض المستوى في الذاكرة والعتاد. بعد عقود، لا يزال هذا المزيج هو سبب اختيارها: تتيح لك C++ كتابة تجريدات عالية المستوى (الأصناف، والقوالب، والمكتبة القياسية) مع الاحتفاظ بالقدرة على إدارة الذاكرة يدوياً والاستدلال بدقة على ما تفعله الآلة فعلياً.

غالباً ما تُلخَّص فلسفة اللغة التوجيهية بـ**التجريد بلا كلفة زائدة** — ميزة لا تستخدمها لا ينبغي أن تكلفك شيئاً، وميزة تستخدمها لا ينبغي أن تكلف أكثر من كتابة الكود المكافئ يدوياً. هذا سبب هيمنة C++ في المجالات التي لا يُتنازل فيها عن الأداء: محركات الألعاب، وأنظمة التشغيل، والمتصفحات، والبرامج الثابتة المدمجة، وأنظمة التداول عالي التردد، وأجزاء كبيرة من المكتبات القياسية وبيئات التشغيل التي تُبنى عليها لغات أخرى.

بخلاف اللغات المفسَّرة أو المُترجمة بواسطة JIT، تُترجَم برامج C++ مسبقاً إلى كود آلة أصلي بواسطة مترجم (GCC، أو Clang، أو MSVC). لا يوجد مفسِّر وقت تشغيل ولا جامع قمامة تلقائي — تُحدَّد أعمار الكائنات بالنطاق (scope)، وتُدار في C++ الحديثة عبر نمط يُدعى RAII بدلاً من جامع قمامة في الخلفية يقرر متى يستعيد الذاكرة.

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

يحتاج كل برنامج C++ إلى دالة `int main()` — إنها نقطة الدخول المخصَّصة التي يستدعيها نظام التشغيل لبدء التنفيذ. يستورد `#include <iostream>` تصريحات `std::cout`، دفق الإخراج القياسي في C++، بينما يفرّغ `std::endl` الدفق ويكتب سطراً جديداً. إرجاع `0` من `main` يخبر العملية المستدعية أن البرنامج انتهى بنجاح؛ وتشير قيمة غير صفرية إلى خطأ.

```cpp
#include <iostream>

int square(int n) {
    return n * n;
}

int main() {
    int value = 6;
    std::cout << "Square: " << square(value) << std::endl;
    return 0;
}
```

يُظهر هذا المثال أمرين يتكرران في C++ بأكملها: تُصرَّح الدوال بنوع إرجاع صريح (`int square(int n)`)، ويُسلسل `std::cout` عدة قيم بـ `<<` في عبارة واحدة — يُرجع كل استدعاء لـ `<<` الدفق نفسه، وهذا سبب إمكانية ربطها ببعضها.

الانتقال من الكود المصدري إلى برنامج يعمل عملية متعددة المراحل: توسّع المعالجة المسبقة توجيهات `#include` والماكروهات، ويترجم المترجم الناتج إلى ملف كائن، ويجمع الرابط ملفات الكائنات (وأي مكتبات) في ملف تنفيذي نهائي. تُترجَم كل ملف `.cpp` بشكل مستقل إلى ملف كائن خاص به قبل الربط — تفصيل يهم بمجرد أن يمتد مشروع لأكثر من ملف مصدري واحد.
