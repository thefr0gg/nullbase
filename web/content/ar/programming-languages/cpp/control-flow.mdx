تقرر عبارات التحكم بمسار التنفيذ أي كود يعمل فعلياً وكم مرة — بدونها سيكون برنامج C++ مجرد تسلسل مستقيم من العبارات يُنفَّذ مرة واحدة، من الأعلى إلى الأسفل.

## `if` / `else if` / `else`

```cpp
#include <iostream>

int main() {
    int score = 82;

    if (score >= 90) {
        std::cout << "Grade: A\n";
    } else if (score >= 80) {
        std::cout << "Grade: B\n";
    } else if (score >= 70) {
        std::cout << "Grade: C\n";
    } else {
        std::cout << "Grade: F\n";
    }
    return 0;
}
```

تُقيَّم الشروط من الأعلى إلى الأسفل، ويعمل أول فرع شرطه `true` — ويُتجاوَز الباقي، حتى لو كان شرط لاحق سيكون `true` أيضاً. `if` مجردة بلا `else` مطابق لا تفعل شيئاً ببساطة عندما يكون شرطها `false`.

## `switch`

```cpp
#include <iostream>

int main() {
    int day = 3;

    switch (day) {
        case 1:
            std::cout << "Monday\n";
            break;
        case 2:
            std::cout << "Tuesday\n";
            break;
        case 3:
            std::cout << "Wednesday\n";
            break;
        default:
            std::cout << "Some other day\n";
            break;
    }
    return 0;
}
```

يقارن `switch` قيمة واحدة بمجموعة من الحالات الثابتة. تحتاج كل `case` إلى `break` صريحة — بدونها، **ينزلق** التنفيذ إلى الحالة التالية بغض النظر عن مطابقة قيمتها، وهي خاصية غريبة في C++ موروثة من C وتُعد مصدراً شائعاً للأخطاء عند نسيانها.

## الحلقات

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores = {70, 85, 90, 60};

    // classic for loop, index-based
    for (int i = 0; i < scores.size(); i++) {
        std::cout << "Index " << i << ": " << scores[i] << "\n";
    }

    // range-based for (C++11), no index needed
    for (int score : scores) {
        if (score < 65) continue;
        std::cout << "Passed with " << score << "\n";
    }

    // while loop
    int attempts = 0;
    while (attempts < 3) {
        std::cout << "Attempt " << attempts << "\n";
        attempts++;
    }
    return 0;
}
```

تمنح حلقة `for (init; condition; increment)` الكلاسيكية تحكماً كاملاً في متغير الحلقة، وهذا يهم عندما تحتاج الفهرس نفسه (كما أعلاه، لطباعته) أو تحتاج للتخطي بأكثر من واحد. أما **حلقة for المدى-محورة**، المُضافة في C++11، فتُكرر مباشرة على عناصر حاوية دون فهرسة يدوية — وهي الشكل المُفضَّل كلما لم تكن الحاجة إلى الفهرس قائمة، إذ لا يوجد خطأ إزاحة بواحد ليخطئ فيه. تُخطي `continue` مباشرة إلى الدورة التالية؛ بينما `break` (غير موضحة هنا) ستخرج من الحلقة كلياً. تعمل `while` طالما شرطها قائم، ويُفحص قبل كل دورة — إذا كان الشرط `false` من البداية، لا يعمل الجسم أبداً، بخلاف `do...while`، التي تعمل الجسم دائماً مرة واحدة على الأقل.
