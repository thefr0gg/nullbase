لدالة C++ نوع إرجاع صريح، واسم، وقائمة معاملات ثابتة — يفحص المترجم كل موقع استدعاء مقابل ذلك التوقيع، لذا فإن استدعاء دالة بعدد أو نوع خاطئ من الوسائط خطأ ترجمة، لا شيء يُكتشف في وقت التشغيل.

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

double average(int a, int b, int c) {
    return (a + b + c) / 3.0;
}

int main() {
    std::cout << add(4, 5) << "\n";
    std::cout << average(2, 4, 9) << "\n";
    return 0;
}
```

## التمرير بالقيمة مقابل التمرير بالمرجع

```cpp
#include <iostream>

void incrementByValue(int n) {
    n = n + 1; // only modifies the local copy
}

void incrementByReference(int& n) {
    n = n + 1; // modifies the caller's variable
}

int main() {
    int x = 10;
    incrementByValue(x);
    std::cout << "After by-value: " << x << "\n"; // still 10

    incrementByReference(x);
    std::cout << "After by-reference: " << x << "\n"; // now 11
    return 0;
}
```

بشكل افتراضي، تُمرِّر C++ الوسائط **بالقيمة** — تستقبل الدالة نسخة، لذا لا تؤثر التغييرات داخلها أبداً على متغير المستدعي. إضافة `&` إلى نوع معامل يجعله معامل **مرجع**: تصبح `n` اسماً آخر لمتغير المستدعي الفعلي، لذا تكون التعديلات داخل الدالة مرئية خارجها. هذه أيضاً طريقة C++ لتجنب نسخ الكائنات الكبيرة: معامل `const std::string&`، مثلاً، يتيح لدالة قراءة سلسلة نصية دون نسخها ودون السماح بتعديلها.

## الوسائط الافتراضية والحمل الزائد

```cpp
#include <iostream>
#include <string>

void greet(const std::string& name, const std::string& greeting = "Hello") {
    std::cout << greeting << ", " << name << "!\n";
}

int multiply(int a, int b) {
    return a * b;
}

double multiply(double a, double b) {
    return a * b;
}

int main() {
    greet("Ada");                 // uses the default greeting
    greet("Grace", "Welcome");    // overrides it

    std::cout << multiply(3, 4) << "\n";       // calls the int version
    std::cout << multiply(2.5, 4.0) << "\n";   // calls the double version
    return 0;
}
```

قيمة `greeting` الافتراضية تعني أن بإمكان المستدعين حذفها كلياً؛ يجب أن تأتي الوسيطة الافتراضية بعد كل المعاملات التي لا قيمة افتراضية لها. يتيح **الحمل الزائد** لعدة دوال مشاركة اسم طالما اختلفت قوائم معاملاتها — يختار المترجم النسخة المطابقة بناءً على أنواع الوسائط في كل موقع استدعاء، ويُحل الأمر بالكامل في وقت الترجمة.
