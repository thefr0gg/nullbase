تمنحك C++ خياراً من الحاويات بحسب ما إذا كان الحجم معروفاً مسبقاً وما إذا كنت تحتاج بحثاً سريعاً بالمفتاح بدلاً من الموضع — اختيار الحاوية الخاطئة مصدر شائع للأخطاء والبطء غير الضروري معاً.

## المصفوفات

```cpp
#include <iostream>

int main() {
    int scores[5] = {90, 85, 77, 92, 60};

    for (int i = 0; i < 5; i++) {
        std::cout << "scores[" << i << "] = " << scores[i] << "\n";
    }
    return 0;
}
```

لمصفوفة على طراز C مثل `scores` حجم ثابت في وقت الترجمة ولا فحص للحدود — قراءة أو كتابة `scores[5]` تُترجَم بلا مشكلة لكنها تقرأ خارج ذاكرة المصفوفة، وهو سلوك غير معرَّف يمكن أن يُفسد بيانات غير متعلقة بصمت. لا يُتتبَّع حجمها أيضاً في وقت التشغيل؛ تحتاج دالة تستقبل `scores` إلى تمرير الطول بشكل منفصل.

## `std::vector`

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores;
    scores.push_back(90);
    scores.push_back(85);
    scores.push_back(77);

    scores.push_back(100);
    std::cout << "Count: " << scores.size() << "\n";

    for (int s : scores) {
        std::cout << s << " ";
    }
    std::cout << "\n";

    scores.pop_back();
    std::cout << "After pop_back, count: " << scores.size() << "\n";
    return 0;
}
```

`std::vector<int>` مصفوفة قابلة لتغيير الحجم: تُلحق `push_back` عنصراً وتُنمِّي التخزين الأساسي تلقائياً، وتُبلغ `size()` عن عدد العناصر الحالي، وتُزيل `pop_back()` العنصر الأخير. بخلاف مصفوفة خام، يعرف المتجه دائماً طوله الخاص ويدير ذاكرته الخاصة — وهذا سبب كون `std::vector` الخيار الافتراضي لتسلسل من القيم في C++ الحديثة، محجوزة مصفوفة ثابتة الحجم على طراز C فقط عندما يكون الحجم ثابتاً حقاً ومعروفاً في وقت الترجمة (أو في `std::array`، الذي يوفر ضمان الحجم الثابت نفسه بواجهة أكثر أماناً).

## `std::map`

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> ages;
    ages["Ada"] = 36;
    ages["Grace"] = 85;
    ages["Alan"] = 41;

    ages["Ada"] = 37; // overwrites the existing entry

    for (const auto& pair : ages) {
        std::cout << pair.first << " -> " << pair.second << "\n";
    }
    return 0;
}
```

يخزّن `std::map<K, V>` أزواج مفتاح-قيمة ويحافظ عليها مرتبة داخلياً بالمفتاح (باستخدام شجرة ثنائية متوازنة)، لذا فإن التكرار على خريطة يزور دائماً المدخلات بترتيب تصاعدي للمفتاح — هنا، أبجدياً بالاسم. تُدرج الفهرسة بـ `ages["Ada"]` مدخلاً جديداً أو تُحدِّث الموجود إن كان المفتاح موجوداً بالفعل؛ البحث عن مفتاح غير موجود بـ `[]` يُدرجه بصمت بقيمة مُنشأة افتراضياً، وهذه مفاجأة شائعة — `ages.find("Bob")` أو `ages.count("Bob")` طريقتان أكثر أماناً للتحقق من وجود مفتاح دون إدراجه.
