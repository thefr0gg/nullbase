MySQL قاعدة بيانات علائقية بنمط عميل-خادم، مثل [PostgreSQL](/ar/databases/postgresql) — الاثنان هما الخياران المفتوحا المصدر المهيمنان ويُقارَنان باستمرار، لكنهما تباعدا من أولويات تصميم مختلفة: أعطت MySQL الأولوية لسرعة القراءة الخام والبساطة لحالة تطبيق الويب الشائعة (شغّلت حرف "M" في حزمة LAMP الكلاسيكية — Linux، Apache، MySQL، PHP)، بينما أعطى Postgres الأولوية للامتثال للمعايير والصحة أولاً.

## جرّبه (SQL قياسي، يعمل على المحرك داخل المتصفح)

يستخدم ذلك الاستعلام `ON CONFLICT ... DO UPDATE` (صياغة "الإدراج-أو-التحديث" القياسية في SQLite وPostgres) لأن هذا ما يدعمه المحرك داخل المتصفح فعلياً — مكافئ MySQL، الموضَّح أدناه، غير قابل للتشغيل هنا لكنه يفعل نفس الشيء.

## ما هو خاص فعلياً بـ MySQL

```sql
-- AUTO_INCREMENT: صياغة MySQL لمفتاح أساسي تلقائي الزيادة
CREATE TABLE users (id INT AUTO_INCREMENT PRIMARY KEY, email VARCHAR(255) UNIQUE);

-- صياغة الإدراج-أو-التحديث الخاصة بـ MySQL
INSERT INTO page_views (path, views) VALUES ('/home', 1)
ON DUPLICATE KEY UPDATE views = views + 1;

-- اختيار محرك التخزين، لكل جدول
CREATE TABLE logs (id INT PRIMARY KEY, message TEXT) ENGINE=InnoDB;

-- LIMIT مع إزاحة، الصيغة بفاصلة (صالحة أيضاً في Postgres، ليست SQL قياسية)
SELECT * FROM users LIMIT 10, 20; -- skip 10, take 20
```
