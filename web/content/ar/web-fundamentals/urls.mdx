**عنوان URL** (محدد موقع الموارد الموحد) يحدد مورداً وكيفية الوصول إليه. لكل جزء منه وظيفة:

<UrlAnatomy
  parts={[
    { text: "https://", label: "المخطط", color: "blue" },
    { text: "api.example.com", label: "المضيف", color: "green" },
    { text: ":443", label: "المنفذ", color: "orange" },
    { text: "/v1/users", label: "المسار", color: "purple" },
    { text: "?active=true", label: "الاستعلام", color: "red" },
    { text: "#profile", label: "الجزء", color: "default" },
  ]}
/>

- **`https`** — البروتوكول/المخطط. يخبر المتصفح بالبروتوكول الذي سيستخدمه للتحدث مع المضيف.
- **`api.example.com`** — المضيف. النطاق (أو عنوان IP) الذي يترجمه DNS للعثور على الخادم.
- **`443`** — المنفذ. يُحذف عادةً لأن 80 (HTTP) و443 (HTTPS) هما الافتراضيان.
- **`/v1/users`** — المسار. أي مورد على الخادم تريده.
- **`?active=true`** — سلسلة الاستعلام. معاملات إضافية، على شكل أزواج مفتاح-قيمة.
- **`#profile`** — الجزء (Fragment). من جانب العميل فقط — لا يُرسل إلى الخادم إطلاقاً.
