كل تفاعل HTTP هو **طلب** واحد من عميل يتبعه **استجابة** واحدة من خادم. البروتوكول عديم الحالة: كل طلب مستقل، ولا يتذكر الخادم الطلبات السابقة (تُحمَل الحالة من قبل العميل، مثلاً في ملفات تعريف الارتباط أو الرموز).

<HttpRequest defaultMethod="GET" defaultPath="/api/http/echo" />

## دورة الحياة

1. **العميل ← الطلب** — يبني العميل طلباً: *طريقة*، و*هدف الطلب* (عادةً URI)، و*حقول ترويسة*، ونص اختياري.
2. **النقل** — يسافر الطلب عبر الشبكة (عادةً TCP، وغالباً مشفّراً بـ TLS كـ HTTPS).
3. **الخادم ← الاستجابة** — يعالج الخادم الطلب ويعيد استجابة: *رمز حالة*، و*حقول ترويسة*، ونص اختياري.

## لماذا هذا مهم

- **عديم الحالة** — أي جهاز يفهم HTTP يمكنه أن يعمل كخادم؛ لا تُفترض أي حالة جلسة.
- **التكرارية** — بعض الطرق (`GET`، و`PUT`) تكرارية: تكرارها آمن.
- **قابلية التخزين المؤقت** — يمكن تخزين الاستجابات مؤقتاً (من قبل العميل، أو CDN، أو وسيط) لتجنب العمل الزائد.
