تخبر حالة `3xx` العميل بأن المورد قد انتقل، أو أن خطوة أخرى مطلوبة قبل اكتمال الطلب — الأكثر شيوعاً، ترويسة `Location` تشير إلى عنوان URL الذي يجب اتباعه بعد ذلك.

## أكثر رموز 3xx شيوعاً

| الرمز | الاسم | مؤقت أم دائم؟ |
|------|------|------------------------|
| 301 | Moved Permanently | إعادة توجيه دائمة |
| 302 | Found | إعادة توجيه مؤقتة |
| 304 | Not Modified | استخدم نسختك المخزَّنة مؤقتاً |
| 307 | Temporary Redirect | مؤقتة، مع الحفاظ على الطريقة |
| 308 | Permanent Redirect | دائمة، مع الحفاظ على الطريقة |

---

## فهم 301 مقابل 302 مقابل 307 مقابل 308

### 301 Moved Permanently
انتقل المورد إلى عنوان URL جديد **بشكل دائم**. تتذكر التخزينات المؤقتة والمتصفحات هذا.

```http
HTTP/1.1 301 Moved Permanently
Location: /new/path
```

**الاستخدام:** اختفى عنوان URL القديم إلى الأبد. ستحدّث محركات البحث فهرستها. ستخزّن المتصفحات هذا مؤقتاً.

---

### 302 Found
المورد في عنوان URL مختلف **الآن**، لكنه قد يعود لاحقاً.

```http
HTTP/1.1 302 Found
Location: /temporary/path
```

**الاستخدام:** إعادة التوجيه المؤقتة (الصيانة، واختبار A/B، وموازنة الحمل).

**تنبيه:** قد تغيّر بعض عملاء HTTP القدامى POST إلى GET بعد 302 (ليس معيارياً، لكنه يحدث).

---

### 307 Temporary Redirect
مثل 302، لكن **مضمون** الحفاظ على الطريقة.

```http
HTTP/1.1 307 Temporary Redirect
Location: /temporary/path
```

**الاستخدام:** إعادة توجيه مؤقتة عندما تحتاج POST أن تبقى POST.

---

### 308 Permanent Redirect
مثل 301، لكن **مضمون** الحفاظ على الطريقة.

```http
HTTP/1.1 308 Permanent Redirect
Location: /new/path
```

**الاستخدام:** إعادة توجيه دائمة عندما تحتاج POST أن تبقى POST.

---

## 304 Not Modified

لم يتغيّر المورد منذ آخر تحقق. استخدم نسختك المخزَّنة مؤقتاً.

```http
GET /api/data HTTP/1.1
If-None-Match: "abc123"

HTTP/1.1 304 Not Modified
```

**الاستخدام:** الطلبات الشرطية (مع `If-Modified-Since` أو `If-None-Match`). يوفّر عرض النطاق الترددي.

---

## كيف تعمل إعادة التوجيه

1. يرسل العميل طلباً
2. يستجيب الخادم بـ 301/302/307/308 مع ترويسة `Location`
3. يتبع العميل (المتصفح) إعادة التوجيه تلقائياً إلى عنوان URL الجديد
4. يعيد الخادم في عنوان URL الجديد المورد

## رموز 3xx أخرى

- **300 Multiple Choices** — موارد متعددة متاحة (نادر).
- **303 See Other** — مثل 302، لكن استخدم GET دائماً (حتى لو أرسلت POST).
- **305 Use Proxy** — مرّ عبر Proxy (عفا عليه الزمن).
- **306** — محجوز (غير مستخدم).

---

## أخطاء شائعة

**تجنّب:** استخدام 302 عندما تحتاج 307 — يمكن أن يغيّر 302 POST إلى GET. استخدم 307 إن كان الأمر مهماً.

**تجنّب:** استخدام 301 لكل شيء — استخدم 301 فقط إذا اختفى عنوان URL إلى الأبد. معظم إعادات التوجيه هي 302 أو 307.

**تجنّب:** عدم تضمين ترويسة Location — يجب أن تحتوي استجابات 3xx على ترويسة Location.
