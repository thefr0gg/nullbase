تبدأ كل استجابة HTTP بـ **رمز حالة** — رقم من ثلاثة أرقام يخبر العميل بما حدث.

## الفئات بلمحة

| الفئة | النطاق | المعنى | الرابط |
|-------|-------|---------|------|
| 1xx | 100–199 | إعلامي (متابعة المعالجة) | — |
| 2xx | 200–299 | نجاح (استُقبل الطلب، وفُهم، وقُبل) | [← استكشف](/ar/web-fundamentals/http/status-codes/2xx) |
| 3xx | 300–399 | إعادة توجيه (يلزم إجراء إضافي) | [← استكشف](/ar/web-fundamentals/http/status-codes/3xx) |
| 4xx | 400–499 | خطأ من جهة العميل (فعل العميل شيئاً خاطئاً) | [← استكشف](/ar/web-fundamentals/http/status-codes/4xx) |
| 5xx | 500–599 | خطأ من جهة الخادم (فشل الخادم) | [← استكشف](/ar/web-fundamentals/http/status-codes/5xx) |

---

## رموز نجاح 2xx

نجح الطلب. استُرجع المورد أو أُنشئ أو حُدّث أو حُذف.

| الرمز | الاسم | حالة الاستخدام |
|------|------|----------|
| **200** | OK | نجاح عام. استُرجع المورد أو عُولج. |
| **201** | Created | أُنشئ مورد جديد بنجاح (POST). |
| **202** | Accepted | قُبل الطلب لكن المعالجة غير متزامنة. |
| **204** | No Content | نجاح بلا نص (DELETE وPATCH). |

[← مرجع 2xx الكامل](/ar/web-fundamentals/http/status-codes/2xx)

## رموز إعادة توجيه 3xx

انتقل المورد، أو يحتاج العميل لفعل شيء إضافي.

| الرمز | الاسم | حالة الاستخدام |
|------|------|----------|
| **301** | Moved Permanently | انتقل المورد نهائياً. حدّث إشاراتك المرجعية. |
| **302** | Found | انتقل المورد مؤقتاً. |
| **304** | Not Modified | استخدم نسختك المخزَّنة مؤقتاً. |
| **307** | Temporary Redirect | انتقال مؤقت، مع الحفاظ على طريقة HTTP. |
| **308** | Permanent Redirect | انتقال دائم، مع الحفاظ على طريقة HTTP. |

[← مرجع 3xx الكامل](/ar/web-fundamentals/http/status-codes/3xx)

## رموز خطأ العميل 4xx

كانت هناك مشكلة في طلب العميل. أصلح الطلب وحاول مجدداً.

| الرمز | الاسم | المعنى |
|------|------|---------|
| **400** | Bad Request | تنسيق طلب غير صالح (JSON مشوَّه، حقول ناقصة). |
| **401** | Unauthorized | لست مصادَقاً. سجّل الدخول أولاً. |
| **403** | Forbidden | أنت مصادَق لكن ليس لديك إذن. |
| **404** | Not Found | المورد غير موجود. |
| **409** | Conflict | يتعارض الطلب مع حالة الخادم. |
| **422** | Unprocessable Entity | التنسيق صالح لكن البيانات مرفوضة. |
| **429** | Too Many Requests | محدود المعدل. ترسل طلبات بسرعة كبيرة. |

[← مرجع 4xx الكامل](/ar/web-fundamentals/http/status-codes/4xx)

## رموز خطأ الخادم 5xx

فشل الخادم. ليس خطأ العميل.

| الرمز | الاسم | المعنى |
|------|------|---------|
| **500** | Internal Server Error | حدث خطأ ما على الخادم. |
| **502** | Bad Gateway | لا يستطيع الـ Proxy الوصول إلى الخلفية. |
| **503** | Service Unavailable | الخادم معطَّل أو محمَّل زيادة. أعد المحاولة لاحقاً. |
| **504** | Gateway Timeout | استغرقت الخلفية وقتاً طويلاً للاستجابة. |

[← مرجع 5xx الكامل](/ar/web-fundamentals/http/status-codes/5xx)

## متى ترى كل حالة

### إنشاء مورد

```http
POST /api/users HTTP/1.1
Content-Type: application/json

{ "name": "Alice" }

HTTP/1.1 201 Created
Location: /api/users/42
```

### المورد غير موجود

```http
GET /api/users/999999 HTTP/1.1

HTTP/1.1 404 Not Found
```

### المصادقة مطلوبة

```http
GET /api/admin HTTP/1.1

HTTP/1.1 401 Unauthorized
WWW-Authenticate: Bearer realm="api"
```

### خطأ خادم

```http
POST /api/users HTTP/1.1

HTTP/1.1 500 Internal Server Error
```

## دليل قرار سريع

**هل نجح الطلب؟**
- نعم ← **2xx** (عادةً 200 أو 201)
- لا ← تابع أدناه

**هل هناك شيء آخر يحتاج العميل فعله؟**
- نعم، اتبع إعادة توجيه ← **3xx** (عادةً 301 أو 302 أو 307)
- لا ← تابع أدناه

**هل فعل العميل شيئاً خاطئاً؟**
- نعم ← **4xx** (400، و401، و403، و404، و422، و429، وغيرها)
- لا ← فشل الخادم

**فشل الخادم؟**
- نعم ← **5xx** (500، و502، و503، و504)

---

## أخطاء شائعة

**تجنّب:** إعادة 404 لمشاكل الأذونات — استخدم 403، وليس 404.

**تجنّب:** الخلط بين 401 و403 — 401 = سجّل الدخول، 403 = لا إذن.

**تجنّب:** إعادة 500 لأخطاء العميل — استخدم 4xx لمشاكل العميل، و5xx لمشاكل الخادم.

**تجنّب:** عدم تضمين ترويسة Location في 201 — يجب أن يتضمن 201 Created مكان المورد الجديد.

**تجنّب:** عدم تضمين Retry-After في 429/503 — أخبر العميل متى يعيد المحاولة.
