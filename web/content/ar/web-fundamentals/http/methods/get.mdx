تطلب طريقة `GET` تمثيلاً للمورد المحدَّد. تُرسل البيانات إلى الخادم عبر **معاملات الاستعلام** في عنوان URL (سطر الطلب والترويسات). لا يملك طلب `GET` **أي نص** بحسب المواصفة.

<HttpRequest defaultMethod="GET" defaultPath="/api/http/echo?hello=world" />

## الخصائص

- **آمنة** — يجب ألا تغيّر طلبات `GET` حالة الخادم.
- **تكرارية** — إجراء نفس طلب `GET` مرات عديدة يعطي نفس النتيجة.
- **قابلة للتخزين المؤقت** — الاستجابات قابلة للتخزين المؤقت (ما لم تنص الترويسات على خلاف ذلك).

## مثال

```http
GET /api/http/echo?hello=world HTTP/1.1
Host: nullbase.local
Accept: application/json
```

### `GET` مقابل `POST`

| الجانب | GET | POST |
|---|---|---|
| موقع البيانات | سلسلة الاستعلام (`?key=value`) | النص |
| النص | لا يوجد | نعم |
| قابلة للتخزين المؤقت | نعم | لا (افتراضياً) |
| قابلة للإشارة المرجعية | نعم | لا |
