تطلب **CONNECT** من Proxy فتح Tunnel TCP خام إلى مضيف ومنفذ وجهة، ثم الابتعاد عن الطريق. بمجرد إنشاء الـ Tunnel، يمرر الـ Proxy البايتات فقط في كلا الاتجاهين دون النظر إليها.

تُستخدم دائماً تقريباً لحمل **HTTPS عبر Proxy من نوع HTTP** — يحتاج العميل اتصال TLS مشفّراً من طرف إلى طرف مع الـ Origin Server، لذا لا يستطيع الـ Proxy إنهاء TLS بنفسه؛ يمكنه فقط فتح الأنبوب وتمرير الحركة المشفّرة عبره.

## تنسيق الطلب

الهدف هو `host:port`، وليس مساراً:

```http
CONNECT example.com:443 HTTP/1.1
Host: example.com:443
Proxy-Authorization: Basic dXNlcjpwYXNz
```

## استجابة الـ Proxy

إذا وافق الـ Proxy على فتح الـ Tunnel:

```http
HTTP/1.1 200 Connection Established
```

من هذه النقطة، يتوقف الـ Proxy عن تفسير البايتات التي يمررها كـ HTTP — كل ما يُرسل عبر الاتصال معتم بالنسبة له، بما في ذلك الـ Handshake الخاصة بـ TLS وكل طلب/استجابة مشفّرة تليها.

إذا رفض الـ Proxy (غير مصرَّح، الوجهة غير مسموحة، وغيرها)، يستجيب برمز حالة عادي ويغلق محاولة الـ Tunnel:

```http
HTTP/1.1 407 Proxy Authentication Required
Proxy-Authenticate: Basic realm="proxy"
```

---

## لماذا توجد

بدون CONNECT، سيحتاج Proxy من نوع HTTP إلى إنهاء TLS بنفسه لتمرير حركة HTTPS — فك تشفير حركة العميل، ثم إعادة تشفيرها إلى الـ Origin Server. هذا يكسر التشفير من طرف إلى طرف ويتطلب من العميل الثقة بشهادة الـ Proxy.

تتفادى CONNECT هذا: يرى الـ Proxy فقط `host:port`، ولا يرى المحتوى المشفّر أبداً. تحدث الـ Handshake الخاصة بـ TLS مباشرة بين العميل والـ Origin Server، عبر الـ Tunnel.

---

## الخصائص

- **آمنة:** لا — تفتح اتصال شبكة، وهو أثر جانبي
- **تكرارية:** لا — الاستدعاءات المتكررة تفتح Tunnels منفصلة
- **قابلة للتخزين في الـ Cache:** لا — لا يوجد تمثيل لحفظه في الـ Cache، مجرد أنبوب بايتات

---

## أخطاء شائعة

**تجنّب:** محاولة إرسال نص — لا يوجد لـ CONNECT نص طلب ذو معنى؛ الهدف يوضع في سطر الطلب.

**تجنّب:** توقّع أن يفحص الـ Proxy الحركة داخل الـ Tunnel — بمجرد إنشائه، لا يستطيع الـ Proxy رؤية الطريقة أو الترويسات أو رموز الحالة بداخله (وهذا هو المقصود).

**تجنّب:** استخدام CONNECT لـ HTTP العادي — توجد تحديداً للـ Tunnel المعتم؛ يستخدم طلب HTTP عادي عبر Proxy شكل الطلب المطلق العادي، بلا حاجة لـ CONNECT.
