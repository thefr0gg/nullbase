يستضيف **GitHub** مستودعات [Git](/ar/developer-tools/git) ويضيف فوقها طبقة تعاون كاملة: واجهة ويب لتصفح الكود والتاريخ، وطلبات سحب لمراجعة التغييرات قبل دمجها، وتتبّع للمشاكل، وCI/CD عبر GitHub Actions. لا يملك Git نفسه أي مفهوم لأي من هذا — فهو أداة تحكم في الإصدارات خالصة؛ وGitHub منصة مبنية حوله.

## طلبات السحب (Pull Requests)

يقترح **طلب السحب (PR)** دمج فرع في آخر، وهو المكان الذي تحدث فيه معظم المراجعة التعاونية فعلياً: يعلّق المراجعون على أسطر محددة، وتُشغَّل فحوصات CI تلقائياً على التغيير المقترح، ويصبح طلب السحب نفسه سجلاً دائماً لـ*سبب* حدوث تغيير، وليس فقط *ماذا* تغيّر (وهو ما يُظهره تاريخ الـ commits وحده أصلاً). لا شيء في طلب السحب خاص بـ Git — إنه ميزة تخص GitHub (أو GitLab، أو Bitbucket) بالكامل، مبنية فوق فروع Git.

## Forks مقابل الفروع

يعيش **الفرع (branch)** داخل مستودع تملك بالفعل صلاحية الكتابة عليه. أما **الـ fork** فهو نسخة كاملة من مستودع شخص آخر إلى حسابك الخاص — الطريقة المعتادة للمساهمة في مشروع لا تملك صلاحية كتابة مباشرة عليه: اعمل fork له، ثم أنشئ فرعاً ونفّذ commits داخل نسختك (fork)، ثم افتح طلب سحب من فرع نسختك إلى المستودع الأصلي.

## GitHub Actions

يُشغّل GitHub Actions تدفقات عمل [CI/CD](/ar/devops/ci-cd) معرَّفة في ملفات YAML تحت `.github/workflows/`، تُطلَق بأحداث مثل push أو pull request:

```yaml
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npm test
```

تُشغَّل كل مهمة (job) في آلة افتراضية جديدة ومعزولة (أو [حاوية](/ar/devops/containers))، ووجود نظام بيئي كبير من "actions" قابلة لإعادة الاستخدام (مثل `actions/checkout` أعلاه) يعني أن معظم خطوات CI الشائعة لا تحتاج لكتابتها من الصفر.

## المشاكل (Issues) ولوحات المشروع

يتتبّع GitHub Issues الأخطاء وطلبات الميزات والمهام، لكل منها خيط نقاش خاص به، ووسوم (labels)، ومكلَّفون بها — وغالباً ما تكون مرتبطة مباشرة بطلب السحب الذي يحلّها (إغلاق مشكلة تلقائياً عند دمج طلب السحب المرتبط). وتضيف لوحات المشروع عرضاً بأسلوب Kanban (قيد الانتظار / قيد التنفيذ / منجَز) فوق المشاكل وطلبات السحب لتتبّع خفيف للمشروع دون الحاجة لأداة منفصلة.
