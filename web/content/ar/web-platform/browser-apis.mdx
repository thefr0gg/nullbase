## كشف الميزات بدلاً من استنشاق المتصفح

لأن ليس كل متصفح (أو إصدار) يدعم كل واجهة برمجية، ينبغي للكود المعتمد على واحدة منها أن يتحقق من وجودها مباشرة بدلاً من محاولة تحديد هوية المتصفح:

```js
if ("clipboard" in navigator) {
  await navigator.clipboard.writeText("copied!");
} else {
  // fall back to a manual copy affordance
}
```

## الأذونات

العديد من هذه الواجهات البرمجية (تحديد الموقع، والإشعارات، والحافظة، والكاميرا/الميكروفون) محمية خلف طلب إذن صريح من المستخدم في المرة الأولى التي تطلبها فيها الصفحة — ولا تعمل معظمها إلا في سياق آمن (`https://` أو `localhost`)، وهو قيد متعمد بما أنها تعرض قدرة حقيقية للجهاز/المستخدم.

## طالع أيضاً

- **[ملفات تعريف الارتباط (Cookies)](/ar/web-platform/cookies)** و**[تخزين الويب](/ar/web-platform/web-storage)** — اثنتان من أكثر واجهات المتصفح البرمجية استخداماً، تُغطَّيان بشكل منفصل لأن لكل منهما ما يكفي من التفاصيل بمفردها.
- **[عمّال الخدمة (Service Workers)](/ar/web-platform/service-workers)** — الواجهة البرمجية خلف الدعم دون اتصال والإشعارات في الخلفية.
