تعمل شبه كل الخوادم على الإنترنت — الأجهزة الافتراضية السحابية، الحاويات، الآلات التي تقف خلف معظم الخوادم الخلفية — على توزيعة Linux ما. ليس لأن Linux مطلوب، بل لأنه مجاني ومستقر ومفهوم جيداً، وله عقود من الأدوات المبنية بالضبط حول حالة الاستخدام هذه. معرفة طريقك في صدفة Linux قريبة من كونها شرطاً مسبقاً لعمل الخادم الخلفي وDevOps عموماً.

## الصلاحيات

لكل ملف مالك، ومجموعة، وثلاث مجموعات صلاحيات (مالك/مجموعة/آخرون)، لكل منها بتات قراءة وكتابة وتنفيذ — تظهر عبر `ls -l` كسلسلة مثل `-rwxr-xr--`. يضبط `chmod 755 script.sh` المالك على قراءة/كتابة/تنفيذ (7)، والمجموعة والآخرين على قراءة/تنفيذ (5 لكل منهما) — الصيغة الرقمية هي فقط تلك البتات الثلاث مقروءة كأرقام ثمانية. سكربت غير قابل للتنفيذ (`chmod +x`) سيرفض العمل مباشرة حتى لو كانت محتوياته صحيحة تماماً.

## أوامر تستحق إتقانها عن ظهر قلب

```bash
ls -la          # list files, including hidden ones, with details
cd /var/log      # change directory
pwd              # print working directory
cat file.txt     # print a file's contents
grep -r "TODO" . # search recursively for a pattern
ps aux           # list running processes
kill -9 1234     # forcibly terminate process 1234
chmod +x run.sh  # make a file executable
tail -f app.log  # follow a log file as it grows
```

`tail -f` تحديداً أداة يومية لأي شخص يشغّل خدمة — مراقبة تحديث ملف سجل في الوقت الفعلي أثناء معالجة خادم للطلبات.
