JSON (JavaScript Object Notation) هو صيغة بيانات خفيفة ونصية — وعلى الرغم من اسمها، فهي اليوم مستقلة عن اللغة، بمحلِّل متوفر في كل لغة برمجة تقريباً. إنها صيغة جسم الطلب/الاستجابة الافتراضية عبر [REST](/ar/web-apis/rest)، ومعظم [RPC](/ar/web-apis/rpc)، و[GraphQL](/ar/web-apis/graphql)، وكل استجابة وهمية في هذا الموقع هي JSON لهذا السبب بالضبط.

```json
{
  "id": 42,
  "name": "Grace Hopper",
  "active": true,
  "roles": ["admin", "editor"],
  "manager": null
}
```

## ما لا يستطيع JSON تمثيله

لا يملك JSON نوع `Date` — تُسلسَل الطوابع الزمنية تقليدياً كسلاسل نصية بمعيار ISO 8601 (`"2024-01-15T09:00:00Z"`) وتُحلَّل مرة أخرى إلى كائنات تاريخ حقيقية من قبل المستهلك، وليس تلقائياً. كما لا يستطيع تمثيل `undefined`، أو الدوال، أو المراجع الدائرية — تُسقِط `JSON.stringify` قيم `undefined` والدوال بصمت، وترمي خطأ عند وجود مرجع دائري.

```js
JSON.stringify({ a: undefined, b: () => {}, c: 1 });
// '{"c":1}' — a and b are just gone, not null
```

## بنية صارمة، عن قصد

خلافاً لحرفيات كائنات JavaScript، لا يملك JSON فواصل زائدة في النهاية، ولا تعليقات، ولا مفاتيح دون علامات اقتباس، ولا سلاسل نصية بعلامات اقتباس مفردة — هذه الصرامة مقصودة: لا يحتاج المحلّل إلى تخمين النية، وهذا ما يجعل JSON قابلاً للتشغيل البيني بموثوقية عبر تنفيذ كل لغة.
