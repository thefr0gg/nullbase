طريقة سريعة لاختبار ما إذا كان سلوك مقطع من JavaScript يطابق نموذجك الذهني عنه. اختر إجابة، تحقّق منها، واقرأ الشرح في الحالتين.

<PredictOutput
  title="مصفوفة + مصفوفة"
  code={`console.log([1, 2, 3] + [4, 5, 6]);`}
  options={["1,2,34,5,6", "[1,2,3,4,5,6]", "7", "خطأ"]}
  correctIndex={0}
  explanation="يحوّل المعامل + عند تطبيقه على عنصرين (بما في ذلك المصفوفات) كليهما إلى سلاسل نصية أولًا. [1,2,3].toString() تعطي '1,2,3'، و[4,5,6].toString() تعطي '4,5,6'، ودمج السلاسل النصية يلصقهما ببساطة دون أي شيء بينهما."
  actualOutput="1,2,34,5,6"
/>

<PredictOutput
  title="var داخل حلقة"
  code={`for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}`}
  options={["0, 1, 2", "3, 3, 3", "0, 0, 0", "خطأ"]}
  correctIndex={1}
  explanation="نطاق var هو نطاق الدالة وليس نطاق الكتلة — تلتقط جميع الدوال الثلاث نفس المتغير i، الذي يكون قد وصل بالفعل إلى 3 عندما تُنفَّذ أيٌّ منها فعليًا (تؤجَّل setTimeout دائمًا، حتى بتأخير 0 مللي ثانية). لو استُبدلت var بـ let، لحصلت كل تكرارة على رابطة خاصة بها، فتُطبع 0 ثم 1 ثم 2 بدلًا من ذلك."
  actualOutput="3, 3, 3"
/>
