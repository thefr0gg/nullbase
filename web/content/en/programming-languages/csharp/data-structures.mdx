C# ships with a small set of collection types that cover most day-to-day
needs: fixed-size arrays, the resizable `List<T>`, and the key-value
`Dictionary<TKey, TValue>`. All three are generic, so they're type-safe
without casting.

## Arrays

Arrays have a fixed size once created and are zero-indexed:

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };
Console.WriteLine(numbers.Length); // 5
Console.WriteLine(numbers[0]);     // 1

numbers[0] = 100;

int[] empty = new int[3]; // [0, 0, 0] — value types default to their zero value

int[,] grid = new int[2, 3]; // a 2D array, 2 rows by 3 columns
grid[0, 1] = 7;
```

Because arrays can't grow or shrink, most code that needs a dynamically
sized collection reaches for `List<T>` instead.

## List\<T\>

`List<T>` is a resizable, ordered collection — the everyday workhorse for
sequences of items:

```csharp
using System.Collections.Generic;
using System.Linq;

List<string> names = new List<string> { "Ada", "Grace" };
names.Add("Alan");
names.Remove("Grace");

Console.WriteLine(names.Count);    // 2
Console.WriteLine(names[0]);       // Ada
Console.WriteLine(names.Contains("Alan")); // True

foreach (string name in names)
{
    Console.WriteLine(name);
}

// LINQ works directly on List<T> and most other collections
List<int> evens = new List<int> { 1, 2, 3, 4, 5, 6 }
    .Where(n => n % 2 == 0)
    .ToList();
```

## Dictionary\<TKey, TValue\>

`Dictionary<TKey, TValue>` stores key-value pairs with fast lookup by key:

```csharp
using System.Collections.Generic;

Dictionary<string, int> ages = new Dictionary<string, int>
{
    ["Ada"] = 36,
    ["Grace"] = 85,
};

ages["Alan"] = 41; // adds a new key
ages["Ada"] = 37;  // updates an existing key

if (ages.TryGetValue("Grace", out int graceAge))
{
    Console.WriteLine(graceAge); // 85
}

foreach (KeyValuePair<string, int> pair in ages)
{
    Console.WriteLine($"{pair.Key} is {pair.Value}");
}

Console.WriteLine(ages.ContainsKey("Nobody")); // False
```

`TryGetValue` is the idiomatic way to look up a key that might not exist —
indexing with `ages["Nobody"]` on a missing key throws a `KeyNotFoundException`
instead of returning `null` or a default value.
