Java's control-flow constructs will look familiar if you know C, C++, or
JavaScript — braces delimit blocks and conditions must be genuine `boolean`
expressions, not truthy/falsy values coerced from numbers or objects.

## if / else

```java
int score = 82;

if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("C or below");
}
```

Unlike C, `if (score)` does not compile when `score` is an `int` — the
condition must be a `boolean` expression such as `score != 0`. This rules
out an entire class of "assignment instead of comparison" bugs, since
`if (score = 0)` is also a compile error rather than a silent assignment.

## switch: classic and arrow form

The classic `switch` falls through to the next case unless you `break`:

```java
int day = 3;
String name;
switch (day) {
    case 1:
        name = "Monday";
        break;
    case 2:
        name = "Tuesday";
        break;
    case 3:
        name = "Wednesday";
        break;
    default:
        name = "Unknown";
}
System.out.println(name);
```

Java 14 introduced the arrow form, which does not fall through and can
produce a value directly with `yield` (or as an expression):

```java
int day = 3;
String name = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Unknown";
};
System.out.println(name);
```

The arrow form is generally preferred in modern Java: it's harder to
accidentally fall through, and using it as an expression means the compiler
can check that every branch produces a value of the same type.

## Loops

Java has three loop forms. `for` with an explicit counter:

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

The enhanced `for` (a "for-each") for iterating a collection or array
without manual indexing:

```java
int[] scores = {70, 85, 92};
for (int score : scores) {
    System.out.println(score);
}
```

`while` and `do-while`, distinguished by when the condition is checked —
`while` checks before the first iteration, `do-while` always runs the body
at least once:

```java
int n = 5;
while (n > 0) {
    System.out.println(n);
    n--;
}

int attempts = 0;
do {
    attempts++;
} while (attempts < 3);
System.out.println(attempts);
```

`break` exits a loop entirely; `continue` skips to the next iteration. Both
accept a label (`outer:`) to target an enclosing loop when loops are nested.
