Java was released by Sun Microsystems in 1995 (now maintained by Oracle)
under the slogan "write once, run anywhere." Source code compiles to
platform-independent **bytecode**, which runs on the Java Virtual Machine
(JVM) rather than directly on any one operating system. The same `.class`
file runs unmodified on Windows, Linux, or macOS as long as a compatible JVM
is installed.

Java is statically typed, garbage collected, and deeply object-oriented:
almost everything you write lives inside a class. It has powered a huge
share of enterprise backend systems, Android apps (via a Java-compatible
toolchain), and large-scale distributed systems for three decades, and its
ecosystem of mature libraries and tooling (Maven, Gradle, Spring) is one of
the largest in the industry.

## What makes Java distinctive

- **The JVM.** Code compiles to bytecode, not machine code. The JVM's
  just-in-time compiler then turns hot bytecode into native instructions at
  run time, and the same bytecode runs unmodified on any platform with a JVM.
- **Everything is a class (almost).** There are no free-floating functions.
  Every method lives inside a class or interface, even a program's `main`
  entry point.
- **Checked exceptions.** Java distinguishes exceptions the compiler forces
  you to handle or declare (checked) from those it doesn't (unchecked) — a
  distinction most other mainstream languages dropped.
- **Single inheritance, multiple interfaces.** A class extends at most one
  superclass but can implement any number of interfaces, sidestepping the
  diamond problem that full multiple inheritance creates.
- **Automatic memory management.** A generational garbage collector reclaims
  unreachable objects; there's no manual `free` or `delete`.
- **Strong backward compatibility.** Code written for Java 1.2 in the late
  1990s largely still compiles today — a deliberate, heavily guarded
  language-evolution policy.

Here's a minimal, complete Java program:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, nullbase!");
    }
}
```

The file must be named `Main.java` to match the public class name, and
`main` must have exactly this signature — `public static void
main(String[] args)` — for the JVM to recognize it as the entry point.

## When you'd reach for Java

Java is a strong default for large, long-lived backend systems where team
size, tooling maturity, and long-term maintainability matter more than
minimal startup latency: enterprise services, Android applications, and
big data infrastructure (Hadoop, Kafka, and Spark are all written in Java or
its JVM sibling Scala). It's less commonly reached for when you want a
single small binary with no runtime to install, which is where compiled
languages like Go or Rust tend to win.
