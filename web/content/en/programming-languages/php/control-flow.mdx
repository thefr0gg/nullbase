PHP's control flow will look immediately familiar if you know any C-family
language, with a couple of PHP-specific additions worth knowing: `match`
(added in PHP 8.0) and an alternative colon syntax designed for mixing PHP
with HTML templates.

## if / elseif / else

Note the spelling: `elseif` (one word), not `else if`, though PHP accepts
both — `elseif` is the conventional style in PHP codebases.

```php
<?php

function classify(int $score): string {
    if ($score >= 90) {
        return "A";
    } elseif ($score >= 80) {
        return "B";
    } else {
        return "F";
    }
}

echo classify(85) . "\n"; // B
```

## Loops

PHP has `while`, `do...while`, `for`, and `foreach` — foreach being the one
you'll reach for constantly, since it works directly over arrays:

```php
<?php

$fruits = ["apple", "banana", "cherry"];

foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit\n";
}
```

`for` and `while` behave exactly as in C:

```php
<?php

for ($i = 0; $i < 3; $i++) {
    echo "count: $i\n";
}

$n = 1;
while ($n < 100) {
    $n *= 2;
}
echo $n . "\n"; // 128
```

## switch

`switch` in PHP uses **loose comparison** (`==`) by default and falls
through unless you `break` — the classic C-style pitfall:

```php
<?php

$role = "editor";

switch ($role) {
    case "admin":
        echo "full access\n";
        break;
    case "editor":
    case "author":
        echo "can publish\n";
        break;
    default:
        echo "read only\n";
}
```

## match — a stricter, expression-based alternative

`match` (PHP 8.0+) fixes switch's two biggest footguns: it compares with
strict (`===`) semantics, and there's no fall-through — each arm is a single
expression, and `match` itself evaluates to a value.

```php
<?php

$role = "editor";

$access = match ($role) {
    "admin" => "full access",
    "editor", "author" => "can publish",
    default => "read only",
};

echo $access . "\n"; // can publish
```

Unlike `switch`, an unmatched value with no `default` arm throws an
`UnhandledMatchError` rather than silently doing nothing — a deliberate
safety improvement.

## The alternative colon syntax

Inside templates that mix PHP and HTML, PHP offers a colon-based syntax for
`if`, `foreach`, `for`, and `while` that avoids a wall of curly braces:

```php
<?php $items = ["tea", "coffee"]; ?>
<ul>
<?php foreach ($items as $item): ?>
    <li><?= $item ?></li>
<?php endforeach; ?>
</ul>
```

`<?= $item ?>` is shorthand for `<?php echo $item; ?>` and is common in
template files for exactly this reason.
