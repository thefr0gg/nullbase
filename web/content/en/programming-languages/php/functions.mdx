Functions in PHP are declared with the `function` keyword and can appear at
top level (PHP has no requirement that code live inside a class). Since PHP
7, parameters and return values can carry type hints, which the engine
enforces at runtime.

## Basic declaration

```php
<?php

function greet(string $name): string {
    return "Hello, $name!";
}

echo greet("Ada") . "\n";
```

## Default arguments

Any parameter can have a default value, which lets callers omit it. Default
parameters must come after parameters without defaults:

```php
<?php

function makeGreeting(string $name, string $greeting = "Hello"): string {
    return "$greeting, $name!";
}

echo makeGreeting("Grace") . "\n";              // Hello, Grace!
echo makeGreeting("Grace", "Welcome") . "\n";    // Welcome, Grace!
```

## Named arguments

PHP 8.0 added named arguments, which let a caller skip earlier defaults
without repeating them positionally:

```php
<?php

function connect(string $host, int $port = 5432, bool $ssl = false): string {
    return ($ssl ? "ssl://" : "") . "$host:$port";
}

echo connect("db.internal", ssl: true) . "\n"; // ssl://db.internal:5432
```

## Variadic functions

Prefixing the last parameter with `...` collects any number of trailing
arguments into an array — PHP's equivalent of `*args`:

```php
<?php

function sum(int ...$numbers): int {
    $total = 0;
    foreach ($numbers as $n) {
        $total += $n;
    }
    return $total;
}

echo sum(1, 2, 3, 4) . "\n"; // 10
echo sum() . "\n";            // 0
```

The `...` spread operator does the reverse when calling a function: it
unpacks an array into positional arguments.

```php
<?php

$values = [3, 6, 9];
echo sum(...$values) . "\n"; // 18
```

## Passing by reference

By default, arguments are passed by value — a function gets a copy. Adding
`&` before a parameter passes it by reference instead, letting the function
mutate the caller's variable:

```php
<?php

function increment(int &$n): void {
    $n++;
}

$counter = 10;
increment($counter);
echo $counter . "\n"; // 11
```

## Anonymous functions and arrow functions

PHP supports closures via `function` (with an explicit `use` clause to
capture outer variables) and the more concise `fn` arrow-function syntax,
which captures automatically by value:

```php
<?php

$multiplier = 3;

$classic = function (int $n) use ($multiplier): int {
    return $n * $multiplier;
};

$arrow = fn(int $n): int => $n * $multiplier;

echo $classic(5) . " " . $arrow(5) . "\n"; // 15 15
```
