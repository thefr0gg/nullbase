Go deliberately keeps control flow minimal. There's no `while`, no
`do-while`, no ternary operator — `for` covers every looping need, and
`switch` is more flexible than in most C-family languages.

## if / else

Conditions never need parentheses, but the opening brace must be on the
same line as `if` — Go's grammar relies on automatic semicolon insertion,
and a brace on its own line breaks that.

```go
func classify(score int) string {
	if score >= 90 {
		return "A"
	} else if score >= 80 {
		return "B"
	} else {
		return "F"
	}
}
```

`if` also accepts an initializer statement, scoped to the `if`/`else`
chain — commonly used to check an error right where it's produced:

```go
if value, ok := lookup("key"); ok {
	fmt.Println("found:", value)
} else {
	fmt.Println("not found")
}
// value and ok are not visible here — they only exist inside the if/else
```

## for — Go's only loop

Go has one looping keyword that covers what other languages split into
`for`, `while`, and infinite loops.

Classic three-part form:

```go
for i := 0; i < 5; i++ {
	fmt.Println(i)
}
```

Condition only — this is Go's `while`:

```go
n := 1
for n < 100 {
	n *= 2
}
```

No condition at all — an infinite loop, typically paired with `break`:

```go
count := 0
for {
	count++
	if count == 3 {
		break
	}
}
```

`for ... range` iterates over slices, arrays, maps, strings, and channels:

```go
names := []string{"Ada", "Grace", "Linus"}
for i, name := range names {
	fmt.Println(i, name)
}
```

## switch

Go's `switch` doesn't fall through by default (the opposite of C/Java), so
you rarely need `break`. Cases can also list multiple values or omit the
switch expression entirely to act as a cleaner if/else chain:

```go
func describe(n int) string {
	switch {
	case n < 0:
		return "negative"
	case n == 0:
		return "zero"
	case n%2 == 0:
		return "positive even"
	default:
		return "positive odd"
	}
}
```

Use `fallthrough` explicitly on the rare occasion you want the next case to
run anyway:

```go
switch day := "sat"; day {
case "sat", "sun":
	fmt.Println("weekend")
default:
	fmt.Println("weekday")
}
```
