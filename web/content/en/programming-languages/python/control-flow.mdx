Python's conditional and loop statements read close to plain English, but the mechanics underneath are worth being precise about, especially the parts that differ from C-family languages.

```python
temperature = 72
if temperature > 80:
    print("hot")
elif temperature > 60:
    print("mild")
else:
    print("cold")
```

`elif` is Python's spelling of "else if" — there's no separate `else if` keyword pair, and conditions never need surrounding parentheses (though you can add them). Any value can be used as a condition, not just booleans: `0`, `""`, `None`, and empty collections (`[]`, `{}`, `()`) are all "falsy," and everything else is "truthy," so `if some_list:` is an idiomatic way to check "is this list non-empty" without comparing lengths explicitly.

```python
fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(index, fruit)
```

Python's `for` loop iterates directly over the *items* of a sequence — there's no C-style `for (i = 0; i < len; i++)` counting pattern. When the index is actually needed alongside the value, `enumerate()` wraps the sequence to yield `(index, value)` pairs, which is the idiomatic way to get both without manually tracking a counter.

```python
n = 0
while n < 5:
    if n == 3:
        n += 1
        continue
    print(n)
    n += 1
```

`while` loops run as long as their condition stays truthy; `continue` skips straight to the next iteration's condition check, and `break` exits the loop entirely. There's also no `n++` — Python has no increment/decrement operators, only `n += 1`.

One genuinely unusual feature: both `for` and `while` loops can have an `else` clause, which runs only if the loop finished normally — i.e. was *not* stopped by a `break`.

```python
for i in range(2, 10):
    if i % 7 == 0:
        print("found a multiple of 7:", i)
        break
else:
    print("no multiples of 7 found")
```

Read `for...else` as "if we never broke out of this loop, then..." — it's most useful for search loops where `break` means "found it" and falling through to `else` means "searched everything, found nothing."
