Any `.py` file is a **module**, and its top-level code (functions, classes, variables) becomes available elsewhere via `import`.

```python
import math
from datetime import date

print(math.sqrt(16))   # 4.0
print(date.today())      # 2026-09-01, for example
```

`import math` brings in the whole module, and its contents are accessed with `math.sqrt(...)`; `from datetime import date` pulls one specific name directly into scope, so it's used as `date` rather than `datetime.date`. Both `math` and `datetime` ship in Python's standard library — no installation needed.

Your own files work the same way: any name defined at the top level of `mymodule.py` becomes importable as `mymodule.name` (or via `from mymodule import name`) from another file in the same project.

```python
# mymodule.py
def add(a, b):
    return a + b
```

```python
# main.py
from mymodule import add
print(add(2, 3))  # 5
```

For code beyond the standard library, `pip` installs **packages** published to the Python Package Index (PyPI). Because different projects on the same machine often need conflicting versions of the same package, Python projects almost always use a **virtual environment** — an isolated, project-local set of installed packages — rather than installing everything globally.

```bash
python -m venv .venv
source .venv/bin/activate   # .venv\Scripts\activate on Windows
pip install requests
pip freeze > requirements.txt
```

`python -m venv .venv` creates the isolated environment in a `.venv` folder; `activate` makes the shell use that environment's Python and `pip` instead of the system-wide ones; `pip freeze > requirements.txt` captures exactly what's installed (with pinned versions) so the environment can be recreated elsewhere with `pip install -r requirements.txt`.

Newer projects increasingly declare dependencies in `pyproject.toml` instead of a bare `requirements.txt`, since it also captures the project's name, version, and build configuration in one standardized file:

```toml
[project]
name = "my-app"
version = "0.1.0"
dependencies = ["requests>=2.31"]
```
