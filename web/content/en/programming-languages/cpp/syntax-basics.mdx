C++ is **statically typed**: every variable has a type fixed at compile time, and the compiler rejects a program where a value doesn't match the type it's assigned to. This catches an entire class of bugs before the program ever runs, at the cost of having to write out (or infer) types up front rather than deciding them at runtime.

```cpp
#include <iostream>
#include <string>

int main() {
    int age = 30;
    double price = 19.99;
    char grade = 'A';
    bool isActive = true;
    std::string name = "Ada";

    std::cout << name << " is " << age << " years old.\n";
    return 0;
}
```

The fundamental built-in types are `int` (whole numbers), `double`/`float` (floating-point numbers), `char` (a single byte, usually one character), and `bool` (`true`/`false`). `std::string`, from the `<string>` header, is not a built-in type but part of the standard library — it manages its own memory, so unlike a raw C-style character array it grows and shrinks safely as text is assigned to it.

## `auto` and `const`

```cpp
#include <iostream>

int main() {
    auto count = 42;          // deduced as int
    auto ratio = 3.14;        // deduced as double
    const int maxRetries = 5; // cannot be reassigned

    std::cout << "count=" << count << " ratio=" << ratio << " max=" << maxRetries << "\n";
    return 0;
}
```

`auto` asks the compiler to deduce a variable's type from its initializer rather than spelling it out — the variable is still statically typed, just inferred instead of written explicitly. `const` marks a variable as unmodifiable after initialization; attempting `maxRetries = 10;` later in the function would fail to compile. Using `const` wherever a value genuinely shouldn't change documents that intent for readers and lets the compiler catch accidental reassignment.

## Reading input

```cpp
#include <iostream>

int main() {
    std::string name;
    int age;

    std::cout << "Enter your name: ";
    std::cin >> name;
    std::cout << "Enter your age: ";
    std::cin >> age;

    std::cout << name << " is " << age << " years old.\n";
    return 0;
}
```

`std::cin` (declared in `<iostream>`) reads from standard input the same way `std::cout` writes to standard output, using `>>` instead of `<<`. By default `std::cin >> name` reads a single whitespace-delimited token, not a full line — reading `"Ada Lovelace"` this way would only capture `"Ada"`; a full line requires `std::getline(std::cin, name)` instead.
