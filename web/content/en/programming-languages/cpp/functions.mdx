A C++ function has an explicit return type, a name, and a fixed parameter list — the compiler checks every call site against that signature, so calling a function with the wrong number or type of arguments is a compile error, not something discovered at runtime.

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

double average(int a, int b, int c) {
    return (a + b + c) / 3.0;
}

int main() {
    std::cout << add(4, 5) << "\n";
    std::cout << average(2, 4, 9) << "\n";
    return 0;
}
```

## Pass by value vs. pass by reference

```cpp
#include <iostream>

void incrementByValue(int n) {
    n = n + 1; // only modifies the local copy
}

void incrementByReference(int& n) {
    n = n + 1; // modifies the caller's variable
}

int main() {
    int x = 10;
    incrementByValue(x);
    std::cout << "After by-value: " << x << "\n"; // still 10

    incrementByReference(x);
    std::cout << "After by-reference: " << x << "\n"; // now 11
    return 0;
}
```

By default, C++ passes arguments **by value** — the function receives a copy, so changes made inside it never affect the caller's variable. Adding `&` to a parameter's type makes it a **reference** parameter: `n` becomes another name for the caller's actual variable, so modifications inside the function are visible outside it. This is also how C++ avoids copying large objects: a `const std::string&` parameter, for example, lets a function read a string without copying it and without allowing it to be modified.

## Default arguments and overloading

```cpp
#include <iostream>
#include <string>

void greet(const std::string& name, const std::string& greeting = "Hello") {
    std::cout << greeting << ", " << name << "!\n";
}

int multiply(int a, int b) {
    return a * b;
}

double multiply(double a, double b) {
    return a * b;
}

int main() {
    greet("Ada");                 // uses the default greeting
    greet("Grace", "Welcome");    // overrides it

    std::cout << multiply(3, 4) << "\n";       // calls the int version
    std::cout << multiply(2.5, 4.0) << "\n";   // calls the double version
    return 0;
}
```

`greeting`'s default value means callers can omit it entirely; a default argument must come after all parameters that don't have one. **Overloading** lets multiple functions share a name as long as their parameter lists differ — the compiler picks the matching version based on the argument types at each call site, resolved entirely at compile time.
