The `Cache-Control` header carries directives that control caching behavior — for browsers, and for anything in between the client and the origin server, like a [CDN](/en/web-fundamentals/cdns). It can appear on both requests and responses; on responses is where it matters most.

## A typical response

```http
HTTP/1.1 200 OK
Content-Type: application/json
Cache-Control: public, max-age=3600, must-revalidate
```

Cacheable by anyone, fresh for an hour, and once that hour is up, don't serve it again without checking with the origin first.
