The `502 Bad Gateway` response status code indicates that **a server acting as a gateway or proxy received an invalid or malformed response from the upstream server it was trying to reach**.

<StatusCodeExplorer defaultCode={502} />

## Details

- **Class:** 5xx (Server error)
- **Typical cause:** the upstream application server crashed, restarted, or returned garbage while the proxy (nginx, a load balancer, a CDN) was waiting for a response.
- **Who fixes it:** the origin/backend, not the client — retrying the exact same request rarely helps until the upstream recovers.

## Example

```http
GET /api/data HTTP/1.1

HTTP/1.1 502 Bad Gateway
Content-Type: text/html

<h1>502 Bad Gateway</h1>
<p>The upstream server returned an invalid response.</p>
```

## Common Mistakes

**Avoid:** Confusing `502` with `503` — `502` means the upstream sent back something invalid; `503` means the server (or upstream) is deliberately unavailable, e.g. overloaded or in maintenance.

**Avoid:** Retrying aggressively without backoff — a struggling upstream service gets worse under a retry storm.
