The `308 Permanent Redirect` response status code indicates that **the target resource has permanently moved to a new URL, and the client must repeat the request with the same method**.

<StatusCodeExplorer defaultCode={308} />

## Details

- **Class:** 3xx (Redirection)
- **Difference from 301:** `308` guarantees the method (and body, for `POST`/`PUT`) is preserved; `301` does not.
- **SEO:** passes link equity like `301` does, while keeping the original method intact.

## Example

```http
PUT /api/v1/resource HTTP/1.1
Content-Type: application/json

{ "value": 1 }

HTTP/1.1 308 Permanent Redirect
Location: /api/v2/resource
```

## Common Mistakes

**Avoid:** Using `301` when the method must be preserved — some clients rewrite `POST`/`PUT` to `GET` on a `301`, which `308` prevents.

**Avoid:** Using `308` for a temporary move — use `307` instead so caches don't treat it as permanent.
