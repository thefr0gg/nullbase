## 2xx Success Codes

Request succeeded. The resource was retrieved, created, updated, or deleted.

| Code | Name | Use Case |
|------|------|----------|
| **200** | OK | Generic success. Resource retrieved or processed. |
| **201** | Created | New resource successfully created (POST). |
| **202** | Accepted | Request accepted but processing is async. |
| **204** | No Content | Success with no body (DELETE, PATCH). |

[→ Full 2xx Reference](/en/web-fundamentals/http/status-codes/2xx)

---

## 3xx Redirection Codes

The resource has moved, or the client needs to do something more.

| Code | Name | Use Case |
|------|------|----------|
| **301** | Moved Permanently | Resource moved forever. Update your bookmarks. |
| **302** | Found | Resource moved temporarily. |
| **304** | Not Modified | Use your cached copy. |
| **307** | Temporary Redirect | Temporary move, preserve the HTTP method. |
| **308** | Permanent Redirect | Permanent move, preserve the HTTP method. |

[→ Full 3xx Reference](/en/web-fundamentals/http/status-codes/3xx)

---

## 4xx Client Error Codes

The client's request had a problem. Fix the request and try again.

| Code | Name | Meaning |
|------|------|---------|
| **400** | Bad Request | Invalid request format (malformed JSON, missing fields). |
| **401** | Unauthorized | You're not authenticated. Log in first. |
| **403** | Forbidden | You're authenticated but don't have permission. |
| **404** | Not Found | The resource doesn't exist. |
| **409** | Conflict | The request conflicts with server state. |
| **422** | Unprocessable Entity | Format is valid but data is rejected. |
| **429** | Too Many Requests | Rate limited. You're making requests too fast. |

[→ Full 4xx Reference](/en/web-fundamentals/http/status-codes/4xx)

---

## 5xx Server Error Codes

The server failed. It's not the client's fault.

| Code | Name | Meaning |
|------|------|---------|
| **500** | Internal Server Error | Something broke on the server. |
| **502** | Bad Gateway | Proxy can't reach the backend. |
| **503** | Service Unavailable | Server is down or overloaded. Retry later. |
| **504** | Gateway Timeout | Backend took too long to respond. |

[→ Full 5xx Reference](/en/web-fundamentals/http/status-codes/5xx)

## When You See Each Status

### Creating a Resource

```http
POST /api/users HTTP/1.1
Content-Type: application/json

{ "name": "Alice" }

HTTP/1.1 201 Created
Location: /api/users/42
```

### Resource Not Found

```http
GET /api/users/999999 HTTP/1.1

HTTP/1.1 404 Not Found
```

### Authentication Required

```http
GET /api/admin HTTP/1.1

HTTP/1.1 401 Unauthorized
WWW-Authenticate: Bearer realm="api"
```

### Server Error

```http
POST /api/users HTTP/1.1

HTTP/1.1 500 Internal Server Error
```

## Common Mistakes

**Avoid:** Returning 404 for permission issues — Use 403, not 404.

**Avoid:** Confusing 401 and 403 — 401 = log in, 403 = no permission.

**Avoid:** Returning 500 for client errors — Use 4xx for client issues, 5xx for server issues.

**Avoid:** Not including Location header on 201 — 201 Created should include where the new resource is.

**Avoid:** Not including Retry-After on 429/503 — Tell the client when to retry.
