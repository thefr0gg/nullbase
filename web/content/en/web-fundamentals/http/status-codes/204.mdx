The `204 No Content` response status code indicates that **the server successfully processed the request, but there is no content to send in response**.

<StatusCodeExplorer defaultCode={204} />

## Details

- **Class:** 2xx (Success)
- **Typical with:** `DELETE`, `PUT`, `PATCH`
- **Body:** must be empty — a `204` response must not include a message body.

## Example

```http
DELETE /api/users/42 HTTP/1.1

HTTP/1.1 204 No Content
```

## Common Mistakes

**Avoid:** Sending a response body with `204` — clients and proxies expect none, and some will error on one.

**Avoid:** Using `200` with an empty body instead — `204` explicitly signals "nothing more to say," which is more precise than a `200` with no content.
