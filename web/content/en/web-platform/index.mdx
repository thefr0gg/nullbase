Everything in [Web Fundamentals](/en/web-fundamentals) and [Web APIs](/en/web-apis) is about how data gets from a server to a browser. This section is about what happens once it's there — the languages and APIs the browser itself gives a page to work with.

## The core languages

- **[HTML](/en/web-platform/html)** — structure and semantics.
- **[CSS](/en/web-platform/css)** — how the browser decides what a page looks like.
- **[JavaScript](/en/web-platform/javascript)** — the language, and how the browser actually runs it.
- **[The DOM](/en/web-platform/dom)** — the live tree JavaScript actually manipulates.

## What the browser gives you

- **[Browser APIs](/en/web-platform/browser-apis)** — the built-in capabilities beyond the core languages.
- **[Cookies](/en/web-platform/cookies)** — small pieces of state a server can ask the browser to hold and resend.
- **[Web Storage](/en/web-platform/web-storage)** — larger, client-only key-value storage.

## Running code off the main thread

- **[Service Workers](/en/web-platform/service-workers)** — a script that sits between the page and the network.
- **[Web Workers](/en/web-platform/web-workers)** — background JavaScript, off the UI thread.

## Building your own elements

- **[Web Components](/en/web-platform/web-components)** — custom, reusable HTML elements with encapsulated styling.
