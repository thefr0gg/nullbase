Beyond [HTML](/en/web-platform/html), [CSS](/en/web-platform/css), and the [DOM](/en/web-platform/dom), the browser exposes a large set of built-in JavaScript APIs — capabilities that aren't part of the JavaScript language itself, but are provided by the browser environment JavaScript runs inside. Node.js runs the same language with a completely different set of built-in APIs, which is the clearest way to see that these are platform features, not language features.

## Feature detection over browser sniffing

Because not every browser (or version) supports every API, code that depends on one should check for its existence directly rather than trying to identify the browser:

```js
if ("clipboard" in navigator) {
  await navigator.clipboard.writeText("copied!");
} else {
  // fall back to a manual copy affordance
}
```

## Permissions

Several of these APIs (geolocation, notifications, clipboard, camera/microphone) are gated behind an explicit user permission prompt the first time a page requests them — and most only work at all in a secure context (`https://` or `localhost`), a deliberate constraint since they expose real device/user capability.
