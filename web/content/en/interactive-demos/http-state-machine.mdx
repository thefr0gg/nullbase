A single request/response cycle isn't instantaneous — it moves through a small number of distinct states, and not every transition is available from every state (you can't jump straight from "idle" to "receiving"). Click a transition to fire it, or use **Step** to follow the first available one automatically.

<StateMachine
  title="One request/response cycle"
  states={httpLifecycleStates}
  transitions={httpLifecycleTransitions}
  initial="idle"
/>

This same shape — a small set of states, a fixed set of valid transitions between them — describes far more than HTTP: see [TCP](/en/networking/tcp)'s connection lifecycle, a WebSocket's connecting/open/closing/closed states, or an OAuth authorization flow.
