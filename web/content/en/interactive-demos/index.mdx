Nullbase's reference pages aren't limited to prose and static code blocks — most of the interactive widgets used across the site are built from a small, reusable set of primitives (see `web/components/interactive/`). This section is a working tour of that system: each page below embeds one primitive with real, runnable data, so you can see exactly what a content author writes to get it.

## Diagrams and flows

- **[URL Anatomy & Lifecycle](/en/interactive-demos/url-anatomy-and-lifecycle)** — breaking a URL into its parts, then walking through what happens to it.
- **[Under the Hood: a URL Request](/en/interactive-demos/under-the-hood-url-request)** — progressive disclosure hiding a full request lifecycle behind one button.
- **[HTTP Request Lifecycle (State Machine)](/en/interactive-demos/http-state-machine)** — clickable states and transitions instead of a static diagram.

## Protocols and comparisons

- **[HTTP Request & Response](/en/interactive-demos/http-request-response)** — build a real request, see a simulated response.
- **[TCP vs UDP](/en/interactive-demos/tcp-vs-udp)** — a click-to-expand comparison, plus a slider showing what TCP window size actually controls.

## Code and data

- **[JavaScript Code Playground](/en/interactive-demos/js-code-playground)** — editable, runnable JavaScript in a sandboxed iframe.
- **[SQL Interactive](/en/interactive-demos/sql-interactive)** — real SQLite, compiled to WebAssembly, running in your browser.

## Practice

- **[Predict the Output](/en/interactive-demos/predict-the-output)** — a short JavaScript quiz with an explanation.
- **[Order the Request](/en/interactive-demos/ordering-exercise)** — drag or reorder an HTTP request's parts into the right sequence.
- **[Terminal: Git Basics](/en/interactive-demos/terminal-git-basics)** — a simulated shell with a small `git` command exercise.
