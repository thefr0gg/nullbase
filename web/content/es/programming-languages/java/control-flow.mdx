Las construcciones de flujo de control de Java te resultarán familiares si
conoces C, C++, o JavaScript — las llaves delimitan bloques y las
condiciones deben ser expresiones `boolean` genuinas, no valores truthy/falsy
coaccionados desde números u objetos.

## if / else

```java
int score = 82;

if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("C or below");
}
```

A diferencia de C, `if (score)` no compila cuando `score` es un `int` — la
condición debe ser una expresión `boolean` como `score != 0`. Esto descarta
toda una clase de bugs de "asignación en vez de comparación", ya que
`if (score = 0)` también es un error de compilación en vez de una asignación
silenciosa.

## switch: forma clásica y forma flecha

El `switch` clásico cae al siguiente caso a menos que uses `break`:

```java
int day = 3;
String name;
switch (day) {
    case 1:
        name = "Monday";
        break;
    case 2:
        name = "Tuesday";
        break;
    case 3:
        name = "Wednesday";
        break;
    default:
        name = "Unknown";
}
System.out.println(name);
```

Java 14 introdujo la forma flecha, que no cae al siguiente caso y puede
producir un valor directamente con `yield` (o como expresión):

```java
int day = 3;
String name = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Unknown";
};
System.out.println(name);
```

La forma flecha generalmente se prefiere en el Java moderno: es más difícil
caer al siguiente caso por accidente, y usarla como expresión significa que
el compilador puede comprobar que cada rama produce un valor del mismo tipo.

## Bucles

Java tiene tres formas de bucle. `for` con un contador explícito:

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

El `for` mejorado (un "for-each") para iterar una colección o array sin
indexación manual:

```java
int[] scores = {70, 85, 92};
for (int score : scores) {
    System.out.println(score);
}
```

`while` y `do-while`, distinguidos por cuándo se comprueba la condición —
`while` la comprueba antes de la primera iteración, `do-while` siempre
ejecuta el cuerpo al menos una vez:

```java
int n = 5;
while (n > 0) {
    System.out.println(n);
    n--;
}

int attempts = 0;
do {
    attempts++;
} while (attempts < 3);
System.out.println(attempts);
```

`break` sale de un bucle por completo; `continue` salta a la siguiente
iteración. Ambos aceptan una etiqueta (`outer:`) para apuntar a un bucle que
lo contiene cuando los bucles están anidados.
