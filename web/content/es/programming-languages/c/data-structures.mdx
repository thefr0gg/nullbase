La biblioteca estándar de C no trae prácticamente ninguna estructura de datos — no hay una lista, mapa, o array dinámico incorporados como el `list` de Python o el `Array` de JavaScript. Lo que te da en su lugar son arrays de tamaño fijo y memoria en bruto, y todo lo demás más elaborado (arrays dinámicos, listas enlazadas, mapas hash) es algo que construyes tú mismo a partir de arrays, structs y punteros, o que traes de una librería de terceros.

## Arrays

Un array en C es un bloque contiguo de memoria de tamaño fijo que contiene elementos de un tipo — su tamaño debe conocerse en tiempo de compilación (o proporcionarse al asignarlo dinámicamente) y nunca crece:

```c
#include <stdio.h>

int main(void) {
    int scores[5] = {90, 85, 77, 92, 88};

    int total = 0;
    for (int i = 0; i < 5; i++) {
        total += scores[i];
    }

    printf("average: %.1f\n", total / 5.0);

    int grid[2][3] = {{1, 2, 3}, {4, 5, 6}}; /* a 2D array is an array of arrays */
    printf("grid[1][2] = %d\n", grid[1][2]);

    return 0;
}
```

Crucialmente, C **no realiza verificación de límites**: `scores[10]` compila perfectamente y lee cualquier memoria que se encuentre más allá del final del array, lo cual es comportamiento indefinido — puede fallar, puede leer basura silenciosamente, o puede parecer que funciona hasta el día en que no lo hace.

## Los strings son simplemente arrays de char

C no tiene un tipo de cadena dedicado. Un "string" es un array de `char` terminado por un byte nulo `'\0'`, y las funciones de cadenas de la biblioteca estándar (en `<string.h>`) dependen todas de encontrar ese terminador:

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char name[20] = "Ada"; /* the compiler adds the '\0' terminator automatically */

    printf("length: %zu\n", strlen(name)); /* 3, not counting the '\0' */

    strcat(name, " Lovelace"); /* appends onto the existing buffer */
    printf("name: %s\n", name);

    if (strcmp(name, "Ada Lovelace") == 0) { /* strcmp, not == */
        printf("matched\n");
    }

    return 0;
}
```

`==` sobre dos valores `char*` compara *punteros* (direcciones de memoria), no el contenido de la cadena — un bug clásico de principiante — por lo que comparar el contenido de las cadenas siempre requiere `strcmp`. `strcat` y funciones similares tampoco verifican que el buffer de destino sea suficientemente grande, así que escribir más caracteres de los que un buffer puede contener corrompe silenciosamente la memoria adyacente (un **desbordamiento de buffer**).

## Construir una lista enlazada con structs y punteros

Más allá de los arrays, las estructuras de datos en C se construyen combinando `struct` (agrupando campos relacionados) con punteros (enlazando nodos entre sí):

```c
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int value;
    struct Node *next; /* a struct can point to another instance of itself */
};

int main(void) {
    struct Node *head = malloc(sizeof(struct Node));
    head->value = 10;
    head->next = malloc(sizeof(struct Node));
    head->next->value = 20;
    head->next->next = NULL; /* marks the end of the list */

    for (struct Node *cur = head; cur != NULL; cur = cur->next) {
        printf("%d -> ", cur->value);
    }
    printf("NULL\n");

    /* every malloc needs a matching free, walked node by node */
    struct Node *cur = head;
    while (cur != NULL) {
        struct Node *next = cur->next;
        free(cur);
        cur = next;
    }

    return 0;
}
```

`head->value` es una forma abreviada de `(*head).value` — desreferenciar el puntero, y luego acceder al campo. Este patrón de lista enlazada (un struct que contiene un puntero al siguiente struct del mismo tipo) es la base de casi toda estructura de datos hecha a mano en C: listas enlazadas, árboles y grafos siguen todos este mismo patrón. La página [Structs y Métodos](/es/programming-languages/c/oop-or-structs) cubre el propio `struct` con más profundidad.
