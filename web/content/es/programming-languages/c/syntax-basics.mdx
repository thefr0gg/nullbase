C es estática y (mayormente) débilmente tipado: toda variable tiene un tipo fijo declarado por adelantado, pero el compilador a menudo te dejará convertir entre tipos sin mucha queja, a veces truncando o reinterpretando datos silenciosamente en el proceso. Entender los tipos básicos de C y cómo se declaran es la base de todo lo demás en el lenguaje.

## Tipos básicos y declaraciones

Los tipos incorporados de C describen tamaños de almacenamiento en bruto, no conceptos de alto nivel como "un número entero" — `int` normalmente tiene 32 bits, pero el estándar de C solo garantiza un rango mínimo, no un tamaño exacto, que es por lo que existen tipos de ancho fijo como `int32_t` para cuando el tamaño exacto importa.

```c
#include <stdio.h>

int main(void) {
    int count = 42;          /* whole numbers */
    float price = 19.99f;    /* single-precision floating point */
    double precise = 3.14159265358979; /* double-precision floating point */
    char grade = 'B';        /* a single byte, usually holding one character */
    unsigned int score = 100; /* no sign bit, so it can't go negative */

    printf("count=%d price=%.2f grade=%c\n", count, price, grade);
    return 0;
}
```

Toda variable debe declararse con un tipo antes de usarse, y las variables locales sin inicializar contienen cualquier basura que ya hubiera en esa memoria — C no las pondrá a cero por ti ni se quejará en tiempo de compilación si lees una antes de asignarle un valor.

## Operadores y E/S con formato

`printf` escribe salida con formato usando **especificadores de formato** (`%d` para `int`, `%f` para punto flotante, `%s` para una cadena, `%c` para un carácter) que deben coincidir con el tipo del argumento pasado — no hacerlos coincidir es C válido pero produce basura o un crash, ya que `printf` no tiene forma de verificar tipos en tiempo de compilación por sí solo. `scanf` lee la entrada de la misma manera, pero al revés, y necesita la *dirección* de la variable en la que escribir (de ahí el `&`):

```c
#include <stdio.h>

int main(void) {
    int a, b;
    printf("Enter two integers: ");
    scanf("%d %d", &a, &b);

    int sum = a + b;
    int remainder = a % b;   /* modulo: remainder of a divided by b */

    printf("sum = %d, remainder = %d\n", sum, remainder);
    printf("a > b is %d\n", a > b); /* comparisons produce 0 or 1 as an int */
    return 0;
}
```

C no tiene un tipo booleano dedicado en los estándares más antiguos — comparaciones como `a > b` se evalúan al `int` `0` (falso) o `1` (verdadero), y cualquier valor distinto de cero se trata como "verdadero" en una condición. `stdbool.h` (C99 en adelante) agrega un tipo `bool` con `true`/`false` como alias de `1`/`0`, pero por debajo sigue siendo simplemente un entero.

## Constantes y ámbito

`const` marca una variable como de solo lectura después de la inicialización (el compilador rechaza la reasignación), y `#define` crea una macro de preprocesador que se sustituye textualmente antes de que comience siquiera la compilación:

```c
#include <stdio.h>

#define MAX_USERS 100   /* preprocessor macro, substituted as text */

const double PI = 3.14159; /* typed constant, checked by the compiler */

int main(void) {
    double radius = 2.0;
    double area = PI * radius * radius;
    printf("Area: %.2f, capacity: %d\n", area, MAX_USERS);
    return 0;
}
```

`MAX_USERS` nunca existe realmente como una variable en memoria — el preprocesador reemplaza cada aparición del texto `MAX_USERS` por `100` antes de que el compilador siquiera vea el código, mientras que `PI` es una variable real y tipada que el compilador puede verificar.
