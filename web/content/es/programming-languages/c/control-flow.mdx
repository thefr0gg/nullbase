El flujo de control de C le resultará familiar a cualquiera que haya usado un lenguaje de la familia C (JavaScript, Java, C#, Go) — y no es coincidencia, ya que todos ellos tomaron prestada su sintaxis de `if`, `for` y `while` directamente de C. Lo distintivamente C es la falta de barandillas de seguridad: las condiciones aceptan cualquier entero (no solo un `bool`), `switch` cae por defecto de un caso al siguiente a menos que uses `break`, y `goto` sigue siendo una palabra clave real y funcional.

## if / else y "veracidad"

Cualquier expresión que se evalúe a un valor distinto de cero cuenta como "verdadera" en una condición — no hay un requisito booleano dedicado:

```c
#include <stdio.h>

int main(void) {
    int age = 20;

    if (age < 13) {
        printf("child\n");
    } else if (age < 20) {
        printf("teenager\n");
    } else {
        printf("adult\n");
    }

    int flag = 5; /* nonzero, so this branch runs even though 5 isn't 1 */
    if (flag) {
        printf("flag is truthy: %d\n", flag);
    }

    return 0;
}
```

Ese último bloque es una fuente común de bugs: `if (flag)` es válido para cualquier entero, así que un error de escritura como `if (result = 0)` (asignación, no comparación) compila silenciosamente y siempre se evalúa como falso, ya que el propio `0` es falso — la mayoría de los compiladores avisan de esto con `-Wall`, pero no es un error.

## switch y fallthrough

`switch` salta a la etiqueta `case` que coincide y luego **sigue ejecutando cada sentencia siguiente** hasta que encuentra un `break` o el final del bloque — no hay un break implícito como en algunos otros lenguajes:

```c
#include <stdio.h>

int main(void) {
    int day = 3;

    switch (day) {
        case 1:
        case 2:
        case 3:
        case 4:
        case 5:
            printf("weekday\n");
            break;
        case 6:
        case 7:
            printf("weekend\n");
            break;
        default:
            printf("invalid day\n");
    }

    return 0;
}
```

Apilar `case 1:` hasta `case 5:` sin ninguna sentencia entre ellos es un fallthrough intencional, usado aquí para agrupar varios valores bajo una misma acción. Olvidar un `break` donde *no* se pretendía el fallthrough es uno de los bugs más comunes de C.

## Bucles: while, do-while, for

```c
#include <stdio.h>

int main(void) {
    int i = 0;
    while (i < 3) {          /* checks condition before each iteration */
        printf("while: %d\n", i);
        i++;
    }

    int j = 0;
    do {                       /* always runs at least once */
        printf("do-while: %d\n", j);
        j++;
    } while (j < 3);

    for (int k = 0; k < 5; k++) {
        if (k == 2) continue;  /* skip the rest of this iteration */
        if (k == 4) break;     /* exit the loop entirely */
        printf("for: %d\n", k);
    }

    return 0;
}
```

`do-while` es el único bucle que garantiza ejecutar su cuerpo al menos una vez, ya que la condición se verifica *después* de la primera pasada — útil para cosas como "pedir un dato al usuario, y volver a pedirlo mientras la entrada sea inválida."
