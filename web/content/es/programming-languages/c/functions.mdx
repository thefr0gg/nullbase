Las funciones en C son exclusivamente por valor: cada argumento se copia en los parámetros locales de la función, así que una función nunca puede modificar la variable del llamador directamente — solo su propia copia. Este único hecho determina buena parte del C idiomático, incluyendo por qué los "parámetros de salida" se pasan como punteros en lugar de devolverse directamente, y por qué entender el paso por valor es un prerrequisito para entender los punteros en absoluto.

## Declarar y llamar a una función

Una función tiene un tipo de retorno, un nombre, una lista de parámetros, y un cuerpo. C también distingue un **prototipo** (solo la firma, terminada en `;`) de una **definición** (la firma más el cuerpo) — un prototipo te permite llamar a una función antes de que el compilador haya visto su definición completa:

```c
#include <stdio.h>

int add(int a, int b); /* prototype: tells the compiler this function exists */

int main(void) {
    int result = add(3, 4); /* can be called here even though add is defined below */
    printf("3 + 4 = %d\n", result);
    return 0;
}

int add(int a, int b) { /* definition */
    return a + b;
}
```

Sin el prototipo, llamar a `add` antes de que su definición aparezca en el archivo sería un error de compilación en el C moderno — el compilador necesita conocer la firma de una función antes de poder generar código que la llame correctamente.

## Paso por valor y por qué importa

```c
#include <stdio.h>

void tryToDouble(int n) {
    n = n * 2; /* only modifies the local copy */
}

void doubleViaPointer(int *n) {
    *n = *n * 2; /* dereferences the pointer to modify the caller's variable */
}

int main(void) {
    int x = 5;

    tryToDouble(x);
    printf("after tryToDouble: %d\n", x); /* still 5 */

    doubleViaPointer(&x); /* pass the address of x */
    printf("after doubleViaPointer: %d\n", x); /* now 10 */

    return 0;
}
```

`tryToDouble` recibe una copia del valor de `x` y no puede afectar al original. `doubleViaPointer` en cambio recibe la *dirección* de `x`, y la desreferencia con `*n` para llegar directamente a la memoria del llamador — así es como C simula el "paso por referencia", y es la razón por la que funciones como `scanf` requieren `&variable` para cada valor que necesitan escribir de vuelta.

## Recursión

Una función que se llama a sí misma funciona exactamente igual que lo haría con iteración, siempre que exista un caso base que detenga la recursión:

```c
#include <stdio.h>

long factorial(int n) {
    if (n <= 1) {
        return 1; /* base case */
    }
    return n * factorial(n - 1); /* recursive case */
}

int main(void) {
    for (int i = 1; i <= 6; i++) {
        printf("%d! = %ld\n", i, factorial(i));
    }
    return 0;
}
```

Cada llamada a `factorial` obtiene su propio marco de pila con su propia copia de `n` — la recursión en C consume memoria real de pila por cada llamada, y un caso base ausente o inalcanzable causa un desbordamiento de pila en lugar de un bucle infinito que simplemente se cuelga.
