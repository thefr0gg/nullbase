Go mantiene el flujo de control deliberadamente mínimo. No hay `while`, no
hay `do-while`, no hay operador ternario — `for` cubre toda necesidad de
bucle, y `switch` es más flexible que en la mayoría de los lenguajes de la
familia C.

## if / else

Las condiciones nunca necesitan paréntesis, pero la llave de apertura debe
estar en la misma línea que `if` — la gramática de Go depende de la
inserción automática de punto y coma, y una llave en su propia línea rompe
eso.

```go
func classify(score int) string {
	if score >= 90 {
		return "A"
	} else if score >= 80 {
		return "B"
	} else {
		return "F"
	}
}
```

`if` también acepta una sentencia inicializadora, con alcance limitado a la
cadena `if`/`else` — usada comúnmente para comprobar un error justo donde se
produce:

```go
if value, ok := lookup("key"); ok {
	fmt.Println("found:", value)
} else {
	fmt.Println("not found")
}
// value y ok no son visibles aquí — solo existen dentro del if/else
```

## for — el único bucle de Go

Go tiene una única palabra clave de bucle que cubre lo que otros lenguajes
dividen en `for`, `while`, y bucles infinitos.

Forma clásica de tres partes:

```go
for i := 0; i < 5; i++ {
	fmt.Println(i)
}
```

Solo condición — este es el `while` de Go:

```go
n := 1
for n < 100 {
	n *= 2
}
```

Sin condición en absoluto — un bucle infinito, típicamente combinado con
`break`:

```go
count := 0
for {
	count++
	if count == 3 {
		break
	}
}
```

`for ... range` itera sobre slices, arrays, maps, strings, y channels:

```go
names := []string{"Ada", "Grace", "Linus"}
for i, name := range names {
	fmt.Println(i, name)
}
```

## switch

El `switch` de Go no cae por defecto de un caso al siguiente (lo opuesto a
C/Java), así que rara vez necesitas `break`. Los casos también pueden listar
múltiples valores u omitir la expresión del switch por completo para actuar
como una cadena if/else más limpia:

```go
func describe(n int) string {
	switch {
	case n < 0:
		return "negative"
	case n == 0:
		return "zero"
	case n%2 == 0:
		return "positive even"
	default:
		return "positive odd"
	}
}
```

Usa `fallthrough` explícitamente en la rara ocasión en que quieras que el
siguiente caso se ejecute de todas formas:

```go
switch day := "sat"; day {
case "sat", "sun":
	fmt.Println("weekend")
default:
	fmt.Println("weekday")
}
```
