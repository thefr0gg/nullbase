La concurrencia es la característica distintiva de Go. En vez de exponer
threads e locks de sistema operativo puros como la herramienta principal, Go
te da **goroutines** — unidades de ejecución concurrente extremadamente
ligeras gestionadas por el runtime de Go — y **channels**, tuberías tipadas
para que las goroutines se comuniquen de forma segura. La filosofía, tomada
del modelo CSP de Tony Hoare, se resume en una línea de la documentación de
Go: "No te comuniques compartiendo memoria; en su lugar, comparte memoria
comunicándote."

## Goroutines

Iniciar una goroutine es una sola palabra clave, `go`, colocada antes de una
llamada a función. La llamada retorna de inmediato, y la función se ejecuta
concurrentemente:

```go
func sayHello() {
	fmt.Println("hello from a goroutine")
}

func main() {
	go sayHello()
	time.Sleep(100 * time.Millisecond) // le da la oportunidad de ejecutarse
	fmt.Println("main done")
}
```

Las goroutines son baratas — unos pocos kilobytes de stack que crece según
se necesita, comparado con megabytes para un thread de sistema operativo —
así que es normal que un programa Go ejecute miles de ellas a la vez. El
`time.Sleep` de arriba es una forma tosca de esperar; el código real usa
channels o `sync.WaitGroup` en su lugar, ya que dormir una duración fija es
una condición de carrera esperando a ocurrir.

## Channels

Un channel es un conducto tipado en el que envías valores y del que recibes
valores, creado con `make`:

```go
func main() {
	ch := make(chan string)

	go func() {
		ch <- "result from goroutine" // enviar
	}()

	msg := <-ch // recibir — bloquea hasta que llegue un valor
	fmt.Println(msg)
}
```

Enviar y recibir en un channel sin buffer bloquean ambos hasta que el otro
lado esté listo, que es lo que hace útiles a los channels para
sincronización, no solo para transferencia de datos: la recepción de arriba
solo se completa después de que la goroutine haya enviado realmente su
valor, dándote un traspaso seguro sin ningún lock explícito.

## Channels con buffer y cierre

`make(chan T, n)` crea un channel con espacio para `n` valores antes de que
un envío bloquee. Cerrar un channel con `close` señala que no llegarán más
valores, lo cual `range` usa para saber cuándo detenerse:

```go
func main() {
	results := make(chan int, 3)

	go func() {
		for i := 1; i <= 3; i++ {
			results <- i * i
		}
		close(results)
	}()

	for value := range results {
		fmt.Println(value) // 1, luego 4, luego 9
	}
}
```

## select

`select` espera en múltiples operaciones de channel a la vez y continúa con
la que esté lista primero — el equivalente en concurrencia de un `switch`
sobre channels:

```go
func main() {
	c1 := make(chan string)
	c2 := make(chan string)

	go func() { c1 <- "from c1" }()
	go func() { c2 <- "from c2" }()

	for i := 0; i < 2; i++ {
		select {
		case msg1 := <-c1:
			fmt.Println(msg1)
		case msg2 := <-c2:
			fmt.Println(msg2)
		}
	}
}
```
