Go tiene tres tipos compuestos integrados que vale la pena entender bien:
arrays, slices, y maps. Los slices son lo que usarás casi todo el tiempo —
los arrays existen sobre todo como la base sobre la que se construyen los
slices.

## Arrays

Un array tiene una longitud fija que forma parte de su tipo: `[3]int` y
`[5]int` son tipos diferentes y no pueden asignarse el uno al otro.

```go
var scores [3]int
scores[0] = 90
scores[1] = 85
scores[2] = 78
fmt.Println(scores) // [90 85 78]

primes := [5]int{2, 3, 5, 7, 11}
```

Como el tamaño es fijo y se conoce en tiempo de compilación, los arrays se
usan directamente por valor: asignar un array a otro copia cada elemento.

## Slices

Un slice es una vista sobre un array subyacente: un puntero, una longitud, y
una capacidad. Los slices son a lo que casi siempre recurres en vez de a los
arrays, porque pueden crecer.

```go
nums := []int{1, 2, 3}
nums = append(nums, 4)
fmt.Println(nums) // [1 2 3 4]
```

`make` crea un slice con una longitud dada (y opcionalmente una capacidad):

```go
buf := make([]int, 3)    // [0 0 0]
buf2 := make([]int, 0, 10) // longitud 0, capacidad 10
```

Cortar (`slicing`) un slice existente (`s[low:high]`) **no** copia — el
nuevo slice comparte el mismo array subyacente que el original. Mutar a
través de uno es visible a través del otro, hasta que un `append` fuerza una
reasignación de memoria:

```go
a := []int{1, 2, 3, 4, 5}
b := a[1:3] // [2 3], comparte el array de respaldo de a
b[0] = 99
fmt.Println(a) // [1 99 3 4 5] — a también cambió
```

Este aliasing es una de las fuentes más comunes de sorpresa para quienes
vienen de lenguajes donde cortar siempre copia. Cuando necesites una copia
independiente, usa la función integrada `copy`:

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
copy(dst, src)
```

## Maps

Un map es la tabla hash integrada de Go, declarada con
`map[KeyType]ValueType`:

```go
ages := map[string]int{
	"ada":  36,
	"grace": 85,
}

ages["linus"] = 55
fmt.Println(ages["ada"]) // 36

value, ok := ages["missing"]
fmt.Println(value, ok) // 0 false — el valor cero, y ok indica ausencia
```

Borrar una clave usa la función integrada `delete`:

```go
delete(ages, "grace")
```

Iterar un map con `range` visita las entradas en **orden aleatorio** por
diseño — Go aleatoriza deliberadamente el orden de iteración para evitar que
el código dependa accidentalmente de él. Ordena las claves tú mismo si
necesitas un orden estable.
