Las funciones en Go se declaran con `func`, y el tipo de retorno viene
después de la lista de parámetros, no antes del nombre:

```go
func add(a int, b int) int {
	return a + b
}
```

Los parámetros consecutivos del mismo tipo pueden compartir una sola
anotación de tipo:

```go
func add(a, b int) int {
	return a + b
}
```

## Valores de retorno múltiples

Esta es una de las características más distintivas de Go, y se usa por
todas partes en la librería estándar. Una función puede devolver más de un
valor, separados por comas:

```go
func divide(a, b int) (int, int) {
	quotient := a / b
	remainder := a % b
	return quotient, remainder
}

func main() {
	q, r := divide(17, 5)
	fmt.Println(q, r) // 3 2
}
```

El uso más común es emparejar un resultado con un error o un flag "ok", que
es cómo Go reemplaza las excepciones y la ambigüedad de los retornos
anulables en un solo idioma:

```go
func lookup(m map[string]int, key string) (int, bool) {
	value, ok := m[key]
	return value, ok
}

func main() {
	scores := map[string]int{"ada": 100}
	if value, ok := lookup(scores, "ada"); ok {
		fmt.Println("score:", value)
	}
}
```

Si no necesitas uno de los valores de retorno, descártalo con `_`:

```go
_, remainder := divide(17, 5)
```

## Valores de retorno con nombre

Los valores de retorno pueden nombrarse en la firma. Un `return` desnudo
entonces devuelve sus valores actuales — útil para funciones cortas, pero
fácil de abusar hasta llegar a código ilegible si se usa en exceso:

```go
func split(sum int) (x, y int) {
	x = sum * 4 / 9
	y = sum - x
	return // returns x, y
}
```

## Parámetros variádicos

Un parámetro prefijado con `...` acepta cualquier número de argumentos,
recogidos en un slice dentro de la función:

```go
func sum(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

func main() {
	fmt.Println(sum(1, 2, 3))    // 6
	fmt.Println(sum())            // 0
}
```

## Funciones como valores

Las funciones son valores de primera clase en Go — pueden asignarse a
variables, pasarse como argumentos, y devolverse desde otras funciones:

```go
func makeMultiplier(factor int) func(int) int {
	return func(n int) int {
		return n * factor
	}
}

func main() {
	double := makeMultiplier(2)
	fmt.Println(double(21)) // 42
}
```
