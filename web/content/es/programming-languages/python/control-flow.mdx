Las instrucciones condicionales y de bucle de Python se leen casi como inglés llano, pero vale la pena ser precisos sobre la mecánica subyacente, especialmente las partes que difieren de los lenguajes de la familia C.

```python
temperature = 72
if temperature > 80:
    print("hot")
elif temperature > 60:
    print("mild")
else:
    print("cold")
```

`elif` es la forma en que Python escribe "else if" — no hay un par de palabras clave `else if` separado, y las condiciones nunca necesitan paréntesis alrededor (aunque puedes añadirlos). Cualquier valor puede usarse como condición, no solo booleanos: `0`, `""`, `None`, y las colecciones vacías (`[]`, `{}`, `()`) son todas "falsy," y todo lo demás es "truthy," así que `if some_list:` es una forma idiomática de comprobar "¿esta lista no está vacía?" sin comparar longitudes explícitamente.

```python
fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(index, fruit)
```

El bucle `for` de Python itera directamente sobre los *elementos* de una secuencia — no hay un patrón de conteo al estilo C `for (i = 0; i < len; i++)`. Cuando el índice realmente se necesita junto al valor, `enumerate()` envuelve la secuencia para producir pares `(index, value)`, que es la forma idiomática de obtener ambos sin llevar un contador manualmente.

```python
n = 0
while n < 5:
    if n == 3:
        n += 1
        continue
    print(n)
    n += 1
```

Los bucles `while` se ejecutan mientras su condición se mantenga truthy; `continue` salta directamente a la siguiente comprobación de condición, y `break` sale del bucle por completo. Tampoco existe `n++` — Python no tiene operadores de incremento/decremento, solo `n += 1`.

Una característica genuinamente inusual: tanto los bucles `for` como `while` pueden tener una cláusula `else`, que se ejecuta solo si el bucle terminó normalmente — es decir, *no* fue detenido por un `break`.

```python
for i in range(2, 10):
    if i % 7 == 0:
        print("found a multiple of 7:", i)
        break
else:
    print("no multiples of 7 found")
```

Lee `for...else` como "si nunca salimos de este bucle con un break, entonces..." — es más útil para bucles de búsqueda donde `break` significa "lo encontré" y caer en `else` significa "busqué en todo, no encontré nada."
