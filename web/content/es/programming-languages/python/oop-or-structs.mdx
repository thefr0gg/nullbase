Una clase de Python se define con `class`, y casi toda clase empieza con un método `__init__` — el constructor, llamado automáticamente cuando se crea una nueva instancia — que configura los atributos de instancia mediante `self`.

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} says Woof!"

rex = Dog("Rex", "Labrador")
print(rex.bark())  # Rex says Woof!
```

`self` es la instancia sobre la que se llamó al método — Python lo pasa explícitamente como el primer parámetro de cada método de instancia, en vez de convertirlo en una palabra clave implícita como `this` en otros lenguajes. `rex.bark()` es en realidad `Dog.bark(rex)` por debajo.

La herencia permite que una clase reutilice y extienda el comportamiento de otra clase. Una subclase llama a `super().__init__(...)` para ejecutar el constructor de la clase padre antes de añadir su propia configuración, y puede sobrescribir cualquier método, incluidos los que el padre ya define.

```python
class Puppy(Dog):
    def __init__(self, name, breed, age_months):
        super().__init__(name, breed)
        self.age_months = age_months

    def bark(self):
        return f"{self.name} says Yip!"

buddy = Puppy("Buddy", "Poodle", 4)
print(buddy.bark())  # Buddy says Yip!
```

Los métodos "dunder" (doble guion bajo) son cómo una clase se conecta a los operadores y funciones incorporados de Python en vez de necesitar su propia API a medida. `__repr__` controla lo que `print()` y el REPL muestran para una instancia; `__eq__` controla lo que hace `==` entre dos instancias.

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

p1 = Point(1, 2)
p2 = Point(1, 2)
print(p1 == p2)  # True — because __eq__ compares the coordinates
print(p1)         # Point(1, 2) — because __repr__ formats it
```

Sin `__eq__`, `==` recae en la comparación de identidad — si los dos nombres se refieren exactamente al mismo objeto en memoria — que casi nunca es lo que quieres para una clase de tipo valor como `Point`.
