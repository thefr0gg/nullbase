Python es un lenguaje interpretado y de tipado dinámico cuyo rasgo definitorio es hacer de la legibilidad una característica del lenguaje en vez de una preferencia de estilo: los bloques se definen por indentación en vez de llaves o palabras clave `end`, así que la estructura visual de un script y su flujo de control real nunca pueden separarse. No hay un paso de compilación separado que ejecutar — la implementación de referencia, CPython, lee un archivo `.py` y lo ejecuta directamente — lo cual es parte de la razón por la que Python aparece en todas partes, desde scripts puntuales hasta backends web en producción, pasando por pipelines de datos y código de machine learning.

```python
print("Hello, world!")

name = "Ada"
age = 36
print(f"{name} is {age} years old")
```

Dos cosas destacan incluso en ese pequeño ejemplo. Primero, no hay ninguna declaración de tipo en ninguna parte — `name` y `age` obtienen su tipo de los valores que se les asignan, y una variable puede reasignarse a un tipo diferente más adelante sin ninguna queja. Segundo, la cadena `f"..."` es un f-string: un literal de cadena con placeholders `{expression}` evaluados en línea, que es la forma en que la mayoría del código Python construye salida formateada en vez de concatenar piezas con `+`.

Python también viene con una gran biblioteca estándar y un ecosistema de paquetes de terceros enorme instalado vía `pip`, así que una sorprendente cantidad de trabajo real — leer JSON, hacer solicitudes HTTP, parsear fechas — no necesita más dependencias que lo que ya está instalado o un solo `pip install`.

```python
def fizzbuzz(n):
    for i in range(1, n + 1):
        if i % 15 == 0:
            print("FizzBuzz")
        elif i % 3 == 0:
            print("Fizz")
        elif i % 5 == 0:
            print("Buzz")
        else:
            print(i)

fizzbuzz(15)
```

Fíjate en que no hay paréntesis alrededor de la condición del `if`, no hay puntos y coma terminando las instrucciones, y la extensión del cuerpo de la función está definida puramente por cuánto están indentadas sus líneas — quita la indentación y es un error de sintaxis, no solo un formato desordenado.
