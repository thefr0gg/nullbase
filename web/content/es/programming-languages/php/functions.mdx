Las funciones en PHP se declaran con la palabra clave `function` y pueden
aparecer a nivel superior (PHP no exige que el código viva dentro de una
clase). Desde PHP 7, los parámetros y valores de retorno pueden llevar type
hints, que el motor aplica en tiempo de ejecución.

## Declaración básica

```php
<?php

function greet(string $name): string {
    return "Hello, $name!";
}

echo greet("Ada") . "\n";
```

## Argumentos por defecto

Cualquier parámetro puede tener un valor por defecto, lo que permite a
quien llama omitirlo. Los parámetros con valor por defecto deben ir después
de los parámetros sin valores por defecto:

```php
<?php

function makeGreeting(string $name, string $greeting = "Hello"): string {
    return "$greeting, $name!";
}

echo makeGreeting("Grace") . "\n";              // Hello, Grace!
echo makeGreeting("Grace", "Welcome") . "\n";    // Welcome, Grace!
```

## Argumentos con nombre

PHP 8.0 añadió los argumentos con nombre, que permiten a quien llama saltar
valores por defecto anteriores sin repetirlos posicionalmente:

```php
<?php

function connect(string $host, int $port = 5432, bool $ssl = false): string {
    return ($ssl ? "ssl://" : "") . "$host:$port";
}

echo connect("db.internal", ssl: true) . "\n"; // ssl://db.internal:5432
```

## Funciones variádicas

Prefijar el último parámetro con `...` recolecta cualquier número de
argumentos finales en un array — el equivalente en PHP de `*args`:

```php
<?php

function sum(int ...$numbers): int {
    $total = 0;
    foreach ($numbers as $n) {
        $total += $n;
    }
    return $total;
}

echo sum(1, 2, 3, 4) . "\n"; // 10
echo sum() . "\n";            // 0
```

El operador de propagación `...` hace lo contrario al llamar a una función:
desempaqueta un array en argumentos posicionales.

```php
<?php

$values = [3, 6, 9];
echo sum(...$values) . "\n"; // 18
```

## Paso por referencia

Por defecto, los argumentos se pasan por valor — una función recibe una
copia. Añadir `&` antes de un parámetro lo pasa por referencia en su lugar,
permitiendo que la función mute la variable de quien llama:

```php
<?php

function increment(int &$n): void {
    $n++;
}

$counter = 10;
increment($counter);
echo $counter . "\n"; // 11
```

## Funciones anónimas y funciones flecha

PHP soporta closures mediante `function` (con una cláusula `use` explícita
para capturar variables externas) y la sintaxis más concisa de función
flecha `fn`, que captura automáticamente por valor:

```php
<?php

$multiplier = 3;

$classic = function (int $n) use ($multiplier): int {
    return $n * $multiplier;
};

$arrow = fn(int $n): int => $n * $multiplier;

echo $classic(5) . " " . $arrow(5) . "\n"; // 15 15
```
