PHP tiene exactamente una estructura de datos compuesta integrada: `array`.
Donde muchos lenguajes te dan un tipo lista separado y un tipo mapa/
diccionario separado, el array de PHP es ambos a la vez, respaldado
internamente por un mapa hash ordenado. Esta es una de las cosas más
específicas de PHP con la que hay que familiarizarse, porque significa que
"array" en PHP es un concepto mucho más amplio que "array" en C, Java, o
Rust.

## Arrays indexados

Sin claves explícitas, PHP asigna claves enteras secuenciales empezando en
0 — este es el caso de uso de "lista":

```php
<?php

$colors = ["red", "green", "blue"];

echo $colors[0] . "\n";   // red
echo count($colors) . "\n"; // 3

$colors[] = "yellow"; // append
foreach ($colors as $color) {
    echo $color . "\n";
}
```

## Arrays asociativos

El mismo tipo `array` acepta claves arbitrarias — cadenas, en este caso —
convirtiéndolo en un mapa hash:

```php
<?php

$user = [
    "name" => "Ada",
    "role" => "admin",
    "age"  => 36,
];

echo $user["name"] . "\n"; // Ada

foreach ($user as $key => $value) {
    echo "$key: $value\n";
}
```

## La rareza: son el mismo tipo, y puedes mezclarlos

Debido a que los arrays indexados y asociativos son la misma estructura
subyacente, nada te impide mezclar claves enteras y de cadena en un mismo
array — y el orden de claves de PHP es **orden de inserción**, no ordenado,
lo cual sorprende a quienes vienen de lenguajes con un tipo hash-map
separado:

```php
<?php

$mixed = [
    "name" => "Grace",
    0      => "first positional",
    "role" => "engineer",
    1      => "second positional",
];

foreach ($mixed as $key => $value) {
    echo "$key => $value\n";
}
// Prints in insertion order: name, 0, role, 1 — not sorted by key type or value
```

Esto también significa que una "lista" en PHP es en realidad solo una
convención (claves enteras secuenciales desde 0), no una garantía —
`array_filter()` sobre un array indexado preserva las claves originales y
puede dejar huecos, lo cual es una fuente muy común de bugs cuando el
código asume que los índices se mantienen contiguos:

```php
<?php

$numbers = [10, 20, 30, 40];
$evens = array_filter($numbers, fn($n) => $n % 2 === 0);

print_r($evens);
// [1 => 20, 3 => 40]  — original keys kept, index 0 and 2 are gone
echo array_values($evens)[0] . "\n"; // array_values() re-indexes from 0
```

## Funciones de array comunes

La biblioteca estándar de PHP tiene bastante más de cien funciones
`array_*`. Algunas que aparecen constantemente:

```php
<?php

$nums = [5, 3, 8, 1];

sort($nums);                          // [1, 3, 5, 8], sorts in place
echo implode(", ", $nums) . "\n";      // "1, 3, 5, 8"

$doubled = array_map(fn($n) => $n * 2, $nums);
$total = array_reduce($nums, fn($carry, $n) => $carry + $n, 0);

echo implode(", ", $doubled) . "\n"; // 2, 6, 10, 16
echo $total . "\n";                   // 17
```
