El flujo de control de PHP te resultará inmediatamente familiar si conoces
cualquier lenguaje de la familia C, con un par de adiciones específicas de
PHP que vale la pena conocer: `match` (añadido en PHP 8.0) y una sintaxis
alternativa de dos puntos diseñada para mezclar PHP con plantillas HTML.

## if / elseif / else

Nota la ortografía: `elseif` (una sola palabra), no `else if`, aunque PHP
acepta ambas — `elseif` es el estilo convencional en las bases de código
PHP.

```php
<?php

function classify(int $score): string {
    if ($score >= 90) {
        return "A";
    } elseif ($score >= 80) {
        return "B";
    } else {
        return "F";
    }
}

echo classify(85) . "\n"; // B
```

## Bucles

PHP tiene `while`, `do...while`, `for`, y `foreach` — siendo foreach el que
usarás constantemente, ya que funciona directamente sobre arrays:

```php
<?php

$fruits = ["apple", "banana", "cherry"];

foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit\n";
}
```

`for` y `while` se comportan exactamente igual que en C:

```php
<?php

for ($i = 0; $i < 3; $i++) {
    echo "count: $i\n";
}

$n = 1;
while ($n < 100) {
    $n *= 2;
}
echo $n . "\n"; // 128
```

## switch

`switch` en PHP usa **comparación laxa** (`==`) por defecto y cae al
siguiente caso a menos que uses `break` — la clásica trampa de estilo C:

```php
<?php

$role = "editor";

switch ($role) {
    case "admin":
        echo "full access\n";
        break;
    case "editor":
    case "author":
        echo "can publish\n";
        break;
    default:
        echo "read only\n";
}
```

## match — una alternativa más estricta, basada en expresiones

`match` (PHP 8.0+) corrige los dos mayores tropiezos de switch: compara con
semántica estricta (`===`), y no hay caída al siguiente caso — cada rama es
una única expresión, y `match` en sí evalúa a un valor.

```php
<?php

$role = "editor";

$access = match ($role) {
    "admin" => "full access",
    "editor", "author" => "can publish",
    default => "read only",
};

echo $access . "\n"; // can publish
```

A diferencia de `switch`, un valor sin coincidencia y sin rama `default`
lanza un `UnhandledMatchError` en vez de no hacer nada silenciosamente — una
mejora de seguridad deliberada.

## La sintaxis alternativa de dos puntos

Dentro de plantillas que mezclan PHP y HTML, PHP ofrece una sintaxis basada
en dos puntos para `if`, `foreach`, `for`, y `while` que evita un muro de
llaves:

```php
<?php $items = ["tea", "coffee"]; ?>
<ul>
<?php foreach ($items as $item): ?>
    <li><?= $item ?></li>
<?php endforeach; ?>
</ul>
```

`<?= $item ?>` es la forma abreviada de `<?php echo $item; ?>` y es común en
archivos de plantilla exactamente por esa razón.
