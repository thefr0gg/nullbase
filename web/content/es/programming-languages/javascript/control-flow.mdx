Las construcciones de flujo de control de JavaScript te resultarán
familiares si has usado cualquier lenguaje de la familia C, con algunas
conveniencias propias de JavaScript añadidas encima: encadenamiento
opcional, fusión de nulos, y un puñado de variantes de bucle pensadas para
iterar colecciones en vez de rangos de índices puros.

## Condicionales

`if`/`else if`/`else` funciona como se espera. JavaScript también tiene un
operador ternario para expresiones condicionales compactas, y dos
operadores que vale la pena conocer bien: `??` (fusión de nulos) y `?.`
(encadenamiento opcional).

```js
function describe(temp) {
  if (temp < 0) {
    return "freezing";
  } else if (temp < 20) {
    return "cool";
  } else {
    return "warm";
  }
}

console.log(describe(-5)); // "freezing"

const label = temp => (temp < 20 ? "cool" : "warm"); // ternario, no hacen falta llaves
```

`??` devuelve su lado derecho solo cuando el izquierdo es `null` o
`undefined` — a diferencia de `||`, que también cae al lado derecho con `0`,
`""`, y `false`. `?.` corta en cortocircuito a `undefined` en vez de lanzar
una excepción cuando un acceso a propiedad topa con `null`/`undefined` a
mitad de una cadena.

```js
const config = { retries: 0 };

console.log(config.retries || 3);  // 3  — 0 es falsy, así que || lo sobrescribe (¡normalmente un bug!)
console.log(config.retries ?? 3);  // 0  — 0 no es nullish, así que ?? lo conserva (normalmente lo que quieres)

console.log(config.server?.host ?? "localhost"); // "localhost", sin crash por el server faltante
```

## Bucles

`for`, `while`, y `do...while` existen todos con su semántica habitual. Dos
formas de bucle adicionales iteran colecciones directamente: `for...of`
(valores de un iterable — arrays, cadenas, `Map`s, `Set`s) y `for...in`
(*claves* de propiedades enumerables de un objeto, generalmente reservado
para objetos en vez de arrays).

```js
const scores = [88, 92, 79];

for (const score of scores) {
  console.log(score);
}
// 88
// 92
// 79

for (let i = 0; i < scores.length; i++) {
  console.log(`index ${i}: ${scores[i]}`);
}

const user = { name: "ada", role: "admin" };
for (const key in user) {
  console.log(key, user[key]);
}
```

`break` sale de un bucle por completo; `continue` salta a la siguiente
iteración. Ambos pueden apuntar a un bucle exterior etiquetado cuando
necesitas escapar de bucles anidados desde dentro.

## switch

`switch` compara con `===` contra cada `case`. Olvidar `break` es uno de
los bugs más comunes de JavaScript — la ejecución cae al siguiente caso a
menos que la detengas explícitamente.

```js
function trafficAction(color) {
  switch (color) {
    case "red":
      return "stop";
    case "yellow":
      return "slow down";
    case "green":
      return "go";
    default:
      return "unknown signal";
  }
}

console.log(trafficAction("yellow")); // "slow down"
```
