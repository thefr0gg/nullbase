JavaScript tiene dos estructuras de datos de trabajo integradas en la
sintaxis del lenguaje — arrays y objetos — más dos tipos de colección
dedicados, `Map` y `Set`, añadidos en ES6 para casos donde los objetos
simples se quedan cortos.

## Arrays

Los arrays son listas ordenadas y redimensionables, y todo array viene con
un amplio conjunto de métodos integrados para transformar datos sin bucles
escritos a mano. `map`, `filter`, y `reduce` son los tres a los que
recurrirás constantemente:

```js
const prices = [10, 25, 8, 40];

const withTax = prices.map(p => p * 1.08);
const affordable = prices.filter(p => p < 30);
const total = prices.reduce((sum, p) => sum + p, 0);

console.log(withTax);   // [10.8, 27, 8.64, 43.2]
console.log(affordable); // [10, 25, 8]
console.log(total);      // 83
```

`map` y `filter` devuelven nuevos arrays en vez de mutar el original;
`push`, `pop`, `splice`, y `sort`, por el contrario, mutan el array en su
lugar — una distinción que vale la pena memorizar ya que es fácil mutar un
array que no pretendías cambiar.

## Objetos

Los objetos son colecciones desordenadas de pares clave/valor (en la
práctica, los motores modernos preservan el orden de inserción para claves
de tipo cadena). El acceso a propiedades funciona con notación de punto o
corchetes, y la desestructuración extrae valores de forma concisa.

```js
const user = {
  name: "ada",
  role: "admin",
  loginCount: 12,
};

const { name, role } = user; // desestructuración
console.log(`${name} (${role})`); // "ada (admin)"

const updated = { ...user, loginCount: user.loginCount + 1 }; // spread — una copia superficial con un campo cambiado
console.log(updated.loginCount); // 13
console.log(user.loginCount);    // 12 — el objeto original no se toca
```

## Igualdad de referencia

Los objetos y arrays se comparan por referencia, no por valor. Dos arrays
con contenido idéntico nunca son `===` a menos que sean literalmente el
mismo objeto en memoria.

```js
const a = [1, 2, 3];
const b = [1, 2, 3];
const c = a;

console.log(a === b); // false — arrays distintos, mismo contenido
console.log(a === c); // true  — c apunta exactamente al mismo array que a

c.push(4);
console.log(a); // [1, 2, 3, 4] — mutar c también cambia a, ya que son el mismo objeto
```

## Map y Set

Un objeto simple solo permite claves de tipo cadena o symbol, y iterar sus
entradas en un orden garantizado es ligeramente incómodo. `Map` soluciona
ambas cosas: cualquier valor puede ser una clave, y itera en el orden de
inserción.

```js
const scores = new Map();
scores.set("alice", 90);
scores.set("bob", 85);

console.log(scores.get("alice")); // 90
console.log(scores.size);          // 2

for (const [player, score] of scores) {
  console.log(`${player}: ${score}`);
}
```

`Set` almacena valores únicos — añadir un duplicado es un no-op — lo cual
convierte la deduplicación en una sola línea:

```js
const tags = new Set(["js", "web", "js", "frontend"]);
console.log(tags.size);       // 3
console.log([...tags]);        // ["js", "web", "frontend"]
console.log(tags.has("web"));  // true
```
