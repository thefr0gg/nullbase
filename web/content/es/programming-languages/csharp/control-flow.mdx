El flujo de control de C# empieza de forma familiar — `if`/`else`, `for`, `while` — y luego va más allá que la mayoría de los lenguajes de la familia C con expresiones `switch` que hacen coincidir según tipo y estructura, no solo igualdad.

## if / else y bucles

```csharp
int score = 82;

if (score >= 90)
{
    Console.WriteLine("A");
}
else if (score >= 80)
{
    Console.WriteLine("B");
}
else
{
    Console.WriteLine("C or below");
}

for (int i = 0; i < 3; i++)
{
    Console.WriteLine($"Iteration {i}");
}

int n = 5;
while (n > 0)
{
    Console.WriteLine(n);
    n--;
}
```

`foreach` itera sobre cualquier `IEnumerable<T>` — arrays, listas, diccionarios — sin gestionar un índice:

```csharp
string[] fruits = { "apple", "banana", "cherry" };
foreach (string fruit in fruits)
{
    Console.WriteLine(fruit);
}
```

## switch clásico

La sentencia `switch` tradicional compara un valor contra un conjunto de casos constantes y requiere un `break` explícito (u otra sentencia de salto) por cada case — caer al siguiente case es un error de compilación a menos que el cuerpo del case esté vacío:

```csharp
int day = 3;
switch (day)
{
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        Console.WriteLine("Weekday");
        break;
    case 6:
    case 7:
        Console.WriteLine("Weekend");
        break;
    default:
        Console.WriteLine("Invalid day");
        break;
}
```

## Pattern matching con expresiones switch

Desde C# 8, `switch` puede usarse como una *expresión* que devuelve un valor, y sus patrones van mucho más allá de la igualdad: los patrones de tipo, los patrones relacionales, y los patrones de propiedad te permiten ramificar según la forma de un objeto en un solo lugar.

```csharp
object shape = new { Kind = "circle", Radius = 3.0 };

string Describe(object value) => value switch
{
    int n when n < 0 => "negative integer",
    int n => $"non-negative integer: {n}",
    string s when s.Length == 0 => "empty string",
    string s => $"string of length {s.Length}",
    null => "nothing at all",
    _ => "something else",
};

Console.WriteLine(Describe(-5));   // negative integer
Console.WriteLine(Describe("hi")); // string of length 2
Console.WriteLine(Describe(null)); // nothing at all
```

Los patrones de propiedad pueden desestructurar y comparar directamente contra los miembros de un objeto, algo común al trabajar con tipos record:

```csharp
record Point(int X, int Y);

string Classify(Point p) => p switch
{
    { X: 0, Y: 0 } => "origin",
    { X: 0 } => "on the Y axis",
    { Y: 0 } => "on the X axis",
    { X: > 0, Y: > 0 } => "first quadrant",
    _ => "elsewhere",
};

Console.WriteLine(Classify(new Point(0, 0))); // origin
Console.WriteLine(Classify(new Point(3, 5))); // first quadrant
```

Las expresiones `switch` de pattern matching deben ser exhaustivas desde el punto de vista del compilador — una rama de descarte `_` es la forma habitual de garantizarlo, de forma similar a `default` en una sentencia `switch` clásica.
