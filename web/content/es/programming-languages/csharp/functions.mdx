En C#, las funciones casi siempre se declaran como **métodos** — miembros de una clase o struct — en lugar de funciones libres independientes (las funciones locales son la excepción, cubiertas más abajo). Un método declara un tipo de retorno, un nombre, y una lista de parámetros.

## Métodos básicos

```csharp
class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }

    // Expression-bodied method: shorthand for a single-expression body
    public int Square(int x) => x * x;
}

var calc = new Calculator();
Console.WriteLine(calc.Add(2, 3));    // 5
Console.WriteLine(calc.Square(4));    // 16
```

Un método que no devuelve nada usa `void`. Los métodos `static` pertenecen al propio tipo en lugar de a una instancia, por lo cual `Main` siempre es `static`.

## Parámetros opcionales y valores por defecto

Los parámetros pueden declarar un valor por defecto, haciéndolos opcionales en el punto de llamada — todo parámetro después de uno con un valor por defecto también debe tener uno:

```csharp
string Greet(string name, string greeting = "Hello", bool shout = false)
{
    string message = $"{greeting}, {name}!";
    return shout ? message.ToUpper() : message;
}

Console.WriteLine(Greet("Ada"));                        // Hello, Ada!
Console.WriteLine(Greet("Ada", "Hey"));                  // Hey, Ada!
Console.WriteLine(Greet("Ada", shout: true));            // HELLO, ADA!
```

## Argumentos con nombre

Cualquier llamada puede pasar argumentos por nombre en lugar de por posición, en cualquier orden — esto es especialmente útil al saltarse parámetros opcionales anteriores, como hizo `shout: true` arriba. Los argumentos con nombre hacen que los puntos de llamada se autodocumenten cuando un método recibe varios parámetros del mismo tipo:

```csharp
void CreateUser(string name, int age, bool isAdmin = false)
{
    Console.WriteLine($"{name}, {age}, admin={isAdmin}");
}

CreateUser(name: "Grace", age: 40, isAdmin: true);
CreateUser(age: 25, name: "Alan"); // order doesn't matter with names
```

## params y funciones locales

`params` le permite a un método aceptar un número variable de argumentos finales como un array, y las funciones locales te permiten anidar un método auxiliar dentro de otro:

```csharp
int Sum(params int[] numbers)
{
    int total = 0;
    foreach (int n in numbers)
    {
        total += n;
    }
    return total;
}

Console.WriteLine(Sum(1, 2, 3, 4)); // 10

int Outer(int x)
{
    int Double(int n) => n * 2; // local function, only visible inside Outer
    return Double(x) + 1;
}

Console.WriteLine(Outer(5)); // 11
```
