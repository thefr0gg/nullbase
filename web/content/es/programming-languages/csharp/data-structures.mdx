C# viene con un pequeño conjunto de tipos de colección que cubren la mayoría de las necesidades cotidianas: arrays de tamaño fijo, el `List<T>` redimensionable, y el `Dictionary<TKey, TValue>` de clave-valor. Los tres son genéricos, así que son seguros en cuanto a tipos sin necesidad de conversiones.

## Arrays

Los arrays tienen un tamaño fijo una vez creados y están indexados desde cero:

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };
Console.WriteLine(numbers.Length); // 5
Console.WriteLine(numbers[0]);     // 1

numbers[0] = 100;

int[] empty = new int[3]; // [0, 0, 0] — value types default to their zero value

int[,] grid = new int[2, 3]; // a 2D array, 2 rows by 3 columns
grid[0, 1] = 7;
```

Como los arrays no pueden crecer ni encogerse, la mayoría del código que necesita una colección de tamaño dinámico recurre en su lugar a `List<T>`.

## List\<T\>

`List<T>` es una colección ordenada y redimensionable — el caballo de batalla cotidiano para secuencias de elementos:

```csharp
using System.Collections.Generic;
using System.Linq;

List<string> names = new List<string> { "Ada", "Grace" };
names.Add("Alan");
names.Remove("Grace");

Console.WriteLine(names.Count);    // 2
Console.WriteLine(names[0]);       // Ada
Console.WriteLine(names.Contains("Alan")); // True

foreach (string name in names)
{
    Console.WriteLine(name);
}

// LINQ works directly on List<T> and most other collections
List<int> evens = new List<int> { 1, 2, 3, 4, 5, 6 }
    .Where(n => n % 2 == 0)
    .ToList();
```

## Dictionary\<TKey, TValue\>

`Dictionary<TKey, TValue>` almacena pares clave-valor con búsqueda rápida por clave:

```csharp
using System.Collections.Generic;

Dictionary<string, int> ages = new Dictionary<string, int>
{
    ["Ada"] = 36,
    ["Grace"] = 85,
};

ages["Alan"] = 41; // adds a new key
ages["Ada"] = 37;  // updates an existing key

if (ages.TryGetValue("Grace", out int graceAge))
{
    Console.WriteLine(graceAge); // 85
}

foreach (KeyValuePair<string, int> pair in ages)
{
    Console.WriteLine($"{pair.Key} is {pair.Value}");
}

Console.WriteLine(ages.ContainsKey("Nobody")); // False
```

`TryGetValue` es la forma idiomática de buscar una clave que podría no existir — indexar con `ages["Nobody"]` sobre una clave ausente lanza una `KeyNotFoundException` en lugar de devolver `null` o un valor por defecto.
