C# (pronunciado "C sharp") es un lenguaje orientado a objetos y estáticamente tipado creado por Microsoft en el año 2000, liderado por Anders Hejlsberg (quien también diseñó TypeScript más adelante). Se ejecuta sobre .NET, un runtime gestionado con un modelo de memoria con recolección de basura, un compilador just-in-time (y cada vez más ahead-of-time), y una biblioteca estándar enorme. C# desde entonces ha crecido mucho más allá de Windows: el .NET moderno es multiplataforma, de código abierto, y ejecuta cargas de trabajo de producción en contenedores Linux, en juegos de Unity, y en móviles a través de .NET MAUI.

C# empezó como un primo cercano de Java, pero los dos lenguajes divergieron rápidamente. C# agregó genéricos con soporte real en tiempo de ejecución, propiedades como una construcción de primera clase del lenguaje, LINQ (sintaxis de consulta incorporada al lenguaje), y, más recientemente, `async`/`await` para código asíncrono, tipos de referencia anulables para detectar bugs relacionados con null en tiempo de compilación, y pattern matching que sigue expandiéndose con cada versión.

## Qué hace distintivo a C#

- **Propiedades, no solo campos.** C# incorpora la sintaxis de getter/setter directamente en el lenguaje (`public int Age { get; set; }`), así que el encapsulamiento no requiere escribir el código repetitivo de `getAge()`/`setAge()`.
- **`async`/`await` como sintaxis de primera clase.** El código asíncrono y no bloqueante se lee como código síncrono, respaldado por `Task` y `Task<T>`.
- **Genéricos fuertes.** A diferencia de los genéricos con borrado de tipo de Java, los genéricos de C# se reifican en tiempo de ejecución, lo cual los hace más rápidos y te permite hacer cosas como `typeof(T)` dentro de un método genérico.
- **LINQ.** Consulta y transforma colecciones con sintaxis similar a SQL o cadenas fluidas de métodos (`.Where(...)`, `.Select(...)`) incorporadas directamente al lenguaje y a la biblioteca estándar.
- **Tipos de referencia anulables.** Desde C# 8, el compilador puede advertirte en tiempo de compilación cuando una referencia que no se supone que sea `null` podría serlo.

Aquí hay un programa mínimo y completo en C#:

```csharp
Console.WriteLine("Hello, nullbase!");
```

El C# moderno (desde las sentencias de nivel superior de C# 9) no requiere un envoltorio de `class` y método `Main` para programas simples — el compilador genera uno por ti tras bambalinas. El código más antiguo, y la mayoría de los proyectos reales, todavía lo escriben explícitamente:

```csharp
using System;

namespace HelloWorld
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, nullbase!");
        }
    }
}
```

## Cuándo recurrirías a C#

C# es la elección por defecto para APIs web y backends de ASP.NET Core, software de escritorio y de línea de negocio empresarial en Windows, y — a través del motor de videojuegos Unity — una enorme porción de los juegos comerciales. Su combinación de rendimiento, seguridad de memoria, y una biblioteca estándar rica lo convierten en una fuerte opción de propósito general en cualquier lugar donde de otro modo se consideraría el ecosistema de la JVM.
