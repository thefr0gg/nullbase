Cada guía aquí sigue la misma forma, así que cambiar entre lenguajes significa comparar cosas equivalentes: sintaxis y variables, flujo de control, funciones, estructuras de datos, cómo el lenguaje estructura datos + comportamiento (clases, structs, traits), manejo de errores, módulos y paquetes, y un tema avanzado específico de ese lenguaje (gestión de memoria, ownership, concurrencia, genéricos, etcétera). Cada página termina con 3 ejercicios prácticos — ensamblaje de código por arrastrar y soltar, y predecir la salida — así que leer no es lo único que sucede en la página.

## Lenguajes de sistemas

- **[C](/es/programming-languages/c)** — gestión manual de memoria, punteros, y el modelo al que eventualmente hacen referencia la mayoría de los demás lenguajes.
- **[C++](/es/programming-languages/cpp)** — el modelo de C más clases, referencias, y gestión de recursos basada en RAII.
- **[Rust](/es/programming-languages/rust)** — seguridad de memoria sin un recolector de basura, impuesta en tiempo de compilación mediante ownership y borrowing.
- **[Go](/es/programming-languages/go)** — un lenguaje pequeño, con recolección de basura, construido en torno a goroutines y canales para la concurrencia.

## Lenguajes de aplicación y scripting

- **[Python](/es/programming-languages/python)** — sintaxis legible, tipado dinámico, y una biblioteca estándar que cubre la mayoría de las tareas cotidianas.
- **[JavaScript](/es/programming-languages/javascript)** — el lenguaje del navegador, y cada vez más del servidor, construido en torno a un bucle de eventos y ejecución asíncrona.
- **[TypeScript](/es/programming-languages/typescript)** — JavaScript más un sistema de tipos estático comprobado antes de que el código se ejecute siquiera.
- **[PHP](/es/programming-languages/php)** — un lenguaje de scripting del lado del servidor construido en torno a manejar una solicitud HTTP a la vez.

## Lenguajes empresariales y de runtime gestionado

- **[Java](/es/programming-languages/java)** — un lenguaje estáticamente tipado, profundamente orientado a objetos, que corre en la JVM.
- **[C#](/es/programming-languages/csharp)** — un lenguaje estáticamente tipado sobre el runtime .NET, cercano en forma a Java con sus propios idiomas (propiedades, LINQ, `async`/`await`).
