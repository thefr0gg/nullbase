Las sentencias de flujo de control deciden qué código se ejecuta realmente y cuántas veces — sin ellas, un programa en C++ sería simplemente una secuencia lineal de sentencias ejecutadas una sola vez, de arriba a abajo.

## `if` / `else if` / `else`

```cpp
#include <iostream>

int main() {
    int score = 82;

    if (score >= 90) {
        std::cout << "Grade: A\n";
    } else if (score >= 80) {
        std::cout << "Grade: B\n";
    } else if (score >= 70) {
        std::cout << "Grade: C\n";
    } else {
        std::cout << "Grade: F\n";
    }
    return 0;
}
```

Las condiciones se evalúan de arriba a abajo, y se ejecuta la primera rama cuya condición sea `true` — el resto se omite, incluso si una condición posterior también hubiera sido `true`. Un `if` sin un `else` correspondiente simplemente no hace nada cuando su condición es `false`.

## `switch`

```cpp
#include <iostream>

int main() {
    int day = 3;

    switch (day) {
        case 1:
            std::cout << "Monday\n";
            break;
        case 2:
            std::cout << "Tuesday\n";
            break;
        case 3:
            std::cout << "Wednesday\n";
            break;
        default:
            std::cout << "Some other day\n";
            break;
    }
    return 0;
}
```

`switch` compara un valor contra un conjunto de casos constantes. Cada `case` necesita un `break` explícito — sin él, la ejecución **cae** hacia el siguiente case sin importar si su valor coincide o no, una peculiaridad de C++ heredada de C que es una fuente común de bugs cuando se olvida.

## Bucles

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores = {70, 85, 90, 60};

    // classic for loop, index-based
    for (int i = 0; i < scores.size(); i++) {
        std::cout << "Index " << i << ": " << scores[i] << "\n";
    }

    // range-based for (C++11), no index needed
    for (int score : scores) {
        if (score < 65) continue;
        std::cout << "Passed with " << score << "\n";
    }

    // while loop
    int attempts = 0;
    while (attempts < 3) {
        std::cout << "Attempt " << attempts << "\n";
        attempts++;
    }
    return 0;
}
```

El clásico `for (init; condición; incremento)` da control total sobre la variable del bucle, lo cual importa cuando necesitas el índice en sí (como arriba, al imprimirlo) o necesitas saltar de más de uno en uno. El **for basado en rango**, agregado en C++11, itera directamente sobre los elementos de un contenedor sin indexado manual — es la forma preferida siempre que no se necesite el índice, ya que no hay margen para un error de desplazamiento por uno. `continue` salta directamente a la siguiente iteración; `break` (no mostrado aquí) saldría del bucle por completo. `while` se ejecuta mientras su condición se cumpla, verificada antes de cada iteración — si la condición es `false` desde el principio, el cuerpo nunca se ejecuta, a diferencia de `do...while`, que siempre ejecuta el cuerpo al menos una vez.
