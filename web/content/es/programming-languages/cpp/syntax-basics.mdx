C++ es **estáticamente tipado**: toda variable tiene un tipo fijado en tiempo de compilación, y el compilador rechaza un programa donde un valor no coincide con el tipo al que se asigna. Esto detecta toda una clase de bugs antes de que el programa siquiera se ejecute, al costo de tener que escribir (o inferir) los tipos de antemano en lugar de decidirlos en tiempo de ejecución.

```cpp
#include <iostream>
#include <string>

int main() {
    int age = 30;
    double price = 19.99;
    char grade = 'A';
    bool isActive = true;
    std::string name = "Ada";

    std::cout << name << " is " << age << " years old.\n";
    return 0;
}
```

Los tipos incorporados fundamentales son `int` (números enteros), `double`/`float` (números en punto flotante), `char` (un solo byte, normalmente un carácter), y `bool` (`true`/`false`). `std::string`, del header `<string>`, no es un tipo incorporado sino parte de la biblioteca estándar — gestiona su propia memoria, así que a diferencia de un array de caracteres estilo C en bruto, crece y se reduce de forma segura conforme se le asigna texto.

## `auto` y `const`

```cpp
#include <iostream>

int main() {
    auto count = 42;          // deduced as int
    auto ratio = 3.14;        // deduced as double
    const int maxRetries = 5; // cannot be reassigned

    std::cout << "count=" << count << " ratio=" << ratio << " max=" << maxRetries << "\n";
    return 0;
}
```

`auto` le pide al compilador que deduzca el tipo de una variable a partir de su inicializador en lugar de escribirlo explícitamente — la variable sigue siendo estáticamente tipada, solo que inferida en lugar de escrita explícitamente. `const` marca una variable como no modificable después de la inicialización; intentar `maxRetries = 10;` más adelante en la función no compilaría. Usar `const` siempre que un valor realmente no debería cambiar documenta esa intención para quien lea el código y permite que el compilador detecte una reasignación accidental.

## Leer entrada

```cpp
#include <iostream>

int main() {
    std::string name;
    int age;

    std::cout << "Enter your name: ";
    std::cin >> name;
    std::cout << "Enter your age: ";
    std::cin >> age;

    std::cout << name << " is " << age << " years old.\n";
    return 0;
}
```

`std::cin` (declarado en `<iostream>`) lee de la entrada estándar de la misma manera que `std::cout` escribe en la salida estándar, usando `>>` en lugar de `<<`. Por defecto, `std::cin >> name` lee un solo token delimitado por espacios en blanco, no una línea completa — leer `"Ada Lovelace"` así solo capturaría `"Ada"`; una línea completa requiere `std::getline(std::cin, name)` en su lugar.
