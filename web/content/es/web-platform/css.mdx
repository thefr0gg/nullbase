CSS (Cascading Style Sheets) describe cómo la estructura de [HTML](/es/web-platform/html) obtiene una presentación visual — colores, disposición, espaciado, tipografía. El mismo elemento puede ser el objetivo de reglas provenientes de más de un lugar a la vez (una hoja de estilos, una etiqueta `<style>`, un atributo `style` en línea, los valores por defecto del propio navegador), así que CSS necesita una forma determinista de decidir cuál gana realmente. Eso es la "cascada" del nombre.

## El modelo de caja

Cada elemento que distribuye el navegador es una caja rectangular formada por cuatro capas anidadas — este es el modelo mental más importante en la disposición de CSS.

Por defecto, `width`/`height` dimensionan solo la caja de contenido — el padding y el borde se añaden encima, por lo que `box-sizing: border-box` (hacer que `width` incluya el padding y el borde) es casi universal en las hojas de estilos reales; sin ella, añadir padding a un elemento lo hace silenciosamente más grande que el ancho que fijaste.

## Selectores y especificidad

La especificidad de un selector es lo que compara la cascada cuando más de una regla coincide con la misma importancia/origen — un ID (`#header`) siempre gana a cualquier cantidad de clases, y cualquier cantidad de clases siempre gana a cualquier cantidad de selectores de elemento, sin importar cuántos del tipo más débil se apilen juntos.

```css
#header .nav a { }      /* 1 id, 1 class, 1 element  -> wins over the line below */
.nav .nav-link a.active { }  /* 0 ids, 3 classes, 1 element */
```

## Disposición: flow, flex y grid

El flujo normal del documento (los elementos de bloque se apilan verticalmente, los elementos en línea fluyen horizontalmente) es el valor por defecto de CSS — `display: flex` y `display: grid` sacan a los hijos de un elemento de ese valor por defecto y los llevan a un algoritmo de disposición unidimensional (flex) o bidimensional (grid), razón por la cual casi ninguna disposición moderna se construye ya con floats.
