Más allá de [HTML](/es/web-platform/html), [CSS](/es/web-platform/css), y el [DOM](/es/web-platform/dom), el navegador expone un amplio conjunto de APIs de JavaScript integradas — capacidades que no forman parte del propio lenguaje JavaScript, pero que ofrece el entorno del navegador dentro del cual se ejecuta JavaScript. Node.js ejecuta el mismo lenguaje con un conjunto de APIs integradas completamente distinto, lo cual es la forma más clara de ver que estas son funciones de la plataforma, no del lenguaje.

## Detección de funciones en lugar de sniffing de navegador

Como no todos los navegadores (o versiones) admiten todas las APIs, el código que depende de una debería comprobar su existencia directamente en lugar de intentar identificar el navegador:

```js
if ("clipboard" in navigator) {
  await navigator.clipboard.writeText("copied!");
} else {
  // fall back to a manual copy affordance
}
```

## Permisos

Varias de estas APIs (geolocalización, notificaciones, portapapeles, cámara/micrófono) están protegidas detrás de un aviso de permiso explícito del usuario la primera vez que una página las solicita — y la mayoría solo funciona en un contexto seguro (`https://` o `localhost`), una restricción deliberada dado que exponen capacidad real del dispositivo/usuario.
