Web Components es un conjunto de APIs nativas del navegador para construir elementos personalizados y reutilizables — `<user-card>`, `<rating-stars>` — que se comportan como cualquier otro elemento [HTML](/es/web-platform/html) (se pueden usar en cualquier marcado, con cualquier framework, o sin ninguno) mientras encapsulan su propia estructura interna y su [CSS](/es/web-platform/css) para que los estilos de la página no puedan filtrarse accidentalmente hacia dentro o hacia fuera.

```html
<my-counter start="5"></my-counter>
```

```js
class MyCounter extends HTMLElement {
  connectedCallback() {
    this.attachShadow({ mode: "open" }).innerHTML = `<button>Count: ${this.getAttribute("start")}</button>`;
  }
}
customElements.define("my-counter", MyCounter);
```

## Las tres tecnologías

Web Components no es una sola API — son tres funciones separadas del navegador que casi siempre se usan juntas.

## Por qué importa aquí la encapsulación

Un `<div class="counter">` normal está completamente expuesto a cada regla CSS a nivel de página y a cada `document.querySelector` — una regla `button { color: red; }` que afecte a toda la página lo afecta a él también, lo quiera o no el autor del componente. El límite del Shadow DOM significa que los estilos internos de un Web Component nunca se filtran hacia fuera, y los estilos de la página nunca se filtran hacia dentro (a menos que se expongan deliberadamente mediante propiedades personalizadas de CSS), lo cual es lo que hace que un componente sea genuinamente seguro de insertar sin importar qué CSS tenga ya la página anfitriona.

## Agnóstico de framework por diseño

Como los Custom Elements son simplemente etiquetas HTML por debajo, un Web Component construido una vez puede usarse dentro de una app de React, una app de Vue, HTML plano, o cualquier framework futuro, sin un envoltorio específico de framework — esta es la principal ventaja frente a un componente construido en el propio modelo de componentes de un framework específico, que solo pueden consumir las apps de ese framework.
