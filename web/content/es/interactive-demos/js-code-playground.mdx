Edita el código de abajo y pulsa **Ejecutar**. Se ejecuta dentro de un iframe `sandbox="allow-scripts"` con `allow-same-origin` deliberadamente omitido — el iframe aislado obtiene un origen opaco, por lo que no tiene forma de leer las cookies, el almacenamiento o el DOM de esta página, ni de hacer llamadas de red con credenciales ambientales. La salida de `console.log` se captura y se muestra abajo; un error no capturado o un bucle infinito (mediante un tiempo de espera) se informa en lugar de bloquear la página.

<CodePlayground
  title="Pruébalo"
  initialCode={`function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

for (let i = 0; i < 8; i++) {
  console.log(i, fib(i));
}`}
/>

Solo JavaScript se ejecuta realmente hoy — la arquitectura (`lib/execution/ExecutionProvider`) es deliberadamente genérica para que otro lenguaje pueda añadirse más adelante como su propio proveedor aislado, sin cambiar este componente.
