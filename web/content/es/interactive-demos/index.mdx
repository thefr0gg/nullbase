Las páginas de referencia de Nullbase no se limitan a texto y bloques de código estáticos — la mayoría de los widgets interactivos del sitio están construidos a partir de un pequeño conjunto reutilizable de primitivas (ver `web/components/interactive/`). Esta sección es un recorrido funcional por ese sistema: cada página a continuación integra una primitiva con datos reales y ejecutables, para que veas exactamente qué escribe un autor para obtenerla.

## Diagramas y flujos

- **[Anatomía y ciclo de vida de una URL](/es/interactive-demos/url-anatomy-and-lifecycle)** — descomponer una URL en sus partes y luego recorrer lo que le sucede.
- **[Por dentro: una solicitud de URL](/es/interactive-demos/under-the-hood-url-request)** — divulgación progresiva que oculta un ciclo de solicitud completo detrás de un botón.
- **[Ciclo de vida de una solicitud HTTP (máquina de estados)](/es/interactive-demos/http-state-machine)** — estados y transiciones interactivos en vez de un diagrama estático.

## Protocolos y comparaciones

- **[Solicitud y respuesta HTTP](/es/interactive-demos/http-request-response)** — construye una solicitud real, obtén una respuesta simulada.
- **[TCP contra UDP](/es/interactive-demos/tcp-vs-udp)** — una comparación que se expande al hacer clic, más un control deslizante que muestra qué controla realmente el tamaño de ventana de TCP.

## Código y datos

- **[Entorno de código JavaScript](/es/interactive-demos/js-code-playground)** — JavaScript editable y ejecutable en un iframe aislado (sandbox).
