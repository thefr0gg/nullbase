Una forma rápida de comprobar si el comportamiento de un fragmento de JavaScript coincide con tu modelo mental. Elige una respuesta, compruébala, y lee la explicación en ambos casos.

<PredictOutput
  title="Array + array"
  code={`console.log([1, 2, 3] + [4, 5, 6]);`}
  options={["1,2,34,5,6", "[1,2,3,4,5,6]", "7", "Error"]}
  correctIndex={0}
  explanation="El operador + sobre dos objetos (incluyendo arrays) los convierte primero a cadenas. [1,2,3].toString() es '1,2,3', [4,5,6].toString() es '4,5,6', y la concatenación de cadenas simplemente las une sin nada entre medio."
  actualOutput="1,2,34,5,6"
/>

<PredictOutput
  title="var dentro de un bucle"
  code={`for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}`}
  options={["0, 1, 2", "3, 3, 3", "0, 0, 0", "Error"]}
  correctIndex={1}
  explanation="var tiene ámbito de función, no de bloque — los tres callbacks capturan la misma i, que ya ha llegado a 3 cuando cualquiera de ellos se ejecuta realmente (setTimeout siempre difiere, incluso con un retraso de 0 ms). Reemplazar var por let daría a cada iteración su propio enlace, mostrando 0, 1, 2 en su lugar."
  actualOutput="3, 3, 3"
/>
