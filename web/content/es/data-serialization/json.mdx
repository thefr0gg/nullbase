JSON (JavaScript Object Notation) es un formato de datos ligero y basado en texto — a pesar del nombre, hoy en día es independiente del lenguaje, con un analizador en prácticamente cualquier lenguaje de programación. Es el formato de cuerpo de solicitud/respuesta por defecto en [REST](/es/web-apis/rest), la mayoría de [RPC](/es/web-apis/rpc) y [GraphQL](/es/web-apis/graphql), y cada respuesta simulada en este sitio es JSON precisamente por esa razón.

```json
{
  "id": 42,
  "name": "Grace Hopper",
  "active": true,
  "roles": ["admin", "editor"],
  "manager": null
}
```

## Lo que JSON no puede representar

JSON no tiene un tipo `Date` — las marcas de tiempo se serializan por convención como cadenas ISO 8601 (`"2024-01-15T09:00:00Z"`) y el consumidor las convierte de vuelta en objetos de fecha reales, no de forma automática. Tampoco puede representar `undefined`, funciones, ni referencias circulares — `JSON.stringify` descarta silenciosamente los valores `undefined` y las funciones, y lanza un error ante una referencia circular.

```js
JSON.stringify({ a: undefined, b: () => {}, c: 1 });
// '{"c":1}' — a and b are just gone, not null
```

## Sintaxis estricta, a propósito

A diferencia de los literales de objeto de JavaScript, JSON no tiene comas finales, ni comentarios, ni claves sin comillas, ni cadenas con comillas simples — esta rigidez es deliberada: un analizador no tiene que adivinar la intención, lo cual es lo que hace que JSON sea interoperable de forma fiable entre las implementaciones de cada lenguaje.
