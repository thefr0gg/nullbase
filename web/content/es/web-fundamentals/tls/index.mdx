**HTTPS** es simplemente **HTTP** enviado sobre una conexión cifrada mediante **TLS** — el modelo de solicitud/respuesta no cambia en absoluto, solo cambia el transporte por debajo. TLS (Transport Layer Security) es lo que proporciona:

- **Cifrado** — nadie entre el cliente y el servidor puede leer el tráfico.
- **Integridad** — nadie entre medias puede modificar el tráfico sin que ambos lados lo noten.
- **Autenticación** — el cliente obtiene una prueba criptográfica de que realmente está hablando con el servidor que cree (a través del certificado del servidor).

## Lo que HTTPS no protege

TLS asegura la conexión, no los dos extremos. No impide:

- Que un servidor comprometido filtre datos que mantiene en texto plano.
- Que un malware en el cliente lea los datos antes de que se cifren o después de que se descifren.
- Que un usuario sea engañado por phishing para visitar `paypa1.com` en lugar de `paypal.com` — eso es una conexión HTTPS válida a un servidor *equivocado pero real*.
