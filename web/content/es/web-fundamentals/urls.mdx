Una **URL** (Uniform Resource Locator) identifica un recurso y cómo obtenerlo. Cada parte tiene un trabajo:

<UrlAnatomy
  parts={[
    { text: "https://", label: "esquema", color: "blue" },
    { text: "api.example.com", label: "host", color: "green" },
    { text: ":443", label: "puerto", color: "orange" },
    { text: "/v1/users", label: "ruta", color: "purple" },
    { text: "?active=true", label: "consulta", color: "red" },
    { text: "#profile", label: "fragmento", color: "default" },
  ]}
/>

- **`https`** — protocolo/esquema. Indica al navegador qué protocolo usar para hablar con el host.
- **`api.example.com`** — host. El dominio (o IP) que el DNS resuelve para encontrar el servidor.
- **`443`** — puerto. Normalmente se omite ya que 80 (HTTP) y 443 (HTTPS) son los valores predeterminados.
- **`/v1/users`** — ruta. Qué recurso del servidor quieres.
- **`?active=true`** — cadena de consulta. Parámetros adicionales, como pares clave-valor.
- **`#profile`** — fragmento. Solo del lado del cliente — nunca se envía al servidor.
