El código de estado de respuesta `200 OK` indica que **la solicitud tuvo éxito**. Es el código de estado más común en la web.

<StatusCodeExplorer defaultCode={200} />

## Detalles

- **Clase:** 2xx (Éxito)
- **Típico con:** `GET`, `PUT`, `PATCH`, `DELETE`, `POST`
- **Cacheo:** una respuesta `200` es cacheable por defecto.

## Ejemplo

```http
HTTP/1.1 200 OK
Content-Type: application/json

{ "status": 200, "message": "OK" }
