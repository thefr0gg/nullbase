El encabezado `Cache-Control` transporta directivas que controlan el comportamiento de Cache — para navegadores, y para cualquier cosa entre el cliente y el servidor de origen, como una [CDN](/es/web-fundamentals/cdns). Puede aparecer tanto en solicitudes como en respuestas; es en las respuestas donde más importa.

## Una respuesta típica

```http
HTTP/1.1 200 OK
Content-Type: application/json
Cache-Control: public, max-age=3600, must-revalidate
```

Cacheable por cualquiera, fresca durante una hora, y una vez pasada esa hora, no se sirve de nuevo sin comprobar primero con el origen.
