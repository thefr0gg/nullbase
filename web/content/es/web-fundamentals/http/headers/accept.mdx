El encabezado de solicitud `Accept` indica al servidor qué tipos de medios está dispuesto a manejar el cliente en la respuesta — esto es **negociación de contenido**. Un servidor que puede devolver el mismo recurso como JSON, HTML, o XML usa `Accept` para decidir cuál enviar realmente.

## Cómo se estructura

`Accept` puede listar varios tipos con un valor `q` (calidad) que indica preferencia, siendo `1` el más alto:

```http
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8
```

Esto dice: preferir HTML, luego XHTML, luego XML plano al 90% de preferencia, luego cualquier otra cosa como último recurso.

## Cuando el servidor no puede cumplir

Si el servidor realmente no puede producir ninguno de los tipos que el cliente aceptará, debe responder con `406 Not Acceptable` en lugar de enviar silenciosamente un formato que el cliente no pidió.
