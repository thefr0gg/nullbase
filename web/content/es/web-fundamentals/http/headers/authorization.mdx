El encabezado de solicitud `Authorization` contiene las **credenciales** para la autenticación HTTP. El servidor valida estas credenciales y sirve el recurso o responde con `401 Unauthorized`.

<HttpRequest
  defaultMethod="GET"
  defaultPath="/api/profile"
  defaultHeaders="Accept: application/json
Authorization: Bearer nullbase-demo-token"
/>

## Esquemas comunes

| Esquema | Uso |
|---|---|
| `Basic` | `Authorization: Basic <base64(user:pass)>` |
| `Bearer` | `Authorization: Bearer <token>` (OAuth, JWT, etc.) |
| `Digest` | Desafío-respuesta con un nonce del servidor |

## Ejemplo

```http
GET /api/http/echo HTTP/1.1
Authorization: Bearer nullbase-demo-token
```

El valor se envía por la red, así que **usa siempre HTTPS** al transmitir credenciales — nunca en HTTP sin cifrar.
