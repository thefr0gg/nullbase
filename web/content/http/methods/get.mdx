# GET

The `GET` method requests a representation of the specified resource. Data is sent to the server via **query parameters** in the URL (the request line and headers). A `GET` request has **no body** by specification.

<HttpRequest defaultMethod="GET" defaultPath="/api/http/echo?hello=world" />

## Properties

- **Safe** — `GET` requests should not change server state.
- **Idempotent** — making the same `GET` request many times yields the same result.
- **Cacheable** — responses are cacheable (unless headers say otherwise).

## Example

```http
GET /api/http/echo?hello=world HTTP/1.1
Host: nullbase.local
Accept: application/json
```

### `GET` vs `POST`

| Aspect | GET | POST |
|---|---|---|
| Data location | Query string (`?key=value`) | Body |
| Body | None | Yes |
| Cacheable | Yes | No (by default) |
| Bookmarked | Yes | No |
