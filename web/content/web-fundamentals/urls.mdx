# URLs & URIs

A **URL** (Uniform Resource Locator) identifies a resource and how to get it. Every part of it has a job:

```
https://api.example.com:443/v1/users?active=true#profile
└─┬──┘   └─────┬───────┘└┬┘└─────┬─────┘└────┬────┘└──┬──┘
scheme       host       port    path        query   fragment
```

- **`https`** — protocol/scheme. Tells the browser which protocol to use to talk to the host.
- **`api.example.com`** — host. The domain (or IP) DNS resolves to find the server.
- **`443`** — port. Usually omitted since 80 (HTTP) and 443 (HTTPS) are the defaults.
- **`/v1/users`** — path. Which resource on the server you want.
- **`?active=true`** — query string. Extra parameters, as key-value pairs.
- **`#profile`** — fragment. Client-side only — never sent to the server at all.
