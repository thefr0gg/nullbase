# Web Fundamentals

Before a browser can send a single HTTP request, a lot has to happen: a domain name has to resolve to an IP address, a connection has to open, and — for anything on the modern web — that connection has to be encrypted. This section covers the layers underneath HTTP itself.

## Start Here

- **[URLs & URIs](/web-fundamentals/urls)** — the anatomy of a URL and what each piece does.
- **[DNS](/web-fundamentals/dns)** — how a hostname becomes an IP address.
- **[TLS & HTTPS](/web-fundamentals/tls)** — how a connection gets encrypted before any HTTP flows over it.
