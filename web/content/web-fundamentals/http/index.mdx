# HTTP

**Hypertext Transfer Protocol (HTTP)** is the foundation of web communication. Every request from your browser, every API call, every interaction with a server flows through HTTP.

This reference teaches HTTP not through isolated facts, but through **interactive tools** — compose real requests, explore status codes, inspect headers, and understand why HTTP behaves the way it does.

## Core Concepts

### Methods (Verbs)
Every request uses a method. Here are the most important:

- **[GET](/web-fundamentals/http/methods/get)** — Retrieve a resource.
- **[POST](/web-fundamentals/http/methods/post)** — Submit data, create resources, trigger actions.
- **[PUT](/web-fundamentals/http/methods/put)** — Replace or create a resource entirely.
- **[PATCH](/web-fundamentals/http/methods/patch)** — Partial updates.
- **[DELETE](/web-fundamentals/http/methods/delete)** — Remove a resource.
- **[HEAD](/web-fundamentals/http/methods/head)** — Like GET, but headers only (no body).
- **[OPTIONS](/web-fundamentals/http/methods/options)** — Describe communication options for a resource.
- **[All Methods Reference](/web-fundamentals/http/methods)** — Safe, idempotent, cacheable properties.

### Status Codes
Every response begins with a code. Master them all:

- **[2xx Success](/web-fundamentals/http/status-codes/2xx)** — 200 OK, 201 Created, 204 No Content, etc.
- **[3xx Redirection](/web-fundamentals/http/status-codes/3xx)** — 301 Moved, 302 Found, 304 Not Modified, etc.
- **[4xx Client Error](/web-fundamentals/http/status-codes/4xx)** — 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, etc.
- **[5xx Server Error](/web-fundamentals/http/status-codes/5xx)** — 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable, etc.

**[Live Status Code Explorer](/web-fundamentals/http/status-codes)** — See what each code means and when servers use it.

### Headers
Metadata that controls behavior. The essentials:

**Request Headers:**
- **[Authorization](/web-fundamentals/http/headers/authorization)** — Prove who you are (Basic, Bearer, API keys).
- **[Content-Type](/web-fundamentals/http/headers/content-type)** — Format of the request body (application/json, form-data, etc.).
- **[Accept](/web-fundamentals/http/headers/accept)** — What response formats you can understand.
- **[User-Agent](/web-fundamentals/http/headers/user-agent)** — Identify the client.

**Response Headers:**
- **[Content-Type](/web-fundamentals/http/headers/content-type)** — Format of the response body.
- **[Cache-Control](/web-fundamentals/http/headers/cache-control)** — How long to cache this response.
- **[Set-Cookie](/web-fundamentals/http/headers/set-cookie)** — Store data on the client.
- **[Location](/web-fundamentals/http/headers/location)** — Where to redirect (3xx responses).

**[All Headers Reference](/web-fundamentals/http/headers)** — 50+ headers with examples and use cases.

## Protocol Versions

Understanding the evolution matters — features changed, performance improved.

- **[HTTP/1.0](/web-fundamentals/http/http1-0)** — The original (1991). Stateless, simple.
- **[HTTP/1.1](/web-fundamentals/http/http1-1)** — The standard (1997–today). Keep-Alive, pipelining, caching.
- **[HTTP/2](/web-fundamentals/http/http2)** — Multiplexing and server push (2015). Faster with a single connection.
- **[HTTP/3](/web-fundamentals/http/http3)** — QUIC-based, even faster (2022).
