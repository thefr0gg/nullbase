# Content-Type

The `Content-Type` header indicates the **media type** (formerly MIME type) of the resource: the format of the bytes sent in the message body. The server uses it to tell the client how to interpret the payload.

<HttpRequest
  defaultMethod="POST"
  defaultPath="/api/http/echo"
  defaultHeaders="Content-Type: application/json
Accept: application/json"
  defaultBody='{"hello":"world"}'
/>

## Common media types

| Type | Example |
|---|---|
| JSON | `application/json` |
| Form | `application/x-www-form-urlencoded` |
| Form (multipart) | `multipart/form-data` |
| HTML | `text/html` |
| CSS | `text/css` |
| Plain text | `text/plain` |
| PNG | `image/png` |

## Example

```http
POST /api/http/echo HTTP/1.1
Content-Type: application/json

{"hello":"world"}
