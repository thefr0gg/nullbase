# Accept

The `Accept` request header tells the server which media types the client is willing to handle in the response — this is **content negotiation**. A server that can return the same resource as JSON, HTML, or XML uses `Accept` to decide which one to actually send back.

## How it's structured

`Accept` can list multiple types with a `q` (quality) value indicating preference, `1` being highest:

```http
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8
```

This says: prefer HTML, then XHTML, then plain XML at 90% preference, then anything else as a last resort.

## When the server can't comply

If the server genuinely cannot produce any of the types the client will accept, it should respond with `406 Not Acceptable` rather than silently sending a format the client didn't ask for.
